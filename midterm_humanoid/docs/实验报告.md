# ROS2期中实验报告——简易人形机器人URDF建模

## 一、实验目的
1. 掌握URDF机器人建模语法，学会定义link连杆与joint关节。
2. 能够为连杆添加可视化、碰撞体、惯性参数，搭建可用于物理仿真的机器人模型。
3. 使用robot_state_publisher校验URDF文件语法正确性，排查模型报错与警告。

## 二、实验环境
代码编写环境：Windows 11
运行环境：Ubuntu 22.04 + ROS2 Humble
工具：robot_state_publisher、RViz2、Gazebo

>说明：本机仅完成代码编写，受虚拟机显卡加速问题限制，暂未完成可视化截图，模型可迁移至Ubuntu系统直接运行。

## 三、实验原理
URDF（Unified Robot Description Format）统一机器人描述格式，使用XML标签描述机器人。
- `<link>`：机器人独立刚体部件，包含外观visual、碰撞体collision、惯性参数inertial。
- `<joint>`：连杆之间的连接关系，本次实验使用fixed固定关节，部件之间无相对运动。

robot_state_publisher节点负责解析URDF文件，检验语法并发布机器人状态。

## 四、实验步骤
1. 创建项目文件夹midterm_humanoid，划分目录结构。
2. 新建final_human.urdf文件，依次定义躯干、头、双臂、双腿六个连杆。
3. 给每个连杆添加可视化形状、碰撞体、质量惯性参数。
4. 使用fixed关节将四肢、头部连接至躯干。
5. 使用robot_state_publisher命令校验模型文件。
6. 观察终端输出，识别KDL惯性警告，记录存在的问题。
7. 编写说明文档、运行日志，整理第一次提交版本。

## 五、实验结果
执行校验命令后，程序成功识别6个连杆。
但是出现警告：
>The root link base_link has an inertia specified in the URDF, but KDL does not support a root link with an inertia.

含义：根连杆base_link配置了惯性参数，KDL库不支持根连杆携带惯性，会弹出警告。模型虽然可以正常加载，但不符合物理仿真的规范。

## 六、问题分析
警告来源：整个机器人的根节点base_link同时配置惯性参数。
解决思路（二期任务）：新增一个无几何外形的虚拟连杆dummy_link作为顶层根节点，base_link作为它的子连杆，以此消除警告。

## 七、实验总结
本次实验完成简易人形机器人URDF建模，熟悉了link、joint标签的使用，成功配置机器人的可视化、碰撞和惯性参数，并完成语法校验。
当前版本实现基础功能，但存在根连杆惯性警告，后续第二次提交将优化模型结构，解决该警告，使模型适配物理仿真引擎。
