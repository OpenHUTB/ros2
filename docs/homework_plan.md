## 二、任务选择理由

仓库空域载具板块已有 **uav_ppo_nav（基于 PPO 的无人机导航避障）**。PPO 是
**连续动作**算法；本作业新增 **uav_dqn_nav（基于 DQN）**，用**离散动作**算法
解决同一任务，形成"**相同模型、不同 RL 算法**"的对照实验。DQN 模块与 PPO
**共用同一训练环境（NavEnv）、同一 22 维观测、同一世界系（ENU）动作接口**，
仅替换算法层，保证对比公平。

## 四、实验结果（详见 README §7 与 docs/air/uav_dqn_nav.md §5）

| 场景 | DQN 成功率 | PPO 成功率 | 说明 |
| ---- | ---- | ---- | ---- |
| 16 障碍（100 回合） | **4%**（4/100） | **78%**（78/100） | DQN 能避障（碰撞仅 8 次）但无法精确停靠 0.4 m 点目标 |
| 6 障碍（100 回合） | 0%（0/100） | 待补跑 | 同上，超时为主 |

**核心结论**：离散动作空间（22.5° 方向网格）在"精确到达点目标"任务上存在
固有精度限制；PPO 连续动作可平滑逼近目标。该对比真实展示了**动作空间离散化
对精细控制任务的影响**，是作业要求的"端到端模型/算法对比"的核心成果。
