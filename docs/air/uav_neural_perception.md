# 无人机视觉导航（前视 CNN 行为克隆）

> 第二次作业（任务②）：机载前视 RGB 摄像头图像 → CNN 行为克隆回归 → 机体系速度指令。
> 本页如实记录当前基线的实现方式、离线指标与已知局限；**当前模型尚未实现主动避障与自主绕障**，能力边界见第 5 节。

## 1. 系统架构

```text
前视图像 /camera/image_raw
   → 预处理（resize 120×160，ImageNet 均值方差归一化）
   → CNN 推理（输出归一化动作 [-1, 1]）
   → 反归一化回原始速度指令
   → 安全层限幅 + 非法输出拦截
   → /uav/cmd_vel（geometry_msgs/Twist，机体系 x 前 / y 左 / z 上）
   → carlair_ros_bridge 连接 CarlaAir/AirSim 执行
```

- 感知节点只订阅 `/camera/image_raw`、发布 `/uav/cmd_vel`，不直连仿真器；坐标换算与执行集中在桥接层。
- 安全限幅：`max_vx = 2.0 m/s`，`max_vy = 0.5 m/s`，`max_yaw = 0.4 rad/s`，与人工采集标签尺度一致。

## 2. 算法与模型

### 2.1 行为克隆（模仿学习）思路

1. 用键盘遥控人工飞行，同步录制前视图像与当前速度指令，构成 `(图像, [vx, vy, yaw])` 配对样本；
2. 用监督学习让 CNN 从图像回归三维速度指令；
3. 部署时实时推理当前图像对应的速度指令并发布。

### 2.2 标签归一化

三个指令通道量级不同（vx 最大 2.0、vy 最大 0.5、yaw 最大 0.4），若直接做 MSE，大量级的 vx 会淹没小量级的 vy / yaw，转向指令被回归均值压缩。因此训练标签先按限幅归一化到 `[-1, 1]`：

```text
[vx_n, vy_n, yaw_n] = [vx/2.0, vy/0.5, yaw/0.4]
```

网络末层用 `Tanh` 把输出约束在 `[-1, 1]`；部署节点推理后再线性反归一化回原始速度尺度。

### 2.3 网络结构

```text
Conv2d(3→16, k5/s2) → ReLU → MaxPool
Conv2d(16→32, k5/s2) → ReLU → MaxPool
Conv2d(32→64, k3/s1) → ReLU → AdaptiveAvgPool(4×4)
Flatten → Linear(1024→128) → ReLU → Dropout(0.3) → Linear(128→3) → Tanh
```

- 输入：`3×120×160` RGB 图像；输出：`3` 维归一化动作；
- 模型参数量 **164,131**；模型定义见 `scripts/model.py`。

### 2.4 训练配置（`scripts/train.py`）

| 项目 | 配置 |
|---|---|
| 轮次 | 40 epoch |
| Batch size | 16 |
| 优化器 | AdamW，学习率 1e-3，权重衰减 1e-4 |
| 损失 | 三通道 MSE（等权） |
| 采样 | WeightedRandomSampler 按动作类别均衡采样，避免少样本转向方向被多数方向淹没 |
| 训练集增强 | 随机水平翻转（vy、yaw 对称取反）+ 亮度/对比度抖动 |
| 验证集 | 确定性预处理，不做增强；随机种子 42；训练/验证按 85% / 15% 划分 |

### 2.5 数据集

采集目录默认 `~/perception_dataset/`（`data.csv` + `images/`），当前训练集共 **6280** 条记录、5932 张图像，动作类别分布：

| 动作标签 `(vx, vy, yaw)` | 含义 | 样本数 | 占比 |
|---|---|---:|---:|
| `(2.0, 0, 0)` | 前进 | 3221 | 51.3% |
| `(0, 0, -0.4)` | 左转 | 1030 | 16.4% |
| `(0, 0, 0.4)` | 右转 | 903 | 14.4% |
| `(-2.0, 0, 0)` | 后退 | 574 | 9.1% |
| `(0, 0.5, 0)` | 左移 | 296 | 4.7% |
| `(0, -0.5, 0)` | 右移 | 256 | 4.1% |

> 采集时转向与前进分时按键，因此数据中没有"前进中弧线绕行"的复合轨迹样本。

## 3. 安全设计（对应审查阻塞意见）

安全逻辑抽成不依赖 ROS 的 `scripts/safety.py`，可在无仿真器环境下做回归测试：

- **权重缺失 / 加载失败即安全停止**：部署节点固定 `allow_random=False`。权重文件不存在、损坏、结构不匹配时，节点不创建发布者、不注册订阅者、不进入推理循环，直接 `logfatal` 并 `signal_shutdown`，**绝不使用随机初始化模型驱动无人机**；随机权重只允许在离线自检时由调用方显式开启（`allow_random=True`）。
- **非法输出拦截**：模型输出出现 `NaN` / `inf` / 长度异常时，安全层返回 `None`，节点丢弃本帧、不下发速度指令。
- **合法输出限幅**：合法但超界的动作被钳制到 `[-2.0, 2.0]`、`[-0.5, 0.5]`、`[-0.4, 0.4]` 范围内。
- 在线指令增益参数 `gain_vx / gain_vy / gain_yaw` 仅预留配置位，**默认 1.0 保持原始行为**；放大方案经在线实测不稳定，已弃用。

回归测试 `tests/test_local.py` 覆盖：缺失权重拒绝部署、随机权重仅限离线自检、NaN/inf/长度异常拦截、合法输出正确限幅、模型前向形状、图像预处理形状，共 7 项。

## 4. 离线评估结果（当前 v3 权重，6280 样本）

### 4.1 训练收敛

最佳验证集 MSE（归一化空间）**val_loss = 0.09219**（Epoch 40）。

### 4.2 整体回归质量（原始尺度）

| 通道 | 标签均值 | 标签 std | 预测均值 | 预测 std | MSE |
|---|---:|---:|---:|---:|---:|
| vx (m/s) | 0.843 | 1.306 | 0.805 | 1.249 | 0.2668 |
| vy (m/s) | 0.003 | 0.148 | -0.000 | 0.149 | 0.0079 |
| yaw (rad/s) | -0.008 | 0.222 | 0.001 | 0.175 | 0.0187 |

### 4.3 分动作方向一致率

| 动作 | 样本数 | 预测均值 `(vx, vy, yaw)` | 方向一致率 |
|---|---:|---|---:|
| 前进 | 3221 | `(+1.83, -0.00, +0.01)` | 96.1% |
| 左转 | 1030 | `(+0.06, +0.01, -0.24)` | 96.1% |
| 右转 | 903 | `(+0.06, +0.00, +0.26)` | **76.4%** |
| 后退 | 574 | `(-1.66, -0.01, -0.01)` | 99.7% |
| 左移 | 296 | `(-0.01, +0.38, -0.01)` | 94.9% |
| 右移 | 256 | `(+0.04, -0.45, -0.00)` | 100.0% |

转向专项：左转 `n=1030`，预测 yaw 均值 `-0.237`，方向一致率 96.1%；右转 `n=903`，预测 yaw 均值 `+0.263`，方向一致率 **76.4%**（约四分之一被判反，是当前主要短板）。转向幅值约为限幅（0.4 rad/s）的 59% ~ 66%，被回归均值压低。

上述指标由离线诊断脚本 `scripts/diag_v2.py` 复现（整体 MSE、各方向一致率、转向召回、幅值对比）。

## 5. 当前能力边界与已知局限

以下为当前基线的如实结论，不做夸大：

1. **尚未实现主动避障 / 自主绕障**。在线 20 秒监控中，无人机轨迹主要由横向速度被动漂移带动，模型没有学到"接近障碍 → 主动转向绕行"的因果；近距离面对墙体时模型倾向保持前冲而非转向，存在撞墙风险。
2. **右转召回偏低**：约 1/4 的右转样本被判反，右转方向判断不稳定。
3. **转向幅值被回归均值压低**：MSE 回归向均值收缩，输出转向幅度只有限幅的六成左右。
4. **类别不平衡**：前进样本占 51.3%，模型回归向"前进"多数类偏移；数据中缺少前进中弧线绕行的连续轨迹样本。
5. **泛化与分布偏移**：离线诊断与在线部署的画面分布存在差异；步进时钟（SteppableClock）下速度积分异常，也限制了在线贴近障碍的可控测试。
6. 模型仅依据单目前视 RGB 图像，未利用深度、雷达等距离信息，缺乏直接的障碍距离感知。

### 5.1 后续改进方向（非当前已实现能力）

- 补采"前进中弧线绕行"连续轨迹，增加右转样本并做类别过采样或转向通道加权损失；
- 融合深度图 / 激光雷达等距离感知信息；
- 引入时域网络（如 LSTM/GRU）建模连续帧运动轨迹；
- 在安全层之外叠加规则式距离兜底（深度 / 雷达触发强制制动或悬停）。

## 6. 数据集与权重入库说明

- 数据集图像与训练权重 `.pth` **均不提交本仓库**（体积大、可本地复现）。仓库内只包含源码、配置与测试。
- 部署前必须先在本机采集数据并运行 `train.py`，在 `scripts/models/` 下生成 `best_drone_model.pth`；缺失权重时部署节点会按第 3 节安全停止，不会随机起飞。

## 7. 运行环境与步骤

### 7.1 环境

- Ubuntu 20.04 + ROS Noetic；
- PyTorch（CPU）、OpenCV、cv_bridge、NumPy；
- 前置：`carlair_ros_bridge` 已启动并连接仿真器。

### 7.2 编译

```bash
cd ~/catkin_ws && catkin_make
```

### 7.3 （可选）采集数据集

先用键盘包 `uav_keyboard_control` 遥控飞行，再启动采集节点；节点只在机体处于运动状态时存图，避免悬停画面污染数据集：

```bash
rosrun uav_neural_perception dataset.py
# 默认采集目录 ~/perception_dataset；扫描现有最大编号续采，重启不会覆盖旧样本
```

### 7.4 训练

```bash
cd ~/catkin_ws/src/air/uav_neural_perception/scripts
python3 train.py --csv ~/perception_dataset/data.csv
# 可选参数：--epochs 40 --batch-size 16 --lr 1e-3 --weight-decay 1e-4
# 权重输出到 scripts/models/best_drone_model.pth
```

### 7.5 （可选）离线诊断

```bash
cd ~/catkin_ws/src/air/uav_neural_perception/scripts
python3 diag_v2.py
```

### 7.6 部署运行

```bash
roslaunch uav_neural_perception main.launch
# 订阅 /camera/image_raw，发布 /uav/cmd_vel；默认权重 scripts/models/best_drone_model.pth
# 可用 launch 参数覆盖 model_path / max_vx / max_vy / max_yaw
```

## 8. 本地测试（无需仿真器、无需 ROS）
