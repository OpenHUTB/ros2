# 神经残差动力学与学习式轨迹跟踪

!!! note "占位页"
    完整内容随本模块 PR 提交。

对应任务（2）给定轨迹的控制。
用网络学习四旋翼未建模动力学（气动阻尼、地面效应、载荷变化、风扰），
作为几何控制器的残差补偿，并支持秒级在线自适应。

## 与已有模块的区别

`src/air/` 与 `OpenHUTB/nn/src` 中无学习式动力学建模或自适应控制模块：

| 已有 | 区别 |
|---|---|
| `unmannedcar_MPC` | 是车；用解析模型而非学习模型 |
| `drone_path_learning` | 学"走哪条路"，不学"怎么飞" |
| `uav_ppo_nav` | 端到端黑箱策略，不显式建模动力学 |

## 计划

* 基底：几何控制（负责已知的刚体动力学）
* 残差：小型 MLP 学 $f_{\text{res}}(x, u)$，输出加速度修正
* 在线自适应：滑动窗口递推最小二乘，只更新最后一层，实现秒级适应新载荷
* 数据：由 uav_mujoco_sim 随机激励飞行自动采集，无需人工标注
* 对比：3 载荷 × 2 风扰 × 2 轨迹（螺旋、8 字），位置/姿态 RMSE、控制能量、适应时间；
  基线 PID、纯几何、几何+MLP 离线、几何+MLP 在线自适应
