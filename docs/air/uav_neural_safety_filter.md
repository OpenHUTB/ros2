# 神经控制屏障函数安全过滤器

!!! note "占位页"
    完整内容随本模块 PR 提交。

实时安全层：接收上层控制器（键盘遥控、导航策略、端到端策略）的速度指令，
送入执行器前用网络修正为安全动作，给出可证明的安全边界。

## 与已有模块的区别

课程仓库与 `OpenHUTB/nn/src`（218 个已有实现）中无任何安全、可达性或控制屏障函数
相关的工作。已有避障类项目都是"把避障编进奖励函数"的软约束，无保证，也不能叠加在别人的控制器上。

| 已有 | 区别 |
|---|---|
| `airsim_depth_obstacle_avoidance` | 避障编进策略奖励，学习型软约束 |
| `uav_ppo_nav` | 同上 |
| 本项目其他模块 | 本模块是安全层，与性能正交，可叠加在任何一个上面 |

## 计划

* 安全集 $\mathcal{C} = \{x : h(x) \ge 0\}$，约束 $\dot{h} + \alpha h \ge 0$ 保证前向不变性
* 神经 $h(x)$：比手工二次型障碍函数保守性更低（手工版会把大量安全区域误判为危险）
* QP：在 CBF 约束下求与期望指令最接近的安全指令
* 实时性：小型网络 + QP 求解器，CPU 单步 < 1 ms
* 对比：无安全层 / 手工 CBF / 神经 CBF 的碰撞率与保守性（指令修改幅度、可达空间缩小比例），
  给出"安全性 vs 任务完成度"权衡曲线
