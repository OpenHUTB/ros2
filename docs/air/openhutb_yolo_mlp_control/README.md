# OpenHUTB 无人机感知与控制

本目录提供 YOLO 感知、MLP 八字轨迹控制及相关功能的使用文档。

## 阅读入口

- [环境配置](setup.md)：依赖安装、模拟器连接、YOLO 权重和功能包构建。
- [YOLO 感知与八字轨迹控制](yolo_trajectory_control.md)：系统架构、运行命令和轨迹分析。
- [YOLO 目标视觉伺服：居中与距离保持](yolo_visual_centering.md)。

## 功能扩展与未来规划

视觉伺服目前支持：水平居中、目标丢失后停止跟随并在重新确认后恢复、基于表观尺寸的距离保持，以及可选的垂直居中，详见[YOLO 目标视觉伺服：居中与距离保持](yolo_visual_centering.md)。仍待实现的部分包括：对**运动目标**的持续跟随与环绕拍摄、把距离估计从单目表观尺寸升级为深度或已知尺寸约束、以及与避障规划的联合。
