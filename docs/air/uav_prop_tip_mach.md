# 旋翼桨尖马赫数与桨盘载荷核算

选桨时两个最容易忽略、又最影响噪声与效率的量：**桨尖马赫数**和**桨盘载荷**。前者决定桨尖会不会
提前进入压缩性（噪声陡增、效率下降），后者决定悬停要多大的诱导速度与功率。

本模块用三个课本公式把这两件事一次算清楚，只依赖 Python 标准库，不需要 NumPy、Matplotlib 或 ROS。
（页内公式用代码块给出，避免依赖前端数学渲染。）

## 默认机型结论

默认参数：2 kg 四旋翼、单桨直径 0.254 m（10 寸）、悬停转速 6500 rpm、最大转速 9000 rpm、15 ℃。

| 指标 | 数值 | 判定 |
| --- | --- | --- |
| 声速 | 340.29 m/s | 15 ℃ 标准值 |
| 悬停重力 | 19.61 N | 单桨 4.90 N |
| 总桨盘面积 | 0.2027 m² | 4 × π(0.127)² |
| 桨尖速度（悬停） | 86.45 m/s | — |
| 桨尖马赫数 | 悬停 0.254 / 最大转速 0.352 | 正常（<0.6） |
| 桨盘载荷 | 96.8 N/m²（9.87 kg/m²） | 偏低（<100） |
| 悬停诱导速度 | 6.28 m/s | — |

也就是说这套 10 寸桨在 9000 rpm 下马赫数才 0.35，离压缩性还远；桨盘载荷也偏低，属于「桨偏大、
转速偏低、效率取向」的配置。反过来，把桨径缩到 5 寸（0.127 m）并保持 2 kg，桨盘载荷会翻 4 倍到
387 N/m²，桨尖马赫数在同样转速下减半——载荷换噪声，这就是小桨高速机的典型取舍。

## 2. 公式

```text
声速        a      = sqrt(gamma * R * T)          gamma=1.4, R=287.05 J/(kg*K), T 用开尔文
桨尖速度    v_tip  = pi * D * rpm / 60
桨尖马赫数  M_tip  = v_tip / a
总桨盘面积  A      = pi * (D/2)^2 * n
桨盘载荷    DL     = m * g / A                    单位 N/m^2
悬停诱导速度 v_i   = sqrt(DL / (2 * rho))         动量理论, rho=1.225 kg/m^3
```

两条反解（报告里的 `limits` 字段）：

```text
给定目标马赫数 M*   ->  rpm*  = M* * a * 60 / (pi * D)
给定目标桨盘载荷 DL* ->  D*    = 2 * sqrt((m*g/DL*/n) / pi)
```

## 3. 判定阈值

| 量 | 阈值 | 含义 |
| --- | --- | --- |
| 桨尖马赫数 | < 0.6 正常；0.6–0.7 注意；≥ 0.7 过高 | 0.7 以上桨尖压缩性使噪声与型阻明显上升 |
| 桨盘载荷 | < 100 N/m² 偏低；100–250 中等；> 250 偏高 | 载荷越大，诱导速度与悬停功率越大，抗风与续航越吃亏 |

阈值是工程经验值，不是硬性适航限制；不同桨型（多叶、宽弦、后掠桨尖）能承受的桨尖马赫数不一样。

## 4. 适用范围与限制

- 只看桨尖与桨盘的平均量：不含叶素理论、桨叶扭转/锥度、叶尖损失、涡流与相邻桨的气动干扰；
- 诱导速度用理想动量理论，实际悬停诱导速度略高（有型阻与叶尖损失）；
- 没有电机/电调的转速-扭矩特性，也没有噪声的 dB 估算；
- 静态估算，用于选型初筛与作业窗口判断，不代替桨叶气动仿真或台架试验。

13 项检查全部通过，期望值都能手算核对：

- 声速公式与 15 ℃ 的 340.29 m/s；温度升高声速变大；
- `v_tip = πDrpm/60`、`M = v_tip/a`，以及马赫数对转速/桨径的线性关系；
- 桨盘面积、桨盘载荷，重量翻倍与桨径翻倍的两条缩放关系；
- 诱导速度 `sqrt(DL/(2ρ))` 与密度降低时变大；
- 马赫数三级阈值与桨盘载荷三个区间（含边界值）；
- `rpm_for_mach`、`diameter_for_disk_loading` 两个反解与正解互逆；
- `report.json` 字段自洽、参数校验（质量/桨径/转速/温度/密度/重力/旋翼数）；
