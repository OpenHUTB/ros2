# 多旋翼重心偏移配平与饱和包线核算

电池、相机或机械爪装偏之后，多旋翼悬停时四只电机会出力不均来配平；重心偏得太多，
某只电机先饱和，配平就做不到了。本模块用四条静力平衡方程把「偏了多少 → 电机怎么出力 →
倾斜多少度 → 还能偏多少」一次算清楚，只依赖 Python 标准库。

## 默认样机结论

默认参数：1.2 kg 四旋翼（plus 构型）、前后/左右力臂均 0.25 m、重心前偏 3 mm、右偏 2 mm、
桨平面到重心 30 mm、单电机最大拉力 6 N（约为四分之一重量的 2 倍）。

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 电机拉力 | 前 3.01 / 右 2.99 / 后 2.87 / 左 2.89 N | 前电机补 0.071 N，后电机减 0.071 N |
| 最大电机拉力 | 3.01 N（正常） | 远低于 6 N 上限 |
| 悬停倾角 | 俯仰 +5.71°，横滚 +3.81° | tan = 偏移 / 重心深度 |
| 饱和包线 | 纵向 ±0.130 m，横向 ±0.130 m | 电机饱和前的最大可配平偏移 |
| 饱和倾角 | 俯仰/横滚 77.0° | 包线边界对应的倾角 |
| 配平裕度 | 纵向 97.7%，横向 98.5% | 离饱和还差得远 |

两个值得注意的结论：

- **几毫米的偏心就是几度的倾角。** 重心离桨平面只有 30 mm，`atan(3/30) = 5.7°`。
  多旋翼"悬停时有点歪"通常不是飞控问题，而是配平问题——先查重心，再调参数。
- **包线由单电机饱和决定。** 上限 6 N 是四分之一重量的 2 倍，所以允许的重心偏移高达
  ±0.13 m（相对 0.25 m 力臂的一半）。把电机上限从 2 倍降到 1.2 倍重量，包线会缩小到
  ±0.02 m 量级——这就是"推力余量就是配平余量"。

## 2. 公式

```text
W = m*g
T1 + T2 + T3 + T4 = W                   悬停合力（前/右/后/左）
(T1 - T3) * b = W * dx                  俯仰力矩平衡，b 为前后力臂
(T2 - T4) * a = W * dy                  横滚力矩平衡，a 为左右力臂

T1 = W/4 + W*dx/(2b)   T3 = W/4 - W*dx/(2b)
T2 = W/4 + W*dy/(2a)   T4 = W/4 - W*dy/(2a)

theta = atan(dx / h)   phi = atan(dy / h)        h 为桨平面到重心高度
dx_max = 2b * (T_max/W - 1/4)   dy_max = 2a * (T_max/W - 1/4)
```

`T_max/W < 1/4` 时，单电机带不动四分之一的重量，任何偏移都无法悬停，程序判不可行。
偏移超出包线时，程序按包线给剩余结论，并把 `level` 标为超限。

## 3. 判定阈值

| 量 | 阈值 | 含义 |
| --- | --- | --- |
| 最大电机拉力 | ≤ 上限 正常；> 90% 上限 注意；> 上限 超限 | 饱和前电机的油门余量 |
| 悬停可行性 | T_max ≥ W/4 | 单电机必须带得动四分之一重量 |
| 配平裕度 | 按包线边界算百分比 | 剩余可容忍的偏心量 |

阈值不引入额外经验系数：上限就是电机手册的最大拉力。

## 4. 适用范围与限制

- plus 构型前后/左右通道解耦，公式只对这种构型严格成立；X 构型需要把偏移投影到
  45° 通道上再套用；
- 悬停倾角按"推力线必须穿过重心"推导，忽略桨平面随姿态的气动倾斜耦合与机架弹性；
- 电池/负载随姿态的位移按刚体固定处理，未建模；
- 动态飞行（加速、转弯）时的瞬时配平需求比悬停大，本模块只算悬停工况。
