# 语义分割建图与语义路径规划

!!! note "占位页"
    完整内容随本模块 PR 提交。

对应任务（2）传感器感知、任务（3）建图与导航。
几何地图只知道"哪里有障碍"，本模块用语义分割建图，支持"沿可通行区域飞、绕开植被"这类任务。

## 与已有模块的区别

课程内无人机建图全为纯几何（八叉树 / 栅格），无任何语义建图：

| 已有 | 区别 |
|---|---|
| `octree_uav_3d_pathfinding` | 只有占据/空闲，没有类别 |
| `unmanned_aerial_car_perception` | 是车，且不做地图 |
| `carla_slam_gmapping` | 是车，纯几何 |

分割网络为神经网络，符合"感知算法需为神经网络"的要求。

## 计划

* MuJoCo 分割渲染生成标签 → 训练 U-Net / DeepLabV3-MobileNetV3（256×256，CPU 可训），统计 mIoU
* 分割逆投影到 2.5D 栅格，贝叶斯更新占据概率 + 语义类别投票
* 代价 = 几何距离 + 语义可通行性惩罚 + 语义不确定性惩罚，A*/D* Lite 求解
* 订阅 `/camera/seg`、`/uav/odom`，发布语义地图与规划路径
* 对比：几何栅格 vs 语义栅格，在 3 个"必须穿过可通行区域"场景下的成功率与路径长度
