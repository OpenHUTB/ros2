# 深度图端到端穿越门竞速

!!! note "占位页"
    完整内容随本模块 PR 提交。

对应任务（4）端到端模型（输入图像、输出控制指令）。
三段式"感知→规划→控制"的延迟放不下高速连续穿门，本模块用深度图直接回归控制指令，
训练范式为 DAgger 在线聚合 + PPO 微调。

## 与已有模块的区别

`air_learning` 是最接近的已有工作，五个维度全部不同：

| 维度 | `air_learning` | 本模块 |
|---|---|---|
| 输入模态 | RGB 224×224 | 深度图 96×96 + 当前速度 |
| 数据来源 | 人工遥操作一次性录制 | DAgger 在线聚合（策略跑、专家纠错） |
| 训练范式 | 纯监督 MSE 回归 | 行为克隆预训练 + PPO 微调 |
| 任务 | 通用导航 | 竞速：连续穿越随机摆放的门 |
| 评价 | 验证集 Loss | 穿越时间 / 碰撞率 / 推理延迟 |

## 计划

* 专家：A* + 几何控制器自动生成示范，不需要人工遥控
* 网络：小型 CNN，约 20 万参数，CPU 推理 < 5 ms（满足 20 Hz 控制）
* 阶段一 DAgger 迭代 3 轮（策略跑 → 专家在策略分布上纠错 → 重训）
* 阶段二 PPO 微调，奖励 = 前进距离 − 碰撞惩罚 − 能耗惩罚 − 动作平滑惩罚
* 部署：网络直接发布 `/uav/cmd_vel`
* 对比：纯 BC / BC+PPO / 三段式管线；并承担对比实验②（同一 PPO、不同网络结构：MLP / CNN / GRU / 小型 Transformer）
