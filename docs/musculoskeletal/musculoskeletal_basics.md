# 肌肉骨骼机器人基础

肌肉骨骼机器人（musculoskeletal robot）用**肌肉**驱动关节，而不是用电机直接
输出力矩。这一差别不只是执行器换了个名字，它改变了控制量的含义、出力的大小，
以及整个控制问题的结构。

本文介绍基本概念与常用仿真工具，本版块的模块在此基础上展开。

## 1 与电机驱动机器人的区别

| | 电机驱动机器人 | 肌肉骨骼机器人 |
|---|---|---|
| 控制量 | 力矩 / 电流，可正可负 | **激活度 a ∈ [0, 1]**，只能"收缩" |
| 反向运动 | 电机反转即可 | 必须由**对侧肌肉**拉动 |
| 出力大小 | 近似恒定，与位形无关 | 随**长度**与**收缩速度**变化 |
| 响应速度 | 快，近似瞬时 | 一阶滞后，且**激活快于放松** |
| 刚度 | 由控制器决定 | **共激活**可直接调节关节刚度 |
| 能量 | 通电即消耗 | 可被动储能（肌腱弹性） |

因此肌肉骨骼系统的控制问题**更难也更有研究价值**：控制量被限制在 [0, 1]，
反向力只能靠拮抗肌，出力还随状态变化。

## 2 核心概念

### 2.1 肌肉与肌腱

一块骨骼肌由**收缩成分**（肌纤维）和**弹性成分**（肌腱）串联组成。肌纤维主动
收缩产生力，肌腱像弹簧一样储能并缓冲冲击。仿真中常把肌腱简化为串联弹性单元
（series elasticity），或先忽略它、只建收缩成分。

### 2.2 激活度

神经系统不直接控制肌肉出力，而是发出**神经指令** `u`，使肌肉产生**激活度**
`a ∈ [0, 1]`。激活度不能瞬时跳变，用一阶滞后描述：

```
da/dt = (u - a) / τ,    τ = τ_act  (u > a，正在激活)
                        τ = τ_deact (u ≤ a，正在放松)
```

生理上**激活快于放松**，因此 `τ_act < τ_deact`。

### 2.3 力-长度-速度关系

肌肉能产生多大力，取决于它当前有多长、收缩得多快：

* **力-长度**：肌节在**最优长度** `l_opt` 时主动力最大，过短或过长都下降；
  被拉长超过最优长度时，结缔组织还会产生**被动力**。
* **力-速度**：**缩短**（向心收缩）时力下降，缩短到最大速度时力为 0；
  **拉长**（离心收缩）时力反而**超过**等长收缩，上限约 1.4 倍。

离心收缩比等长收缩更有力，这是肌肉区别于弹簧、阻尼器的重要特性。

### 2.4 共激活

一对**拮抗肌**（屈肌 / 伸肌）可以同时保持一定激活度。这会：

* **提高关节刚度**，增强抗扰与稳定性
* **增加能耗**
* **降低定位精度、减慢响应**（两侧相互对抗）

刚度和精度之间的这种权衡，是肌肉骨骼系统里必须面对的问题。

## 3 Hill 肌肉模型

最常用的肌肉模型由 Hill（1938）提出，把总肌肉力写为

```
F = F_max · [ a · f_l(l_n) · f_v(v_n) + f_p(l_n) ]
```

其中归一化长度 `l_n = l / l_opt`，归一化**缩短速度** `v_n = v / v_max`：

| 符号 | 含义 | 典型形式 |
|---|---|---|
| `f_l` | 主动力-长度 | 高斯型，`l_n = 1` 处为 1 |
| `f_p` | 被动力-长度 | 指数型，`l_n ≤ 1` 时为 0 |
| `f_v` | 力-速度 | Hill 方程，离心段超过 1 |
