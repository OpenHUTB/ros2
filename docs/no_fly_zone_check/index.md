# 禁飞区检测模块

## 功能说明

本模块为无人机配送场景提供**禁飞区安全校验**功能。用户输入取货点和送货点的经纬度坐标，模块判断这两点**以及整条航线**是否进入预设的禁飞区范围。

## 应用场景

在无人机执行配送任务前，需要确认航线起止点不会进入敏感区域（如机场、军事基地、学校上空）。本模块提供了一种基于球面距离与点到线段距离的快速检测方法。

## 算法原理

使用 **Haversine 公式** 计算两个经纬度坐标之间的球面距离，公式如下：

$$
a = \sin^2\left(\frac{\Delta\varphi}{2}\right) + \cos\varphi_1 \cdot \cos\varphi_2 \cdot \sin^2\left(\frac{\Delta\lambda}{2}\right)
$$

$$
c = 2 \cdot atan2\left(\sqrt{a}, \sqrt{1-a}\right)
$$

$$
d = R \cdot c
$$

其中：

- φ₁、φ₂ 为两点的纬度（弧度）
- Δφ、Δλ 为两点纬度和经度的差值
- R 为地球平均半径，取值 6371000 米
- d 为最终距离（米）

## 航线穿越检测（新增）

旧版本只判断取货点/送货点是否落在禁飞区内。当两个端点都在禁区外、但航线从禁区中间穿过时（例如直线配送、绕行失败），会出现「端点安全、航线不安全」的漏判。本版本新增整条航线的检测：

1. 以禁飞区中心为原点做局部等距投影（米），把经纬度变成平面坐标：

$$
x = (\lambda - \lambda_0)\cdot\cos\varphi_0\cdot R,\qquad
y = (\varphi - \varphi_0)\cdot R
$$

2. 把航线变成线段 $A \to B$，求禁区中心到线段的**点到线段最短距离**：

$$
t = \mathrm{clamp}\left(-\frac{A\cdot(B-A)}{|B-A|^2},\,0,\,1\right),\qquad
d_{min} = \left|A + t\,(B-A)\right|
$$

3. 若 $d_{min} \le radius$ 判定为穿越。

判定优先级：端点在内（`pickup_inside` / `delivery_inside`）优先于航线穿越（`path_crosses`），同一个禁区只记一条违规。禁飞区半径通常只有几百米到几公里，局部等距近似的误差远小于判定裕度，而且不会像「逐点采样」那样漏掉细长的穿越。

### 输出示例

```text
$ python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11
==================================================
航线禁飞区检测
==================================================
取货点: (47.65000, -122.17000)
送货点: (47.65000, -122.11000)
检查禁飞区数量: 3
--------------------------------------------------
[WARNING] 航线穿越禁飞区【Airport】：距离中心 0.0 m（半径 2000 m）
```

两个端点离 Airport 中心都约 2.2 km（在 2 km 半径之外），但航线正好从中心穿过——这正是旧版本「只查端点」会漏掉的情况。

## 使用方法

单点检测 + 内置示例（纯 Python，无需 AirSim / ROS）：

    cd src/no_fly_zone_check
    python main.py

航线穿越检测：

    python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11
    python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11 --json

退出码：`0` = 安全，`1` = 存在违规；`--json` 输出机器可读结果（`safe` / `zones_checked` / `violations`）。

> AirSim 版本（`src/air/no_fly_zone_check`）保持原有单点检测逻辑；本次改动在 `src/no_fly_zone_check`。
