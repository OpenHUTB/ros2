# 轮速传感器 + 龙伯格观测器估计传动轴扭角

只有 ABS 齿圈能测到车轮转速时，能不能推出传动轴扭角？能——只要系统可观测，
本页给出观测器设计、可观测性判据，以及「带宽越高越快、但噪声也随之进得来」的量化权衡。

## 1. 问题

传动轴扭矩传感器贵且难装，工程上常用**电机转速（编码器）+ 车轮转速（ABS 齿圈）**
两个已知量反推轴上的扭角与扭矩，这就是观测器要解决的问题。

## 2. 模型与可观测性

```text
x1 = 轴扭转角 theta（rad）
x2 = 车轮转速 omega_w（rad/s）
u  = 电机转速 omega_m（rad/s，已知输入）
y  = omega_w（唯一量测）

x1' = u - x2
x2' = (k*x1 + c*(u - x2)) / Jw

A = [[0,-1],[k/Jw,-c/Jw]] = [[0,-1],[2000,-3.333]]
B = [[1],[c/Jw]]，C = [0,1]
能观性矩阵 [C; CA] = [[0,1],[2000,-3.333]]，det = -2000 ≠ 0 → 可观测
```

## 3. 观测器与参数选择

```text
x_hat' = A·x_hat + B·u + L·(y - C·x_hat)
```

`L` 用**对偶**方式求：把 `(Aᵀ, Cᵀ)` 当作受控对做 Ackermann，得到 `Lᵀ` 后转置。

| 带宽倍数 | wn (rad/s) | L=[l1, l2] | 观测器极点 | 收敛时间 | 噪声增益 ‖L‖ | 扭角 RMS |
| --- | --- | --- | --- | --- | --- | --- |
| 0.5 | 22.4 | [-0.750, 27.972] | -15.7±16.0j | 0.110 s | 27.98 | 0.00027 |
| 1.0 | 44.7 | [-0.000, 59.277] | -31.3±31.9j | 0.045 s | 59.28 | 0.00016 |
| 2.0 | 89.4 | [3.000, 121.886] | -62.6±63.9j | 0.040 s | 121.92 | 0.00013 |
| 3.0 | 134.2 | [8.000, 184.496] | -93.9±95.8j | 0.030 s | 184.67 | 0.00022 |

「收敛时间」= 扭角误差从 0.02 rad 收敛到 10% 的时间；「扭角 RMS」= 轮速叠加
σ=0.05 rad/s 白噪声后稳态段的误差 RMS。

**结论**：带宽越高收敛越快、`‖L‖` 单调增大；但扭角误差主要经 `l1` 进入，`l1` 在
基准带宽附近恰好接近 0，所以最干净的估计出现在「带宽适中」而不是「越高越好」。

## 4. 构建与运行

```bash
cd ~/ros2 && source /opt/ros/humble/setup.bash
colcon build --packages-select wheel_speed_observer && source install/setup.bash
ros2 launch wheel_speed_observer main.launch.py bandwidth_factor:=3.0
cd src/ground/wheel_speed_observer && python3 -m wheel_speed_observer.main
```

话题：订阅 `/drivetrain/motor_speed`、`/drivetrain/wheel_speed`，
发布 `/wheel_speed_observer/theta_hat` 与 `/wheel_speed_observer/status`。

## 5. 已知限制

1. 只保留扭振模态，假设电机转速准确已知；
2. 噪声按白噪声建模，未含齿圈加工的周期误差；
3. 观测器按连续时间设计，节点用 1 ms 步长积分，未分析离散化误差；
4. 未考虑极低速/零速时 ABS 齿圈丢脉冲；
5. 未做参数摄动鲁棒性验证。
