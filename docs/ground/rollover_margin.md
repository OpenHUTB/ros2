# 横向载荷转移与侧翻裕度

## 这一页解决什么问题

「这车会不会翻」听起来像仿真问题，准静态下其实只由三个参数决定：轮距、质心高度、质量。
本页给出纯代数、可断言、不依赖 CARLA 的实现，并把 SSF、临界加速度、内外侧轮垂向力、
极限车速算成具体数字，在终端里画出横向载荷条与车速扫描表。

## 模型

```
SSF     = track / (2·h_cg)              静态稳定因子
a_crit  = SSF · g                       侧翻临界侧向加速度
ΔF_z    = m · a_y · h_cg / track        横向载荷转移
F_inner = m·g/2 − ΔF_z
F_outer = m·g/2 + ΔF_z
v_max   = sqrt(a_crit · R)              给定半径的极限车速
```

两个自洽关系（也是断言的依据）：

- 抬轮发生在 `ΔF_z = m·g/2`，即 `a_y = a_crit`；
- `ΔF_z / F_z0` 恒等于 `a_y / a_crit`。

注意 `F_inner + F_outer = m·g` 始终成立（垂向力守恒），这是模型自检的第一条。

## 默认参数下的数字

车辆：轮距 `1.54 m`、质心高 `0.55 m`、质量 `1500 kg`；工况：半径 `30 m`、车速 `60 km/h`。

## 四条断言

| 断言 | 判据 | 失败意味着 |
|---|---|---|
| **侧翻裕度** | `a_y/a_crit ≤ rollover_margin`（默认 0.70） | 过弯太快或车太高 |
| **内侧轮载荷** | `F_inner > 0` | 已抬轮，准静态模型失效 |
| **极限车速** | `v ≤ sqrt(a_crit·R)` | 车速超过该半径的物理上限 |
| **载荷转移** | `|ΔF_z/F_z0 − a_y/a_crit| ≤ tolerance` | 模型实现不自洽 |

前三条描述安全性，第四条描述实现正确性 —— 所以抬高质心会让前三条一起翻，第四条依然通过。
这种「安全类断言联动、自洽类断言独立」的分工，正是把物理关系做成断言的价值。

## 两个反例

**反例一：裕度上限收到 0.5** —— 只翻第一条

```bash
roslaunch rollover_margin main.launch rollover_margin:=0.5
```

```
[FAIL] 侧翻裕度  a_y 9.259 m/s²，a_crit 13.734 m/s²，比值 0.674（上限 0.50）
断言：3 通过 / 1 失败
结论：FAILED
```

**反例二：质心抬到 0.90 m** —— 安全相关的三条一起翻

```bash
roslaunch rollover_margin main.launch cg_height:=0.90
```

```
SSF = 0.8556，侧翻临界加速度 8.393 m/s²（0.86 g）
[FAIL] 侧翻裕度  a_y 9.259 m/s²，a_crit 8.393 m/s²，比值 1.103（上限 0.70）
[FAIL] 内侧轮载荷  内侧轮 -759.4 N，外侧轮 15474.4 N（静态 7357.5 N）
[FAIL] 极限车速  当前 60.0 km/h，该半径极限 57.1 km/h（余量 -2.9 km/h）
[PASS] 载荷转移  ΔF_z/F_z0 = 1.1032，a_y/a_crit = 1.1032
断言：1 通过 / 3 失败

```

内侧轮载荷为负，物理含义是这一侧已经离地 —— 准静态模型到此为止。

## 常见问题

**Q：为什么不建模悬架与轮胎侧偏？**
A：准静态阈值主要由 `track/2h_cg` 决定，悬架柔度一般让实际阈值低 5~10%。本页要把公式
讲清楚，闭式解更容易校验；真车标定时把 `rollover_margin` 收到 0.6 即可覆盖这一偏差。

**Q：为什么「极限车速」和「侧翻裕度」会同时失败？**
A：二者物理同源：裕度到 1 时 `v = sqrt(a_crit·R)` 刚好达到。所以抬高质心会让它们一起翻，
这不是实现问题，而是模型的必然结论。

**Q：能不能直接给一个「安全车速」？**
A：可以，`safe_speed(margin)` 就是干这个的：默认裕度 0.7 时该车在该半径上的安全车速是
`61.1 km/h`（更保守的 0.5 对应 `51.7 km/h`）。
