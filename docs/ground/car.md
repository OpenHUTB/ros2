# 基于 ROS 与 MuJoCo 的悬崖边缘紧急制动仿真

## 一.项目简介
本项目基于 **MuJoCo** 物理引擎与 **ROS** 框架，实现了一个地面无人车（UGV）在行驶过程中的悬崖检测与紧急制动安全系统。通过模拟虚拟传感器数据，结合 ROS 话题通信，实现了高实时性的防跌落保护。

## 二.项目目录结构
```text
 src/
    └── ground/
        ├── CMakeLists.txt            # 编译配置文件
        ├── package.xml               # 依赖声明
        └── cliff_brake.py            # 核心代码
```

## 三.环境依赖
- Ubuntu 20.04 (或 18.04)
- ROS Noetic (或 Melodic)
- Python 3.8+
- MuJoCo (mujoco python bindings)
- rospy

## 四.编译与启动步骤
1.配置 Python 环境：确保安装 MuJoCo 和 ROS 依赖
 ```bash
 pip3 install mujoco
 ```
2.启动 ROS 核心服务
```bash
roscore
```
3.运行悬崖紧急制动仿真
```bash
python3 cliff_brake.py
```
4.运行成功界面


## 五.核心逻辑
1.物理仿真：利用 MuJoCo 构建带悬崖的地形与滑动底盘模型。

2.传感器模拟：通过实时读取底盘坐标，计算车头到悬崖边缘的“虚拟雷达距离”。

3.安全策略：当距离小于阈值（0.3m）时，通过 ROS 节点发布 /brake_status 话题，并强制执行紧急制动（施加反向力与阻尼）。

## 六.鲁棒性测试与后续展望
1.已验证：实现了基于距离阈值触发的紧急安全停障策略，成功避免了无人车跌落悬崖。

2.已验证：MuJoCo 物理引擎与 ROS 通信机制的完美融合，数据解耦清晰。

3.后续待优化（TODO）：目前为追求轻量化，底盘采用了滑动关节（Holonomic）。未来可接入真实轮胎的旋转关节，并加入轮胎打滑（Slip）物理模型，以验证在雨雪恶劣天气下的制动距离补偿。

4.待联调（未验证）：目前传感器为纯数学计算模拟，后续可接入 MuJoCo 内部的 raycast 射线检测接口，模拟真实激光雷达的物理反射。
