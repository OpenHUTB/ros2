# Sim-to-Real 域随机化（Domain Randomization）· MuJoCo

> 地面载具方向④：仿真里训练/标定的控制器直接搬到真实车往往失效（sim-to-real gap）。
> **域随机化**在训练时把物理参数做随机化，让控制器对真实环境参数差异鲁棒。
> 仿真平台：**MuJoCo**（渲染版）＋ **2D 轻量版**（本仓库可直接跑、出效果动图）。

![域随机化效果动图](img/ground/mujoco_domain_rand_demo.gif)

!!! note "与仓库已有模块的区别"

    本模块不做"在已知参数下把车控制好"，而是处理**仿真与真实的参数鸿沟（sim-to-real gap）**：

    * 已有 MuJoCo/其它模块大多假定车辆参数已知且固定，直接在仿真里整定控制器；
    * 本模块反向处理——真实车的质量/摩擦/电机增益与仿真不同，仿真标定的控制器会失效，
      用**域随机化**在真实参数分布上标定，让控制器对整段分布鲁棒。

## 1. 解决什么问题

**sim-to-real gap**：仿真里的车辆参数（质量 m、电机增益 k、阻力/摩擦 c）与真实车不同，
用仿真标称参数标定的控制器搬到真实车会严重失效——例如前馈指令按仿真阻力算，
真实阻力更大就"给力不足"、车速跟不上。

**域随机化（Domain Randomization, DR）**：不只用一套标称参数，而是在一组随机化的
参数分布（真实环境可能的范围）上反复训练/标定，使控制器对整段分布鲁棒。

本模块用一个最直观的例子展示：**前馈控制器 u = g·v_ref 的标定**。

- **标称标定** `g_nom = c0/k0`：只用仿真标称参数算，搬去真实参数立即失效；
- **域随机化标定** `g_dr`：在真实参数分布上采样，标定出对整段分布平均最优的增益。

小车被部署到一组"真实参数"（电机弱、阻力大，明显偏离仿真），对比两种标定的速度跟踪。

## 2. 文件结构

| 文件 | 说明 |
|------|------|
| `domain_rand_core.py` | **共享核心**：二阶动力学车辆、前馈控制器、域随机化采样器、标称/DR 标定与评估（只依赖 numpy） |
| `sim_2d_domain_rand.py` | 2D 轻量域随机化仿真，可直接运行并生成效果动图（真实跑出，核心与渲染版共用） |
| `mujoco_domain_rand.py` | **MuJoCo 渲染版**：在 MuJoCo 差速小车（可随机化质量/摩擦/电机增益）上评估标称 vs DR 前馈 |
| `README.md` / `requirements.txt` | 说明与依赖 |

## 3. 运行

### 3.1 2D 轻量版（可直接运行、出动图）

```bash
pip install -r requirements.txt
python3 sim_2d_domain_rand.py                     # 默认 240 帧 @30fps
python3 sim_2d_domain_rand.py --frames 300 --fps 20
```

### 3.2 MuJoCo 渲染版（需本机安装 mujoco）

```bash
pip install mujoco numpy
python3 mujoco_domain_rand.py
```

!!! note "沙箱限制声明"

    本仓库沙箱无 GPU / CARLA / ROS / Gazebo / MuJoCo，**渲染版无法在沙箱实跑**。
    上文动图由**共用同一算法核心的 2D 轻量版真实运行**产出；MuJoCo 渲染效果请在本机验证。

## 4. 结果

小车被部署到一组真实参数（电机弱×0.62、阻力大×2.50，明显偏离仿真标称 k0=1.2、c0=0.3）：

| 指标 | 标称标定 g_nom=0.250 | 域随机化标定 g_dr≈0.875 |
|------|--------------------|--------------------------|
| 速度跟踪 RMSE | **0.75 m/s**（车速只到参考的约 25%，严重滞后） | **0.27 m/s**（贴合参考速度） |
| 定位提升 | — | 约 **65%** |
| 位置(10 s 处) | 2.55 m（参考 11.24 m，大幅滞后） | 8.92 m（接近参考） |

在真实参数分布上评估（部署参数落在分布内）：域随机化标定**平均鲁棒性提升约 40%**，
绝大多数部署参数下 DR 明显优于标称标定。动图展示：标称前馈车沿路径严重滞后，
DR 前馈车贴合参考路径与速度剖面。
