# 麦克纳姆轮运动学推导

## 轮子布局

四轮布局（俯视图，x向前）：
- FL（左前）：x=+L, y=+W
- FR（右前）：x=+L, y=-W
- RL（左后）：x=-L, y=+W
- RR（右后）：x=-L, y=-W

参数：轮半径 r=0.08m，半长 L=0.18m，半宽 W=0.15m

## 逆运动学

底盘速度 (vx, vy, wz) → 四轮转速 (ω_FL, ω_FR, ω_RL, ω_RR)：

```
ω_FL = (1/r) * ( vx - vy - (L+W)*wz)
ω_FR = (1/r) * ( vx + vy + (L+W)*wz)
ω_RL = (1/r) * ( vx + vy - (L+W)*wz)
ω_RR = (1/r) * ( vx - vy + (L+W)*wz)
```

## 典型运动模式

| 运动 | vx | vy | wz | 四轮状态 |
|---|---|---|---|---|
| 前进 | 正 | 0 | 0 | 四轮同速正转 |
| 左横移 | 0 | 正 | 0 | FL/RR反转, FR/RL正转 |
| 原地左转 | 0 | 0 | 正 | FL/RL反转, FR/RR正转 |
