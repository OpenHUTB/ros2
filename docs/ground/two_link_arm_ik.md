# 二连杆机械臂正逆运动学（two_link_arm_ik）

演示平面二连杆机械臂的正向运动学与解析逆运动学：给定末端目标点，用余弦定理求出第二个关节角，再回代求第一个关节角，机械臂逐帧插值靠近目标。

## 环境

- Windows 11，Python 3.13.16，pygame 2.6.1

## 运行

见包内 README。

## 分层

- kinematics.py：正解、工作空间判定、解析逆解、关节限位裁剪与角度归一化。
- arm.py：机械臂状态机，逐帧插值到逆解结果，记录末端轨迹并按序切换目标。
- main.py：pygame 绘制基座、两段连杆、关节、末端轨迹与待达目标。

## 逆解思路

目标点距离为 r 时，第二关节角满足 cos(q2) = (r^2 - l1^2 - l2^2) / (2*l1*l2)，取肘部向上为正解；第一关节角由目标方位角减去连杆几何构成的偏角得到。r 超出 |l1-l2| 到 l1+l2 区间即判定为不可达。

## 实测结果

本地复跑：177 步依次抵达全部 4 个目标点，末端最终误差 0.00 px。

## 限制

- 纯二维几何演示，没有动力学与力矩，不考虑重力、惯量与碰撞。
- 插值按固定比例推进，不是时间最优轨迹。
