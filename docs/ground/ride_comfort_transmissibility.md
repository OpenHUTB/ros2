# 乘坐舒适性传递率

路面不是平的。同一辆车，40 km/h 过某段路很难受，60 km/h 反而平稳 —— 这不是错觉，
是**悬架对不同频率的输入放大倍数不同**。把这件事算清楚，就是本模块要讲的传递率。

这个模块用纯标准库实现一个单自由度悬架模型，给出共振在哪个频率、放大多少倍、
按 ISO 2631-1 属于哪个舒适度等级，并用四条断言把「算得对不对」钉住。
不需要 CARLA、不需要显示器、不需要 numpy，Ubuntu 18.04 + ROS Melodic 直接可跑。

## 一、为什么需要这个包

仓库里 `src/ground/` 下的地面载具模块，纵向有 `braking_distance_check`、横向有
`rollover_margin` 与 `lateral_stability_margin`，**垂直方向是空白**：

| 方向 | 已有模块 | 管什么 |
|---|---|---|
| 纵向 | `braking_distance_check` | 反应距离 + 制动距离 |
| 横向（侧翻） | `rollover_margin` | 载荷转移与临界车速 |
| 横向（转向） | `lateral_stability_margin` | 不足转向梯度与特征车速 |
| 执行器 | `steering_actuator_lag` | 转向机构的一阶滞后 |
| **垂直** | **本模块** | **悬架传递率、共振、舒适度等级** |

一条真实的工程链条是：悬架把路面震动放大到人体 → 人难受 → 驾驶员反应变慢 →
制动距离变长。前面三个模块都假设「驾驶员状态正常」，本模块补上这个前提被破坏时的量化依据。

## 二、模型

单自由度基础激励（只看垂直方向，忽略俯仰与侧倾耦合）：

```
r     = f / f_n                                          频率比（激励频率 / 固有频率）
T(r)  = sqrt((1 + (2ζr)²) / ((1 − r²)² + (2ζr)²))        位移传递率
a_w   = T(r) · a_in                                      加权加速度 RMS
```

三个解析结论：

```
峰值位置   r_p = sqrt(1 − 2ζ²)
峰值大小   T_p = sqrt((1 + 4ζ²(1−2ζ²)) / (4ζ²(1−ζ²)))
低频/高频  T(0) = 1；T(∞) = 0
```

**峰值不在 r = 1**。r = 1 处 `T = sqrt(1+(2ζ)²)/(2ζ)`，ζ = 0.25 时是 2.236；
真正的极值在 r_p = 0.935，峰值 2.280，高出约 2%。阻尼越大偏得越多。

`damping` 被限制在 `(0, 1/√2)`：超过 0.7071 后 `sqrt(1−2ζ²)` 无实数意义，闭式峰位失效，
程序直接抛 `RideError`，而不是给一个错的数。现实里的悬架阻尼比也不会到 0.8。

舒适度等级（ISO 2631-1，`a_w` 单位 m/s² RMS）：

| a_w 区间 | 等级 |
|---|---|
| < 0.315 | 舒适 |
| 0.315 ~ 0.63 | 略有不适 |
| 0.63 ~ 1.0 | 不适 |
| 1.0 ~ 1.6 | 很不适 |
| 1.6 ~ 2.5 | 极不适 |
| > 2.5 | 无法忍受 |

## 三、四条断言

| 断言 | 判据 | 默认实测 | 结果 |
|---|---|---|---|
| 共振位置 | 扫描峰位与 `sqrt(1−2ζ²)` 的偏差 ≤ 0.02 | 偏差 0.0132 | PASS |
| 峰值倍率 | 扫描峰值与闭式峰值的相对偏差 ≤ 5% | 偏差 0.0012（0.12%） | PASS |
| 高频衰减 | `T(r=10) ≤ 0.1` | 0.051440 | PASS |
| 输入线性 | 输入加倍后 `a_w` 精确加倍 | 相对偏差 0.0000 | PASS |

四条互相独立：位置管「峰在哪」、倍率管「峰多高」、衰减管「隔振行不行」、
线性管「叠加原理成不成立」。任何一条失败都能定位到具体环节。

## 四、默认数字

参数：`fn_hz = 1.2`、`damping = 0.25`、`input_accel = 0.5`、`freq_hz = 6.0`

| 项 | 值 |
|---|---|
| 理论峰位 / 峰值 | **0.935414 / 2.280351** |
| 扫描峰位 / 峰值 | 0.948625 / 2.283149 |
| r = 1 处传递率 | 2.236068 |
| r = 10 处传递率 | 0.051440 |
| 6 Hz 处加权加速度 | 0.055794 m/s² → 等级「舒适」 |

| r | f Hz | T | a_w m/s² |
|---|---|---|---|
| 0.25 | 0.300 | 1.066 | 0.533 |
| 0.50 | 0.600 | 1.304 | 0.652 |
| 0.75 | 0.900 | 1.853 | 0.927 |
| 1.00 | 1.200 | 2.236 | 1.118 |
| 1.25 | 1.500 | 1.402 | 0.701 |
| 1.50 | 1.800 | 0.857 | 0.429 |
| 2.00 | 2.400 | 0.447 | 0.224 |

| 5.00 | 6.000 | 0.112 | 0.056 |

`r ≤ 1.5` 时 T > 1（放大），`r ≥ 2` 后迅速掉下来（隔振）。这就是过减速带要慢、

## 七、运行

```bash
mkdir -p ~/catkin_ws19/src/ground ~/catkin_ws19/tests ~/catkin_ws19/docs/ground
# 把包放进来，改 shebang，catkin_make，source，roslaunch
roslaunch ride_comfort_transmissibility main.launch
```

默认输出 `结论：PASSED`。两个反例：

```bash
# ① 容差收到 0.001：扫描精度不够，只翻「共振位置」
roslaunch ride_comfort_transmissibility main.launch pos_tolerance:=0.001

# ② 阻尼 0.02（坏减振器）+ 激励挪到 1.2 Hz：峰值 25 倍，等级「无法忍受」
roslaunch ride_comfort_transmissibility main.launch damping:=0.02 freq_hz:=1.2
```

反例②值得多看一眼：四条断言**全部通过**（物理上它自洽），但舒适等级从「舒适」
变成「无法忍受」。**断言管的是「算得对不对」，等级管的是「人坐着难受不难受」** ——
两者不能互相替代，这也是我特意把等级做成独立输出的原因。

## 九、与已有模块的分工

前面第一节的表已经列了纵向/横向/执行器/垂直四块。补一句边界：
`steering_actuator_lag` 也是「频率响应」，但它是**转向机构**的一阶惯性；
本模块是**悬架**的二阶共振。两者都有「频率越高越跟不上」，但物理对象、微分方程阶数、
关心的频段完全不同（转向 2~10 Hz，车身 1~2 Hz）。

## 十、常见问题

**1. 为什么峰值不在 r = 1？**
因为 r = 1 只是「分母实部为 0」的位置，不是传递率对 r 的极值点。
`T(1) = sqrt(1+(2ζ)²)/(2ζ)`，极值点在 `r = sqrt(1−2ζ²)`，ζ = 0.25 时差 1.3%。
判据里写「峰位」而不是直接拿 r = 1 当峰，就是为了不让这个偏差蒙混过去。

**2. 为什么 `damping:=0.8` 直接报错？**
超过 `1/√2 ≈ 0.7071` 后曲线没有经典共振峰，`sqrt(1−2ζ²)` 是虚数。
与其返回一个错的峰位，不如判参数非法。测试 G15 就是查这个事情。

**3. 高通/低通行为怎么读？**
`r → 0` 时 `T → 1`（车身跟着路面一起动，等于没悬架）；`r → ∞` 时 `T → 0`
（高频震动被滤掉）。所以舒适性设计的目标是：把共振峰挪到人最不敏感的低频、
同时把峰压下去 —— 后者靠加阻尼，前者靠改固有频率（也就是改悬架刚度与簧上质量）。
