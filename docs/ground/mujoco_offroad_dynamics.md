# 车辆动力学与越野地形（ABS 制动对比）· MuJoCo

> 地面载具方向⑤：车辆动力学 + 越野地形。核心展示**轮胎滑移**与 **ABS（防抱死制动）**：
> 在低摩擦越野路面（泥地/雪地）上，无 ABS 制动会因车轮锁死打滑而失效，
> ABS 通过滑移率控制始终用足峰值摩擦，显著缩短制动距离。
> 仿真平台：**MuJoCo**（渲染版）＋ **2D 轻量版**（本仓库可直接跑、出效果动图）。

![越野地形 ABS 制动对比动图](img/ground/mujoco_offroad_dynamics_demo.gif)

!!! note "与仓库已有模块的区别"

    本模块侧重**轮胎-地面摩擦的动力学**，而不是路径跟踪/感知：

    * 已有地面载具模块大多是几何/感知层面的路径跟踪（纯跟踪、感知避障）或
      视觉任务；本模块把路面摩擦、轮胎滑移率、制动力这几件物理本质显式建模；
    * 通过「无 ABS（轮锁死打滑）vs ABS（滑移率控制）」的对比，展示主动安全
      控制如何在低摩擦越野路面上用足轮胎抓地力、缩短制动距离。

## 1. 解决什么问题

**轮胎滑移**：车轮"锁死"（不再滚动，λ→1）时，轮胎与地面摩擦会从峰值 μ_peak
掉到更低的滑动摩擦 μ_slip，制动力减弱、车辆打滑滑行，且失去转向能力。
在低摩擦越野路面（泥、雪）上这一失效尤其严重。

**ABS（防抱死制动）**：实时监测滑移率 λ=(v−v_w)/v，把 λ 控制在峰值摩擦对应的
λ_opt≈0.2 附近。这样制动全程用足可用摩擦——制动距离最短、转向可控。

本模块用同一辆越野车在「干路→泥地→雪地→上坡」路面上紧急制动，对比：

- **无 ABS**：制动压力拉满 → 轮锁死 λ≈1 → 滑动摩擦打滑，制动距离长；
- **ABS**：滑移率控制 → 峰值摩擦，制动距离短、稳定停车。

## 3. 运行

### 3.1 2D 轻量版（可直接运行、出动图）

```bash
pip install -r requirements.txt
python3 sim_2d_offroad_dynamics.py                     # 默认 240 帧 @30fps
python3 sim_2d_offroad_dynamics.py --v0 35 --frames 300
```

### 3.2 MuJoCo 渲染版（需本机安装 mujoco）

```bash
pip install mujoco numpy
python3 mujoco_offroad_dynamics.py
```

!!! note "沙箱限制声明"

    本仓库沙箱无 GPU / CARLA / ROS / Gazebo / MuJoCo，**渲染版无法在沙箱实跑**。
    上文动图由**共用同一算法核心的 2D 轻量版真实运行**产出；MuJoCo 渲染效果请在本机验证。

## 4. 结果

同一辆越野车（m=1500 kg）以 v0=30 m/s 在越野路面（干路 μ0.9→泥地 μ0.5→雪地 μ0.3→上坡）紧急制动：

| 指标 | 无 ABS（轮锁死打滑） | ABS（滑移率控制） |
|------|--------------------|-------------------|
| 制动距离 | **140 m**（11.4 s） | **76 m**（6.1 s） |
| 缩短比例 | — | 约 **46%** |
| 滑移率 | λ≈1.0（全程锁死，滑动摩擦） | λ≈0.2～0.3（峰值摩擦附近） |
| 停车位置 | 滑过雪地、到上坡段才停稳 | 泥地即停稳 |

物理机理：无 ABS 时轮胎摩擦掉到滑动摩擦（约 0.6×峰值），低摩擦路面打滑；
ABS 把滑移率维持在峰值附近，全程用足可用摩擦，制动距离大幅缩短。
