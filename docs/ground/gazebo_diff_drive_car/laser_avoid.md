## 2.2 传感器配置

### 2.2.1 激光雷达规格

采用 Hokuyo URG-04LX 风格的 2D 激光雷达：

| 参数 | 值 | 说明 |
|---|---|---|
| 类型 | `ray`（射线型） | Gazebo 传感器类型 |
| 光束数 | 360 | 每帧 360 个距离量测 |
| 角度范围 | $[-\pi, +\pi]$ | 360° 全向扫描 |
| 角分辨率 | $2\pi/360 = 0.01745$ rad | 约 1° |
| 量程 | 0.12 ~ 5.6 m | 超出范围返回 `inf` |
| 扫描频率 | 10 Hz | 每 100 ms 一帧 |
| 噪声 | 高斯，$\sigma = 0.01$ m | 模拟真实传感器噪声 |
| 安装位置 | 车头前方 0.28 m，高度 0.35 m | 略超出车体轮廓 |
| ROS 话题 | `/scan` | `sensor_msgs/LaserScan` |

### 2.2.2 安装位置的设计要点

雷达需置于**车体轮廓之外**，否则激光会扫到自身车体，
在正前方产生虚假的近距离回波（**自遮挡**）。

本模型将雷达前移至车头前方 0.06 m 处（$x = L_{\text{chassis}}/2 + 0.06 = 0.28$ m），
略超出车体边界。但即使如此，仍可能扫到天线、线缆等凸出物，
因此算法层还需额外的自遮挡过滤（见 2.4.3 节）。

### 2.2.3 数据格式

`sensor_msgs/LaserScan` 的核心字段：

| 字段 | 含义 |
|---|---|
| `angle_min` / `angle_max` | 扫描起止角 (rad) |
| `angle_increment` | 相邻光束的角度间隔 (rad) |
| `range_min` / `range_max` | 有效量程 (m) |
| `ranges[]` | 各光束距离数组 (float32)，长度 360 |
| `frame_id` | 坐标系名，本车为 `laser_link` |

第 $i$ 束激光对应的角度为：

$$
\theta_i = \theta_{\min} + i \cdot \Delta\theta
$$

## 2.4 感知层

### 2.4.1 有效性过滤

激光雷达输出的原始数据包含三类无效值：

| 值 | 含义 | 处理 |
|---|---|---|
| `inf` | 该方向无回波（超出量程） | 剔除 |
| `nan` | 传感器异常或无回波 | 剔除 |
| $r < r_{\min}$ | 小于最小量程（0.12 m），通常是噪声 | 剔除 |

```python
if not (r == r) or r == float("inf") or r == float("-inf"):
    continue                       # 剔除 nan / inf
if r < scan.range_min:
    continue                       # 剔除过近噪声
```

> `r == r` 是检测 `nan` 的惯用技巧：IEEE 754 规定 `nan != nan`。

### 2.4.2 五扇区划分

将 $[-\pi, \pi)$ 划分为 5 个扇区，用于判断各方向的通行性：

```
                        前方 front
                     [-30°, +30°]
                          ▲
                          │
        left              │              right
     [+30°,+90°]          │           [-90°,-30°]
            ╲             │             ╱
              ╲           │           ╱
                ╲         │         ╱
                  ╲       │       ╱
                    ╲     │     ╱
                      ╲   │   ╱
                        ╲ │ ╱
     ─────────────────────●─────────────────────  ← 车辆
                        ╱ │ ╲
                      ╱   │   ╲
                    ╱     │     ╲
                  ╱       │       ╲
                ╱         │         ╲
              ╱           │           ╲
            ╱             │             ╲
        left_bk           │           right_bk
     [+90°,+180°]         │        [-180°,-90°]
```

| 扇区 | 角度范围 | 物理含义 |
|---|---|---|
| `front` | $[-30°, +30°]$ | 正前方（决定能否直行） |
| `left` | $[+30°, +90°]$ | 左前方 |
| `right` | $[-90°, -30°]$ | 右前方 |
| `left_bk` | $[+90°, +180°]$ | 左后方 |
| `right_bk` | $[-180°, -90°]$ | 右后方 |

**每个扇区取最小距离**，而非平均值。

**为什么取最小值？** 避障决策关心的是"最近威胁"而非平均距离。
均值会被远处的空旷区域稀释，导致对近处障碍不敏感。例如前方
$-30°$ 处有 0.3 m 的障碍，其余 59° 都是 5.6 m 空旷，则：

- 均值 = $(0.3 + 59 \times 5.6) / 60 \approx 5.5$ m → **误判为安全**
- 最小值 = 0.3 m → **正确识别危险**

### 2.4.3 自遮挡过滤（关键工程处理）

**问题**：即使雷达安装在车体轮廓之外，仍可能扫到车体边缘、天线或线缆，
在某个固定角度上产生**恒定的近距离回波**。

实测现象：车辆处于空旷位置时，正前方仍持续返回 0.12 ~ 0.40 m 的
虚假回波，导致算法误判"前方被堵死"，车辆原地打转。

**解决方案：邻域连续性校验**

真实障碍会**连续遮挡多束激光**，而车体自遮挡只影响少数几束。
据此可以区分二者：

```
      真实障碍（连续多束被遮挡）          自遮挡（孤立少数束）
      ────────────────────────          ──────────────────

  距离 │    ╱╲                         距离 │      ╱╲
       │   ╱  ╲                             │     ╱  ╲
       │  ╱    ╲╲╲╲╲  ← 连续近距            │    ╱    ╲  ╱╲ ← 孤立尖峰
       │ ╱                                │   ╱      ╲╱  ╲
       └────────────────▶ 光束索引         └────────────────▶ 光束索引
           判定：保留                            判定：剔除
```

**判定规则**：对每个距离小于 `SELF_OCCLUSION_RANGE`（0.30 m）的光束，
检查其邻域 $\pm 5$ 束内是否也有同样近的回波：

- 邻域内近距光束数 $\geq$ `MIN_CLOSE_HITS`（5）→ **真实障碍，保留**
- 否则 → **自遮挡噪声，剔除**

```python
hits = 0
for off in range(-MIN_CLOSE_HITS, MIN_CLOSE_HITS + 1):
    j = idx + off
    if 0 <= j < n and valid_beams[j][1] < SELF_OCCLUSION_RANGE:
        hits += 1

if hits >= MIN_CLOSE_HITS:
    filtered.append((theta, r))    # 真实障碍
# 否则丢弃（自遮挡噪声）
```

## 2.5 决策层：有限状态机

### 2.5.1 状态定义

```
                        ┌──────────────┐
        d_front > d_clear│    CRUISE    │ 全速直行
              ┌─────────│    （巡航）   │
              │         └──────┬───────┘
              │                │ d_front < d_safe
              │                ▼
              │         ┌──────────────┐
              │         │    AVOID     │ 减速 + 转向
              │         │  （避障转向） │
              │         └──────┬───────┘
              │                │ d_front < d_danger
              │                ▼
              │         ┌──────────────┐
              └─────────│  EMERGENCY   │ 后退 + 转向
                        │  （紧急脱困） │
                        └──────────────┘
                              │ 持续 EMERGENCY_HOLD
                              ▼
                        重新评估前方
```

### 2.5.2 状态转移条件

| 当前状态 | 转移条件 | 下一状态 | 动作 |
|---|---|---|---|
| CRUISE | $d_{\text{front}} < d_{\text{safe}}$ | AVOID | 减速并转向 |
| AVOID | $d_{\text{front}} > d_{\text{clear}}$ | CRUISE | 恢复巡航 |
| AVOID | $d_{\text{front}} < d_{\text{danger}}$ | EMERGENCY | 后退脱困 |
| EMERGENCY | 保持 $< 0.8$ s | EMERGENCY | 持续后退 |
| EMERGENCY | 超时且 $d_{\text{front}} > d_{\text{clear}}$ | CRUISE | 恢复巡航 |
| EMERGENCY | 超时且前方仍近 | AVOID | 转为避障转向 |

### 2.5.3 滞回设计（抖动抑制）

**问题**：若进入与退出避障使用同一阈值，当距离在阈值附近波动时，
状态机会高频反复切换，导致转向抖动。

**解决方案：滞回（hysteresis）**

```
     距离
       │
  1.4  ┤─────────────────────────────  d_clear（退出避障阈值）
       │         ▲
       │         │  滞回带
       │         ▼
  1.0  ┤─────────────────────────────  d_safe（进入避障阈值）
       │
       └──────────────────────────────▶ 时间
              进入          退出
```

- **进入** AVOID 需要 $d < d_{\text{safe}} = 1.0$ m
- **退出** AVOID 需要 $d > d_{\text{clear}} = 1.4$ m

滞回带宽 0.4 m，有效抑制了临界振荡。

### 2.5.4 状态参数

| 参数 | 值 | 说明 |
|---|---|---|
| $d_{\text{safe}}$ | 1.0 m | 进入避障阈值 |
| $d_{\text{clear}}$ | 1.4 m | 退出避障阈值 |
| $d_{\text{danger}}$ | 0.45 m | 紧急后退阈值 |
| `EMERGENCY_HOLD` | 0.8 s | 紧急状态最小时长 |

## 2.6 控制层：势场法

### 2.6.1 转向方向选择

转向方向由左右两侧的**可通行度之差**决定：

$$
\Delta = d_{\text{left}} - d_{\text{right}}
$$

- $\Delta > 0$ → 左侧更空旷，应**左转**
- $\Delta < 0$ → 右侧更空旷，应**右转**

其中：

$$
d_{\text{left}} = \min(d_{left},\; d_{left\_bk}), \qquad
d_{\text{right}} = \min(d_{right},\; d_{right\_bk})
$$

取前后两个扇区的最小值，保证考虑的是整个侧向的通畅程度。

### 2.6.2 角速度生成

角速度大小与 $\Delta$ 成正比（带饱和），使转向平缓自然：

$$
\omega = k_\omega \cdot \text{clamp}\!\left(\frac{\Delta}{2.0},\; -1,\; +1\right)
$$

归一化分母 2.0 m 的作用：避免远距离处（如两侧都是 5.6 m 量程上限时
$\Delta = 0$）增益过大。参数 $k_\omega = 1.8$。

### 2.6.3 最小转向力度

若 $\omega$ 过小，车辆可能贴着障碍面平移而不真正转开。因此设定下限：

$$
|\omega| < \omega_{\min} \Rightarrow \omega = \pm \omega_{\min}
$$

其中 $\omega_{\min} = 0.45$ rad/s。

### 2.6.4 线速度衰减

线速度随前方障碍接近程度**线性衰减**，保证"越接近障碍开得越慢"：

$$
v = v_{\text{avoid}} \cdot \text{clamp}\!\left(
    \frac{d_{\text{front}} - d_{\text{danger}}}{d_{\text{safe}} - d_{\text{danger}}},\;
    0,\; 1\right)
$$

```
    v (m/s)
      │
  0.18├────────●
      │        │╲
      │        │ ╲
      │        │  ╲
    0 ├────────┼───●────────▶ d_front (m)
             0.45  1.0
           d_danger d_safe
```

### 2.6.5 死胡同处理

若左右两侧均低于 $d_{\text{safe}}$（如进入窄巷尽头），则**原地最大角度转向**
寻找出路：

$$
\max(d_{\text{left}}, d_{\text{right}}) < d_{\text{safe}}
\Rightarrow
\begin{cases}
v = 0 \\
\omega = \pm \omega_{\max}
\end{cases}
$$

### 2.6.6 控制参数汇总

| 参数 | 值 | 说明 |
|---|---|---|
| $v_{\text{cruise}}$ | 0.35 m/s | 巡航线速度 |
| $v_{\text{avoid}}$ | 0.18 m/s | 避障最大线速度 |
| $v_{\text{back}}$ | −0.12 m/s | 紧急后退速度 |
| $\omega_{\min}$ | 0.45 rad/s | 最小角速度 |
| $\omega_{\max}$ | 1.30 rad/s | 最大角速度 |
| $k_\omega$ | 1.8 | 转向增益 |

### 2.7.3 主循环 update()

```python
def update(self):
    # ① 取最新雷达帧
    with self._scan_lock:
        scan = self._scan
    if scan is None:
        self._watchdog.feed(Twist())   # 无数据时保持静止
        return

    self.stats["scans"] += 1

    # ② 感知：扇区划分（含自遮挡过滤）
    sectors = self._extract_sectors(scan)

    # ③ 决策：有限状态机
    state, sectors = self._decide(sectors)

    # ④ 控制：生成速度指令
    cmd = self._compute_command(state, sectors)

    # ⑤ 输出至看门狗（内部完成 publish）
    self._watchdog.feed(cmd)
```

### 2.7.4 统计信息

节点在退出时输出运行统计，用于性能评价：

self.stats = {

    "emergency_count": 0,   # 紧急脱困次数
    "min_front": float("inf"),  # 历史最近前方距离
}
