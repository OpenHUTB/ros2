# 刹车距离核算

## 这一页解决什么问题

跟车太近、雨天不减速、下坡不提前刹车，本质都是同一个问题：**没人算过「以这个速度，从看见到停住要多少米」**。

这个公式（反应距离 + 制动距离）在驾校教材里就有，但工程里它通常散落在设计文档的几张表格里，换个车速、换个路面就得重查。本页给出一个纯物理、纯标准库的实现：输入车速、反应时间、附着系数与坡度，直接算出三个可加和的量，并用四条断言判断这次跟车/接近是否安全。

> 本页原来只有一条参考链接。下面的实现是在同一主题下补的：**不依赖 CARLA、不需要 GPU、不需要显示器**，一条命令在终端出结果，方便在没有仿真环境的机器上做回归。

### 公式

| 量 | 公式 | 默认工况下（50 km/h、μ = 0.70、反应 1 s） |
|---|---|---|
| 初速换算 | `v0 = speed_kmh / 3.6` | 13.889 m/s |
| 反应距离 | `v0 * t_r` | 13.89 m |
| 制动减速度 | `a = μ g cosθ + g sinθ` | 6.87 m/s² |
| 制动距离 | `v0² / (2a)` | 14.05 m |
| 停车距离 | `反应距离 + 制动距离` | 27.93 m |
| 刹停耗时 | `v0 / a` | 2.02 s |
| 两秒法则车距 | `v0 * 2 + 余量(3 m)` | 30.78 m |

两点值得注意：

1. **制动距离与速度是平方关系。** 50 → 100 km/h 时制动距离从 14.05 m 涨到 56.18 m（四倍），完整对照见下文的速度表。这就是「高速上一脚刹车根本不够」的算术解释。
2. **坡度直接进减速度。** 上坡时 `g sinθ` 帮忙，下坡时变成负数。默认 0 度，所以只剩 `μ g`。

### 四条断言

| 断言 | 判据 | 不过时的含义 |
|---|---|---|
| 停车距离 | 停车距离 ≤ 前方可用距离 | 到前车/障碍物之前停不住 |
| 跟车间距 | 车距 ≥ 两秒法则要求 | 跟得太紧，前车急刹就追尾 |
| 路面附着 | `μ ≥ 0.30` | 雪/冰/积水路面，物理上就停不住 |
| 限速 | 车速 ≤ 路段限速 | 超速 |

四条互相独立：换一个参数只会让相关的那条翻转，便于定位到底是哪里不够。

### 参数表

| 参数 | 默认 | 说明 |
|---|---|---|
| `scene/speed_kmh` | 50.0 | 当前车速 |
| `scene/available_distance` | 40.0 | 前方可用距离（到前车或障碍物） |
| `scene/gap` | 32.0 | 当前跟车间距 |
| `vehicle/reaction_time` | 1.00 | 反应时间（含抬脚换踏板） |
| `vehicle/speed_limit_kmh` | 60.0 | 该路段限速 |
| `road/friction` | 0.70 | 附着系数：干沥青 0.7~0.9、湿 0.4、雪 0.2、冰 0.1 |
| `road/slope_deg` | 0.0 | 坡度，正为上坡 |
| `rate/publish_hz` | 1.0 | 报告重发频率 |
| `topic/report` | `/braking/report` | 报告话题（`std_msgs/String`） |
| `topic/bars` | `/braking/bars` | 距离字符条话题（`std_msgs/String`） |

### 话题表

| 话题 | 类型 | 方向 | 说明 |
|---|---|---|---|
| `/braking/report` | `std_msgs/String` | 发布（latched） | 距离分解 + 四条断言 + 车速对照表 |
| `/braking/bars` | `std_msgs/String` | 发布（latched） | 一条字符条：`=` 反应距离、`#` 制动距离、`-` 前方尚可用 |

### 反例

```bash
# 雨天：附着系数从 0.70 掉到 0.35，制动距离翻倍
roslaunch braking_distance_check main.launch friction:=0.35
```

`停车距离` 一条翻转：`[FAIL] 停车距离 需要 41.98 m，前方可用 40.00 m`（减速度只剩 3.43 m/s²，刹停要 4.05 s）。

```bash
# 跟车太近：车距 32 m → 20 m
roslaunch braking_distance_check main.launch gap:=20
```

`跟车间距` 一条翻转：`[FAIL] 跟车间距 当前 20.00 m，两秒法则要求 30.78 m`。

也就是说：**同一次运行里，每个失败都指向一个具体的物理量**，而不是笼统的「不安全」。

### 常见问题

**为什么默认车距是 32 m，不是整数 30 m？**
50 km/h 下两秒法则要求 `13.889 × 2 + 3 = 30.78 m`，30 m 会直接判失败。把默认值放在 32 m 是为了让「默认工况通过、调小参数才失败」这个对照成立。

**附着系数取多少才合理？**
干沥青 0.7~0.9、湿沥青 0.4、压实雪 0.2、冰面 0.1。本模块把 `μ < 0.30` 直接判为不安全（雪天以下就不要谈刹停了）。

**为什么制动距离用 v²/(2a) 而不是查表？**
这是匀减速的解析解：`v² = 2as`。只要减速度恒定，结果与车型无关，所以它可以手算复核——本模块的离线测试里就有几条是手算对照的。

**Melodic 上会看到 `UnicodeEncodeError` 吗？**
不会。所有日志先编码成 byte str 再交给 `rospy.loginfo`（`braking_node.py` 的 `_log()`）。
