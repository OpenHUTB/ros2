# MuJoCo 双车自动跟车

## 简介

在 MuJoCo 物理仿真环境中实现**地面双车自动跟车**：前车（蓝色）沿直线大幅变速行驶，后车（橙色）通过读取前车位置计算车间距，自动调整自身速度跟随前车，保持约 1.2 m 的车距。整个过程中两车都不转向、不翻车，仅通过车速调节完成跟车。

## 控制原理

- **前车（leader）**：速度按正弦规律大幅变化（2.1 s 一个周期，约 0.05 ~ 1.15 m/s），模拟真实道路上车辆加减速场景。
- **后车（follower）**：
  1. 通过 `qpos` 读取前车 x 坐标和后车 x 坐标，计算车间距 `gap`；
  2. 控制目标为 `前车速度 + 8 × (gap − 1.2)`，即以前车速度为**前馈**、以车距误差为**反馈**的比例控制；
  3. 对目标速度做一阶低通滤波（系数 0.003，约 0.67 s 延迟），模拟后车驾驶员反应滞后，产生真实的"追赶—拉开"动态；
  4. 最终左右轮同速输出，后车不转向，只靠调速保距。

## 输出说明

运行后终端实时打印：

```
step=... lead_x=... follow_x=... gap=... lead_ctrl=... f_ctrl=...
```

- `lead_x`：前车位置
- `follow_x`：后车位置
- `gap`：车间距（期望 1.2 m，实际稳定在 1.0 ~ 1.3 m 附近）
- `lead_ctrl` / `f_ctrl`：前车 / 后车轮速指令

## 设计亮点

- 双车跟车在仓库中为全新选题（仓库此前仅有单车巡航、无人机编队、视觉追踪等，无地面双车保距跟车模块）；
- 控制简单稳定：不涉及转向，物理参数沿用已验证组合（轮摩擦 2.5、执行器力限 ±100），不会翻车、不会追尾；
- 加入反应延迟滤波，跟车过程具有真实驾驶的动态感。
