# 差速底盘驱动系统选型核算

给差速底盘配电机和减速箱时，第一件事是把轮端的受力算清楚：一台车在「上坡 + 匀加速 + 巡航风阻」
同时取满的保守工况下，每只驱动轮需要多少转矩、多少转速、多少电功率，然后才能谈电机选型和减速比。
选小了爬坡过热，选大了背着死重——本模块把这三步写成可以手算核对的公式，只依赖 Python 标准库。

## 默认样机结论

默认参数：12 kg 底盘、轮半径 0.06 m、2 轮驱动、滚动阻力系数 0.03、10° 坡、加速度 1 m/s²、
巡航 1.5 m/s、风阻系数 0.8、迎风面积 0.06 m²、传动效率 0.85、旋转惯量系数 1.08、
备选电机持续转矩 1.2 N·m / 峰值 2.5 N·m / 额定 4000 rpm、母线 24 V。

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 滚动阻力 | 3.53 N | f·m·g |
| 坡度阻力 | 20.43 N | 10° 坡上占大头 |
| 加速阻力 | 12.96 N | m·a·k_rot |
| 风阻（1.5 m/s） | 0.066 N | 小车速度低，风阻可忽略 |
| 合计牵引力 | 36.99 N | 保守工况叠加 |
| 每轮转矩 | 1.306 N·m | F·r/n_driven/η |
| 巡航轮速 | 238.7 rpm | v/(2πr)·60 |
| 每轮电功率 | 32.64 W | 母线电流 1.36 A/轮 |
| **直接驱动** | **1.536 N·m（注意）** | 超过电机持续转矩 1.2 N·m，短时可过载 |
| **按额定转速配箱** | **减速比 16.76，电机转矩 0.092 N·m（正常）** | 落在持续能力内 |

结论一句话：这套 12 kg 底盘**不适合直接驱动**——直接连轮子，爬 10° 坡时需求转矩 1.536 N·m 已经
超过 1.2 N·m 的持续转矩，只能短时过载；按电机额定 4000 rpm 配 16.76 的减速箱后，电机侧只需
0.092 N·m，选型余量立刻回来。这正是「减速箱不是降速用的，是换转矩用的」。

## 2. 公式

```text
滚动阻力    F_roll  = f * m * g
坡度阻力    F_grade = m * g * sin(theta)
加速阻力    F_accel = m * a * k_rot           k_rot 计入轮/转子旋转惯量, 典型 1.05~1.15
风阻        F_drag  = 0.5 * rho * Cd * A * v^2
总牵引力    F       = F_roll + F_grade + F_accel + F_drag(v_cruise)

每轮转矩    tau_wheel = F * r / n_driven / eta
巡航轮速    rpm       = v / (2*pi*r) * 60
每轮电功率  P         = F * v / n_driven / eta
减速比      ratio     = rpm_motor_rated / rpm
电机侧转矩  tau_motor = tau_wheel / (ratio * eta)
母线电流    I         = P / U
```

## 3. 判定阈值

| 量 | 阈值 | 含义 |
| --- | --- | --- |
| 需求转矩 vs 持续转矩 | ≤ 持续 正常；≤ 峰值 注意（短时过载）；> 峰值 超限 | 持续爬坡/巡航必须落在持续转矩内 |
| 直接驱动 vs 减速 | 直接驱动转矩超过持续转矩时给「注意」，超过峰值给「超限」 | 超限必须加减速箱或换电机 |

阈值就是电机手册里的持续/峰值两条线，不引入额外经验系数。地面附着力不足时（需求牵引力超过
`mu*m*g`），先按附着力截断再核算——这一点写进了 `report.json` 的 `notes`。

## 4. 适用范围与限制

- 准静态核算：加速度、坡度、风阻都是标称工况，不含坡道起步冲击、越障冲击与驱动轮打滑瞬态；
- `eta` 把减速箱与传动效率并成一项，未拆开；实际行星减速箱效率随负载变化；
- 电机特性只用了持续/峰值转矩与额定转速三条线，不含堵转电流、反电动势与热时间常数——
  连续大坡作业要另做热核算；
- 差速转向时的内外轮差速功率没有单独算，本模块只算直行工况。
