# MuJoCo小车 打靶仿真

## 实验简介
本实验使用MuJoCo搭建带旋转炮塔的四轮小车，固定在场地上自动打靶：前方扇形布置 6 个彩色靶（3 近 3 远），炮塔像雷达一样自动识别还立着的靶子，绿色激光瞄准并锁定（靶子上方亮起白色准星），根据距离和风况解算初速度，逐个击倒；没打倒会自动重新瞄准补枪，全部击倒自动结束，无需人工干预。

## 运行环境
Ubuntu20.04 + Python3 + mujoco

## 运行步骤
```bash
# 1. 安装依赖
pip install mujoco

# 2. 运行仿真（源码位于 src/ground/mujoco_shooting/main.py）
python3 src/ground/mujoco_shooting/main.py
```

运行后弹出 MuJoCo 可视化窗口：绿色激光开场扫描，随后炮塔自动锁定靶子发射小球，靶子逐个倒下，全部击倒后自动停止。

## 弹道解算与风偏补偿

发射不再把抛物线公式写死在循环里，而是先解一个"固定飞行时间"的弹道反问题：

```text
vx = (x − x0)/T − ½·ax·T
vy = (y − y0)/T − ½·ay·T
vz = (z − z0 + ½·g·T²)/T
```

`T` 固定为 0.45 s，距离越远初速度越大；风 `(ax, ay)` 作为恒定水平加速度参与解算，
发射时自动"顶风偏"。竖直方向只受重力，所以解出来的球正好在 `T` 时刻落到靶心。

配套改动：原来 12 个小球的自由关节从 `<default>` 继承了 `damping=0.05 / armature=0.02`，
小球会边飞边减速、等效重力也只有约 8.2 m/s²，和解析模型对不上。现在自由关节显式写成
`<joint type="free" damping="0" armature="0"/>`，弹道与解析式一致（实心球本来就该没有关节阻尼）。

风在仿真里按**恒定加速度**实现：每一步给飞行中的小球加 `m·a` 的外力。

弹道解算集中在 `ballistics.py`（纯数学、不 import mujoco），可以单独跑测试。

## 无界面批量评测与成绩统计

```bash
python3 src/ground/mujoco_shooting/main.py                      # 原来的可视化窗口
python3 src/ground/mujoco_shooting/main.py --headless           # 无窗口，跑完打印成绩
python3 src/ground/mujoco_shooting/main.py --headless --wind 0.8 0.3 --report out.csv
```

| 参数 | 说明 |
|---|---|
| `--headless` | 不创建窗口、不按实时节奏 `sleep`，适合服务器 / CI 批量跑 |
| `--wind AX AY` | 水平风加速度 (m/s²)，默认 `0 0` |
| `--max-shots N` | 最多发射几发，默认 12（场景里预置 12 个球） |
| `--time-limit S` | 仿真时长上限（秒），默认 18 |
| `--report PATH` | 逐发记录写成 CSV（UTF-8 BOM，Excel 可直接打开） |

无界面跑完一次约 2 s（仿真 12 s），输出：

```text
==============================================
打靶成绩
==============================================
  结束原因    : 全部击倒
  发射发数    : 9
  击倒靶数    : 6 / 6
  命中率      : 66.7%
  一发一个靶  : 3 个
  平均用弹    : 1.50 发/靶
  耗时        : 11.94 s
  风加速度    : (0.80, 0.30) m/s²
==============================================
```

指标含义：

* **命中率** = 击倒靶数 / 发射发数；
* **一发一个靶** = 只对这个靶打了一发、并且打倒了；
* **平均用弹** = 总发数 / 击倒靶数。

CSV 逐发记录含 `shot / sim_time_s / target / distance_m / speed_m_s / hit`，方便对比不同风况。

风偏补偿效果（同一目标、风 3.0 m/s²、飞行 0.45 s）：不做补偿落点偏 **0.32 m**，补偿后只偏 **0.045 m**。
