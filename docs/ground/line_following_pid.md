# 循线小车 PID 横向控制（line_following_pid）

演示经典 PID 循线控制：小车沿正弦赛道行驶，实时计算相对中心线的横向误差，用 PID 输出前轮转角。

## 环境

- Windows 11，Python 3.13.16，pygame 2.6.1

## 运行

见包内 README。

## 分层

- track.py：正弦赛道采样、最近点查询、横向误差计算。
- pid.py：PID 控制器，含比例、积分、微分项与输出限幅。
- car.py：自行车运动学推进车身，按 PID 输出转向。
- main.py：pygame 可视化，显示赛道、轨迹、小车朝向与实时误差。

## 实测结果

本地复跑 529 步跑完整条赛道：起步横向误差 18.12 px，最大绝对横向误差 23.93 px，终点误差 -6.44 px。全程 8 次穿越中心线，后半段误差峰峰值 16.35 px，末段仍有小幅漂移。

## 限制

- 纯 2D 几何演示，车辆用简化自行车模型，不接真实定位与控制器话题。
- 赛道固定为正弦曲线，未做鼠标点选交互。
