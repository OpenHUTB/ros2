# R2D2小车 前进后退循环仿真

用 PyBullet 搭了一辆 R2D2 小车，让它自己来回走：前进 3 秒、后退 3 秒，一直循环，模拟简单的往复运动。

## 运行方法

需要 Ubuntu 20.04（或其他 Linux）和 Python3：

```bash
pip install pybullet
python3 src/ground/r2d2_move/main.py
```

运行后弹出 PyBullet 可视化窗口，小车从起点开始前进，3 秒后停住、倒车往回走，再过 3 秒又调头前进，如此循环，关窗口即可退出。

## 实现思路

核心代码在 src/ground/r2d2_move/main.py，很短：

- 用 `time.time()` 记下启动时间，`(当前时间 - 启动时间) % 6` 得到 0~6 秒的周期；
- 0~3 秒给四个轮子正速度（前进），3~6 秒给负速度（后退），速度设为 ±8，驱动力 20；
- R2D2 的四个轮子关节是 2、3、6、7，全部设成同一个速度，车就走直线；
- 主循环里每 1/240 秒调用一次 `stepSimulation()` 推进仿真，并更新一次轮速指令。

控制逻辑就是一个 if 判断，没有状态机、没有传感器，纯粹按时间切换前进/后退。
