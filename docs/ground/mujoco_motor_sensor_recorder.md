# 电机传感器 CSV 记录器

记录器将通用电机状态样本转换为可复现的温度和电流观测值，直接读取 CSV，不依赖仿真器或其他同级包。

## 验证

在 Python 3.11 和 pytest 8 环境下，`python -m pytest -q src/ground/mujoco_motor_sensor_recorder/test` 的两项测试通过。使用相同随机种子的重复运行会生成字节级一致的输出。

## 运行结果

```text
time_s,speed_mps,left_temperature_c,right_temperature_c,left_current_a,right_current_a,ambient_c
0.0,0.2,24.969294365386286,25.161371781501984,1.2409561534086756,2.2373972631067526,24.0
0.1,0.24,24.98839781716127,25.174403766309453,1.405587806350564,2.044743645142815,24.0
```

输出温度和电流字段按指定随机种子加入高斯测量噪声。以上数值由配置中的 5 行输入实际运行生成。
