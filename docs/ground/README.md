\# MuJoCo 滑移转向越野小车定点巡航仿真

对应课程任务：对地面滑移转向底盘进行物理仿真，在随机起伏越野地形下实现定点直行巡航控制，采集车身姿态、轮速、轨迹数据并可视化绘图。

本模块基于 MuJoCo 物理引擎搭建滑移转向四轮小车模型，使用定点闭环控制，小车向目标点行驶，靠近目标自动减速停车；地形引入随机高度扰动模拟越野颠簸，观测车身俯仰、横滚姿态变化。

代码位于 `src/ground/mujoco\_skid\_steer\_offroad\_stable/`



\## 1. 概述与目标

\### 1.1 核心任务目标

1\. \*\*物理仿真\*\*：四轮滑移转向小车由 MuJoCo 解算动力学，车轮配置铰接铰链、地面滚动/滑动摩擦，还原滑移转向底盘特性。

2\. \*\*地形环境\*\*：生成随机起伏地面，模拟越野不平整路面，激励车身姿态震荡。

3\. \*\*决策与控制\*\*：采用定点巡航控制，根据与目标点距离生成期望速度，靠近目标逐步减速，最终平稳停车。

4\. \*\*数据采集\*\*：记录仿真时间、车体位置、行驶速度、车身俯仰/横滚角、四个车轮转速。

5\. \*\*可视化输出\*\*：仿真窗口固定全局相机，全程视野稳定便于录制动图；仿真结束自动输出轨迹、姿态、轮速曲线图。



\### 1.2 与仓库已有模块的区别

| 对比项 | 差速小车避障模块 | 本模块（滑移越野小车） |

| 底盘形式 | 差速转向 | 滑移转向（Skid-Steer） |

| 地形 | 平整地面 | 随机起伏越野地形 |

| 控制目标 | 避开障碍物 | 定点直行巡航、到点停车 |

| 感知 | mj\_ray 激光射线感知 | 无外部传感器，使用全局位置闭环 |

| 相机 | 可跟随/自由视角 | XML固定全局广角相机，视角固定 |

| 输出曲线 | 避障距离、转向油门 | 轨迹、速度、车身姿态、四轮转速 |



\## 2. 计算原理

\### 2.1 滑移转向动力学

滑移转向小车依靠左右侧车轮转速差实现转向，本任务为直行巡航，左右轮目标转速保持一致：

v\_{cmd} = k\_p \\cdot (x\_{target} - x\_{ego})



v\_{cmd} = \\text{clip}(v\_{cmd},\\ 0,\\ v\_{max})

当车体距离目标很近时，置零目标速度，小车减速停止。



\### 2.2 地形扰动与车身姿态

起伏地面给车轮持续施加垂向扰动，车体产生俯仰 pitch、横滚 roll 震荡；仿真记录姿态角随时间变化，用来观察底盘在越野路面的稳定特性。



\### 2.3 数据记录

每一个仿真步长记录：

\- 仿真时间 `t`

\- 车体全局坐标 `x,y`

\- 车体前进速度 `v`

\- 俯仰角 `pitch`、横滚角 `roll`

\- 四轮角速度 `w\_{fl},w\_{fr},w\_{rl},w\_{rr}`



仿真结束使用 matplotlib 绘制多子图。



\## 3. 算法流程

本地仿真流程：

```text

\--run

├─ 加载 mujoco xml 模型，初始化数据

├─ 复位场景，小车在起点静置稳定

├─ 每个控制周期：

│   读取小车当前位置、姿态、轮速

│   计算距离目标偏差，生成期望速度

│   计算左右轮目标转速，施加驱动

│   mj\_step 物理求解

│   记录一组观测数据

│   渲染画面（固定相机）

└─ 到达目标/超时 → 停止仿真，输出绘图

\## 6. 现象说明

\- 0\~ 前期阶段：小车保持匀速向前行驶，起伏地面持续激励车身姿态震荡；

\- 靠近目标点：距离偏差缩小，控制器降低目标轮速，小车减速；

\- 到达目标：速度归零，四轮停止转动，姿态小幅震荡后趋于稳定；

\- 四轮转速曲线基本重合，直行状态下左右轮转速一致，符合滑移直行特性。



\## 7. 常见问题

| 现象 | 原因与处理 |

| 启动黑屏、看不到小车 | 相机参数错误；确认 xml 内 camera 为固定全局相机，euler 参数正确 |

| 小车直接弹飞、穿模 | 车轮半径与车体 z 坐标不匹配，车轮嵌入地面，修改 geom 高度 |

| 仿真一闪而过 | 时间同步逻辑错误，使用基于 walltime 的实时同步 |

| 曲线不弹出 | matplotlib 后端问题，虚拟机内可以保存图片到本地 |

| 运行提示 No module named mujoco | 依赖未安装，执行 `pip install -r requirements.txt` |
