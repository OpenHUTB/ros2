# TurtleBot3键盘遥操作Gazebo仿真

任务 1：物理仿真与键盘运动控制模块。

## 运行环境
- Ubuntu 20.04、ROS Noetic、Gazebo 11（课程虚拟机）

## 运行步骤
1. `source /opt/ros/noetic/setup.bash`
2. `python3 src/turtlebot3_keyboard_teleop_sim/scripts/main.py`
3. 在启动终端按 `方向键` 控制小车，`Ctrl+C` 退出。

## 运行效果
![teleop demo](../img/turtlebot3_keyboard_teleop_sim_demo.gif)
