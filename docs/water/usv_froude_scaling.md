# USV 弗劳德缩比换算与拖曳功率估算

船模试验做完，剩下的是"换算"：模型上测出来的阻力怎么变成实船的阻力、拖曳功率怎么估。
本模块把这条换算链写成可以手算核对的公式——弗劳德相似定速度、λ³ 定力、λ^3.5 定功率、
ITTC 1957 分解法拆摩擦与剩余阻力，只依赖 Python 标准库。

## 默认样机结论

默认参数：实船水线长 10 m、航速 5 m/s（Fr=0.505）、缩尺比 10、实船湿表面积 22 m²、
船模实测总阻力 2.5 N、准推进效率 0.55、海水 1025 kg/m³。

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 模型长度 / 速度 | 1.0 m / 1.581 m/s | v_m = v_s/√λ，保证 Fr 相同 |
| 模型摩擦阻力 | 1.243 N | ITTC 1957 平板公式，Re=1.33×10⁶ |
| 模型剩余阻力 | 1.257 N | 实测总阻力减去摩擦阻力 |
| 实船摩擦阻力 | 668.5 N | Re=4.20×10⁷，摩擦系数 0.00237 |
| **实船总阻力** | **1925.1 N** | 摩擦 + 剩余×λ³（剩余占 65%） |
| 有效功率 | 9625.7 W | R·v |
| 轴功率 | 17501.3 W | ÷准推进效率 0.55 |

两条值得注意的结论：

- **兴波是主体，缩尺放大会把它放大 1000 倍。** 模型上 1.26 N 的剩余阻力到实船变成
  1257 N，占实船总阻力的 65%。所以缩尺试验里"模型摩擦占比大"是假象——实船恰恰相反。
- **功率按 λ^3.5 放大，最容易少算一个根号。** 阻力 λ³ 再乘速度 √λ，就是 λ^3.5。
  10 倍缩尺下模型 10 W 对应实船 31.6 kW，不是 10 kW。

## 2. 公式

```text
Fr        = v / sqrt(g*L)                    弗劳德数
v_m       = v_s / sqrt(lambda)               同 Fr 的模型速度
R_s       = R_m * lambda^3                   阻力换算
P_s       = P_m * lambda^3.5                 功率换算

C_f       = 0.075 / (log10(Re) - 2)^2        ITTC 1957 平板相关线
Re        = v*L/nu
R_f       = 0.5 * rho * S * v^2 * C_f        平板摩擦阻力

R_r_m     = R_total_m - R_f_m                模型剩余阻力（兴波+形状）
R_s       = R_f_s + R_r_m * lambda^3         实船总阻力（弗劳德分解法）
P_e       = R_s * v_s                        有效功率
P_d       = P_e / eta                        螺旋桨轴功率，eta 为准推进效率
```

## 3. 判定与警告

| 量 | 阈值 | 含义 |
| --- | --- | --- |
| 模型剩余阻力 | ≤ 0 时警告 | 实测总阻力小于平板摩擦估算，先查测量与湿表面积 |
| Fr | > 1 时警告 | 高速滑行区兴波规律变化，弗劳德换算不再可靠 |

阈值不是硬界限，只是换算链的适用边界提示。

## 4. 适用范围与限制

- ITTC 1957 是平板摩擦相关线，实船船体弯曲、粗糙度的影响用形况系数 (1+k) 修正，
  本模块取 1；工程上通常另加 5%~15% 的粗糙度/附体裕量，本模块不加；
- 弗劳德分解法只处理"剩余阻力按 λ³ 缩放"这一条，粘性尺度效应（模型与实船雷诺数不同）
  未做形况系数修正；
- 未计入空气阻力、附体阻力与浅水/受限航道效应；
- 模型阻力是输入量——本模块不生成阻力数据，只做换算。
