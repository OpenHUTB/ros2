# MuJoCo 差速小车避障仿真## 实验目标实现差速小车从起点出发，自动识别并避开路径上的障碍物，成功到达目标点。## 模型介绍- 两轮差速小车模型- 静态长方体障碍物设置在路径中间- 绿色圆柱目标点位于障碍物后方## 控制算法采用分段避障策略：1. 阶段1：小车直行朝向目标点前进2. 阶段2：碰撞检测触发，小车原地左转绕开障碍物3. 阶段3：小车恢复直行，绕过障碍物后转向回到原路线4. 阶段4：到达目标点附近自动停止## 运行结果小车从起点(-2,0)出发，直行碰到障碍物后自动左转绕开，最终平稳到达目标点(3,0)。## 运行命令```bashpython3 main.py```支持`--headless`无头模式运行，无需可视化窗口。
