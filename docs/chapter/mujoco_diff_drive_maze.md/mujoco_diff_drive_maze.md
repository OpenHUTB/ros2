# MuJoCo 差速小车走迷宫

## 实验目的
1. 掌握MuJoCo中差速移动机器人的建模方法
2. 理解差速驱动的运动控制原理
3. 学会通过碰撞检测判断机器人与环境的交互
4. 掌握开环路径规划的基本方法

## 实验环境
- MuJoCo 3.0.3
- Python 3.8
- Ubuntu 20.04

## 模型介绍
差速小车由底盘、左右两个驱动轮组成，通过给两个轮子施加不同的角速度实现转向：
- 两轮同速前进：小车直行
- 左轮反转、右轮正转：小车原地左转
- 左轮正转、右轮反转：小车原地右转

迷宫为L型结构，包含两面灰色墙壁和一个绿色圆柱形终点标记。

## 控制流程
1. 从起点(-2,-2)向右直行
2. 原地左转90度，朝向y轴正方向
3. 向上直行，从墙壁上方绕过
4. 原地右转90度，朝向x轴正方向
5. 向右直行，到达绿色终点

## 碰撞检测
通过遍历MuJoCo的contact数组，检测是否存在与wall或goal geom的碰撞：
- 检测到wall碰撞：判定失败，停止控制
- 检测到goal碰撞：判定成功，停止控制

## 调试要点
1. 差速小车的轮子必须左右布置（y方向），放在x方向会变成前后轮无法转向
2. 轮子关节轴必须设为y轴，否则轮子转动方向错误
3. 碰撞检测直接判断静态障碍物geom名称即可，不需要判断机器人geom
4. 转向步数需要反复调试，确保刚好转90度
