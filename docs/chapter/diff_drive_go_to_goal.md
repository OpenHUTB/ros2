# MuJoCo 差速小车 go-to-goal 仿真

## 实验目标
实现差速小车从原点 (0, 0) 自主导航到目标点 (3.0, 2.0)。

## 模型介绍
- 四轮差速小车模型（后轮驱动，前轮被动支撑）
- 车身尺寸: 0.4m × 0.2m × 0.1m
- 轮子半径: 0.05m

## 控制算法
采用分段比例控制策略：
1. 当航向误差 |angle_diff| > 0.5 rad 时，原地转向
2. 当 |angle_diff| ≤ 0.5 rad 时，边走边转，角速度与航向误差成正比
3. 到达判定：小车到目标点距离 < 0.15m

## 运行结果
小车从原点出发，平滑转向目标点，最终稳定到达 (3.0, 2.0)。
