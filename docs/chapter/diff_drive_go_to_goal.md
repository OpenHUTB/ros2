# MuJoCo 差速小车 go-to-goal 仿真

## 简介

本实验在 MuJoCo 仿真环境中实现差速小车的 go-to-goal 控制任务。小车从初始位置出发，自主导航到目标点（绿色小球）。

## 模型

- 差速小车：蓝色长方体底盘，四个轮子（后两轮驱动，前两轮被动支撑）
- 目标点：绿色小球，位于 (3.0, 2.0) 位置
- 控制方式：速度控制，左右轮独立速度指令

## 控制逻辑

### 问题：极限环
原始 bang-bang 控制策略中，当角度误差较小时直接直行，导致航向误差无法收敛，形成极限环，小车始终无法到达目标点（最终误差约 0.46m）。

### 解决方案：分段比例控制

```python
K_ANGULAR = 0.5

if abs(angle_diff) > 0.5:
    # 角度差大：原地旋转
    linear = 0.0
    angular = 0.3 if angle_diff > 0 else -0.3
else:
    # 角度差小：边走边转（比例控制）
    linear = 0.15
    angular = K_ANGULAR * angle_diff
