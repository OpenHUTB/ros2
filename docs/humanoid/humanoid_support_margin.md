# 人形机器人支撑多边形与倾倒裕度核算

人形机器人站立时的第一性问题是：重心投影离支撑边界有多远、多大的推力/冲量会把它推倒。
本模块把这三笔账写成可以手算核对的公式——两脚矩形着地区的凸包是支撑多边形，
投影到边界的最近距离是稳定裕度，绕最近边棱的力矩/能量平衡给出临界推力与临界冲量。
只依赖 Python 标准库（凸包用单调链算法，几十行）。

## 默认样机结论

默认参数：40 kg、两脚中心 x = ±0.10 m、脚掌 0.10 × 0.25 m、重心投影 (0.01, 0) m、
重心高 0.8 m。

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 支撑多边形 | x ∈ [-0.15, 0.15], y ∈ [-0.125, 0.125] m | 双足矩形的凸包（含两脚间空隙） |
| 稳定裕度 | 125 mm | 重心投影到最近边界的距离 |
| 临界推力 | 61.3 N | m·g·d/h，约 15.7% 体重 |
| 临界冲量 | 17.5 N·s | 能量法：重心须抬过边棱正上方 |
| 足底载荷 | 左 45%（177 N）/ 右 55%（216 N） | 投影偏右 1 cm 的结果 |

两条值得注意的结论：

- **支撑多边形是凸包，不是两只脚的并集。** 双足之间的空隙也在支撑范围内——地面反力合力
  可以落在凸包内任意位置，所以判重心投影出界要用凸包，而不是"投影必须落在某只脚上"。
- **推倒它不需要多大劲。** 40 kg 的机器人临界推力只有 61 N，一个成年人的侧向推力轻松超过。
  更直观的是临界冲量 17.5 N·s：5 N 的力持续 3.5 秒就到了。这就是为什么人形控制里
  防倾倒要靠踝/髋力矩主动响应，而不是指望"够稳"。

## 2. 公式

```text
支撑多边形   P = convex_hull(两脚矩形的全部顶点)
稳定裕度     d = min 投影点到各边的距离        (出界取负)
静态临界推力 F_crit = m * g * d / h            绕最近边棱的力矩平衡
临界冲量     J_crit = m * sqrt(2*g*(sqrt(d^2+h^2) - h))
                                              能量法：动能须把重心抬过边棱正上方
足底载荷     f1 = W*(x2-x)/(x2-x1), f2 = W*(x-x1)/(x2-x1)
                                              等刚度弹簧模型，x 在两脚间成立
```

## 3. 判定阈值

| 量 | 阈值 | 含义 |
| --- | --- | --- |
| 重心投影 | 出界 → 超限 | 静立必倒，无静态解 |
| 稳定裕度 | < 20 mm → 注意 | 轻微扰动就可能出界 |
| 稳定裕度 | ≥ 20 mm → 正常 | 同时给出临界推力与冲量 |

20 mm 的门限是工程经验值；不同平台（脚掌大小、踝关节力矩）可放宽或收紧。

## 4. 适用范围与限制

- 两脚矩形着地区且无偏航，凸包即支撑多边形；单脚站立把另一只脚尺寸设 0 也可算；
- 倾倒判据按绕最近边棱的刚体翻转推导，不含踝/髋关节力矩与屈膝缓冲——带主动平衡的
  机器人实际抗推能力大于这里的临界值；
- 足底载荷是等刚度弹簧模型，真实分布需要 CoP 传感器；
- 只算准静态与脉冲扰动的临界值，不含动力学摔倒过程。
