# acc_follow 设计文档：ACC 自适应巡航仿真

## 1. 项目概述

本作业实现 **ACC（Adaptive Cruise Control，自适应巡航）** 纵向跟车仿真：
车辆在直线道路上行驶，当感知到前车减速时自动降低车速、前车停车时在安全
间距处停稳、前车起步后自动跟随并恢复巡航。覆盖"巡航、跟随减速、跟停、
起步再跟随"的完整闭环，是高级驾驶辅助系统（ADAS）中最核心的纵向控制功能。

与仓库已有仿真（自动泊车：路径规划；红绿灯启停：交通规则响应）相比，
本作业聚焦**纵向运动控制与跟车决策**，属于横向/纵向控制体系中的另一分支。

## 2. 系统架构

```text
                    ┌─────────────────────────────────────────────┐
                    │                ACC 控制闭环                  │
                    │                                             │
 前车状态(场景) ──▶ │  感知/输入    ──▶  控制律     ──▶  车辆模型  │
 [x_lead, v_lead]   │  d = x_lead   │  v_cmd = f(d,  │  dv/dt=a   │
    (内置场景 或     │     - x_host  │   v_lead,     │  dx/dt=v   │
     ROS /lead_state)│                │   v_host)     │            │
                    │                └──────┬─────────┘            │
                    │                       │ v_cmd                 │
                    │  /cmd_vel (ROS) ◀─────┘                      │
                    └─────────────────────────────────────────────┘

  控制律 = 恒定时距(CTG) 期望车距 + 三区控制 + 平方根刹停曲线 + 刹停兜底
```

模块划分：

| 模块 | 文件 | 职责 |
|---|---|---|
| 车辆模型 | `vehicle_model.py` | 本车一维运动学（加速度限幅）；前车分段速度场景 |
| 控制律 | `acc_controller.py` | 期望车距、巡航/减速/停车三区切换、平方根刹停、兜底 |
| 仿真主程序 | `acc_sim.py` | Pygame 交互窗口；`--record` 无头录制；`--test` 验证 |
| 自动验证 | `headless_test.py` | 6 项指标自动检查，输出 PASS/FAIL |
| ROS 节点 | `main.py` | 订阅前车状态、发布 `/cmd_vel` |

## 3. 控制律推导

> 车距语义说明：本文所有 `d` 均指**保险杠间距**（两车保险杠之间空隙），
> 由中心距换算：`d = d_center - car_len`，`car_len = 4.5 m` 为车长。
> 控制器接口 `compute(d_center, v_lead, v_host)` 接收中心距，内部自动换算。

### 3.1 恒定时距（Constant Time Gap）期望车距

ACC 的经典车距策略：期望车距随本车速度线性增大，保证高速时跟车距离更远。

```
d_des = d0 + t_gap * v_host + t_react * max(v_host - v_lead, 0)
```

- `d0 = 3.0 m`：停车安全保险杠间距（前车静止时本车停稳后两车保险杠的最终间距）；
- `t_gap = 1.0 s`：跟车时距（车距 = 速度 × 时距，1 s 是常用设定）；
- `t_react = 0.6 s`：相对速度反应时间，前车比本车慢时额外加大期望车距，
  使本车**提前**减速，避免前车急刹时反应不及。

### 3.2 三区控制

以实际车距 `d` 与进入阈值 `d_enter = d_des + margin`（`margin = 3.0 m`）比较：

| 区域 | 条件 | 目标速度 v_cmd |
|---|---|---|
| 巡航区 | `d > d_enter` | `v_cruise`（正常巡航） |
| 减速区 | `d0 < d <= d_enter` | `sqrt(2 * a_brk * (d - d0))` |
| 停车区 | `d <= d0` | `0`（全力制动） |

### 3.3 平方根刹停曲线（减速区）

在减速区内，令目标速度为：

```
v_cmd = sqrt(2 * a_brk * (d - d0))
```

性质：若本车速度始终不超过该曲线，则按 `a_brk = 4.0 m/s²` 制动恰好在前车
停止点（距本车 `d - d0`）处速度降为 0——即**物理上保证不越过前车**，且减速
过程平滑（越接近前车速度越低），乘客舒适度优于阶跃急刹。

### 3.4 刹停兜底

车辆模型对目标速度的跟踪存在一阶滞后（加速度限幅），为应对前车急刹，
增加硬安全条件：若按最大制动减速度刹停所需的相对距离已超过可用空间

```
(v_host^2 - v_lead^2) / (2 * a_brk) > d - d0
```

则直接输出 `v_cmd = 0` 全力制动。该条件同时保证"跟停"功能在低速蠕行阶段
确定停稳（前车静止且本车低速贴近时刹停）。

## 4. 场景设计

前车按分段速度曲线行驶，覆盖 ACC 的典型工况（拥堵-停走）：

| 时间段 | 前车行为 |
|---|---|
| 0 ~ 8 s | 15 m/s（54 km/h）匀速巡航 |
| 8 ~ 13 s | 以 3.0 m/s² 减速至 0（拥堵刹车） |
| 13 ~ 20 s | 静止等待 |
| 20 ~ 34 s | 以 2.0 m/s² 起步，加速回 15 m/s 巡航 |

本车初始在 50 m 后以 15 m/s 行驶，由 ACC 控制器闭环驱动。

## 5. 测试与结果

`headless_test.py` 以 0.05 s 步长运行上述场景 34 s，检查 6 项指标：

| # | 检查项 | 阈值 | 实测 | 结论 |
|---|---|---|---|---|
| 1 | 全程最小保险杠车距（不碰撞） | > 2.0 m | 2.79 m | PASS |
| 2 | 前车停稳后本车停稳 | v < 0.1 m/s | 停稳 | PASS |
| 3 | 跟停车距（期望 3.0 m） | 2.0 ~ 5.0 m | 2.79 m | PASS |
| 4 | 全程不超速（限速 15） | <= 15.0 m/s | 15.00 m/s | PASS |
| 5 | 起步后恢复巡航 | >= 14.5 m/s | 15.00 m/s | PASS |
| 6 | 稳态跟车车距 | 14 ~ 22 m | 20.25 m | PASS |
