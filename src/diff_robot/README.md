# diff_robot 差速驱动小车仿真包

## 功能介绍
基于ROS Noetic和Gazebo 11的差速驱动小车仿真功能包，包含完整的小车URDF模型、Gazebo差速驱动插件和一键启动文件。

## 环境要求
- Ubuntu 20.04
- ROS Noetic
- Gazebo 11

## 依赖安装
```bash
sudo apt install ros-noetic-gazebo-ros ros-noetic-robot-state-publisher ros-noetic-xacro ros-noetic-geometry-msgs ros-noetic-nav-msgs ros-noetic-tf
