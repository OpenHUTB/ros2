# 三自由度机械臂空间螺旋线仿真说明

## 1. 模型

三自由度机械臂，关节链：底座 -> yaw（绕 Z 轴）-> shoulder（绕 Y 轴）-> elbow（绕 Y 轴）-> tip。

| 部件 | 尺寸/颜色 |
|---|---|
| 底座圆柱 | 半径 0.07 m，深灰 |
| 立柱 | 半径 0.035 m，高度 0.24 m |
| link1（蓝） | 胶囊体，半径 0.035 m，长 0.30 m |
| link2（橙） | 胶囊体，半径 0.028 m，长 0.30 m |
| tip（红） | 球，半径 0.028 m |
| 参考圆 | 地面 16 个绿点，半径 0.15 m（螺旋线在地面的投影） |

关节约定：shoulder / elbow 绕 **-Y 轴**，正角度使连杆向 +Z（向上）弯折，
这样与平面两连杆的解析公式方向一致。

## 2. 空间逆运动学（解析解）

目标：末端世界坐标 (x, y, z)。肩俯仰铰点高度 BASE_Z = 0.24 m。

1. 水平投影求方位角：`q0 = atan2(y, x)`，`r = sqrt(x^2 + y^2)`
2. 臂平面（r-z）内两连杆解析解：
   - `d = sqrt(r^2 + (z - BASE_Z)^2)`
   - `q2 = acos((d^2 - L1^2 - L2^2) / (2 L1 L2))`（肘上姿势）
   - `q1 = atan2(z - BASE_Z, r) - atan2(L2 sin(q2), L1 + L2 cos(q2))`
3. **yaw 解缠**：螺旋多圈旋转时 atan2 输出在 ±pi 跳变，按上一帧目标角 ±2pi 调整，
   保证 q0 连续（本仿真 q0 从 0 连续转至 3pi，即 1.5 圈 / 540°）。

## 3. 轨迹

末端沿圆柱螺旋线运动：

```
ang = 2*pi * (t % PERIOD) / PERIOD      # 水平角，PERIOD = 6 s/圈
x = RADIUS * cos(ang)                   # RADIUS = 0.15 m
y = RADIUS * sin(ang)
z = Z_LO + (Z_HI - Z_LO) * t/DURATION   # 0.20 -> 0.40 m 匀速上升
```

参数：L1 = L2 = 0.30 m，TURNS = 1.5 圈，DURATION = 9.0 s，FPS = 24，共 216 帧。

## 4. 控制

三关节独立 PD 位置控制，控制周期 0.006 s（timestep 0.002 s，每帧 3 次积分）：

```
ctrl_i = KP * (q_target_i - q_i) - KD * qvel_i      # KP = 40, KD = 12
```

## 5. 渲染

- 相机：自由视角，lookat (0, 0, 0.30)，distance 1.30，azimuth 45°，elevation 28°。
- 轨迹线：按相机参数手算 lookAt + 透视投影矩阵，把末端世界坐标 (x, y, z)
  投影为像素坐标，在渲染帧上叠加黄色轨迹线（宽 4 px）。
- 输出：Pillow 合成 demo_arm3d.gif（216 帧，duration = 1000/24 ms）。

## 6. 验证

读出 tip 世界坐标 -> 与目标点对比。

### 6.2 实时渲染（verify_arm3d.py gui）

`mujoco.viewer.launch_passive` 弹出 glfw 查看器窗口，逐帧解算并施加 PD 控制，
`v.sync()` 同步播放。

本机实测：**216 帧 / 9.0 秒完整播放**，螺旋线逐圈上升，轨迹连续无跳变。
