# 禁飞区检测模块 (No-Fly Zone Check)

## 简介

本模块用于无人机配送任务的禁飞区安全校验。给定取货点和送货点的经纬度坐标，判断它们以及**两点之间的航线**是否触及预设的禁飞区。

## v2 修复：航线穿越检测

旧版只检查起降点两个端点——两端点都安全、但直线航线正穿禁飞区的任务会被误判为"安全"。v2 接入共享核心 `src/air/no_fly_zone_check/nfz_core.py`，对起降点与每一段航线分别做球面最短距离检测（大圆交叉距离），并支持安全裕量 `buffer`（默认 200 m）。

## 运行环境

- Python 3.6+
- 无第三方依赖（仅用标准库 `math`）

## 运行步骤

cd src/no_fly_zone_check
python main.py

## 运行效果

执行后会输出以下内容：

1. 当前加载的禁飞区列表
2. 6 个测试坐标的逐点检测结果（4 个被拦截，2 个通过）
3. 旧版漏报场景回归：端点安全但直线航线穿越机场禁区 → 被本版拦截
4. 三段直角绕行航路点方案 → 校验通过

## 算法说明

使用 **Haversine 公式** 计算地球表面两点之间的球面距离：

    a = sin²(Δφ/2) + cosφ₁·cosφ₂·sin²(Δλ/2)
    c = 2·atan2(√a, √(1−a))
    d = R·c

其中 R = 6371000 米（地球平均半径）。航线段检测使用大圆交叉距离（cross-track）公式，详见 `docs/air/no_fly_zone_check/index.md`。

## 参数配置

禁飞区在 `main.py` 顶部的 `NO_FLY_ZONES` 列表中定义，安全裕量由 `SAFETY_BUFFER_M` 控制。
