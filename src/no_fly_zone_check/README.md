# 禁飞区检测模块 (No-Fly Zone Check)

## 简介

本模块用于无人机配送任务的禁飞区安全校验，提供两种检测：

- **单点检测**：给定一个经纬度，判断它是否落在预设的禁飞区内；
- **航线穿越检测**：给定取货点与送货点，判断**整条直线航线**是否穿越禁飞区。
  旧版本只检查两个端点，当航线从禁区中间穿过、而两端都在区外时会漏判。

## 运行环境

- Python 3.6+
- 无第三方依赖（仅用标准库 `math` / `argparse` / `json`）

## 运行步骤

单点检测 + 内置示例：

    cd src/no_fly_zone_check
    python main.py

航线穿越检测（离线，不需要 AirSim / ROS）：

    python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11
    python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11 --json

退出码：`0` = 航线安全；`1` = 存在违规（取货点/送货点在区内，或航线穿越禁区）。

## 输出示例

```
$ python main.py --pickup 47.65,-122.17 --dropoff 47.65,-122.11
==================================================
航线禁飞区检测
==================================================
取货点: (47.65000, -122.17000)
送货点: (47.65000, -122.11000)
检查禁飞区数量: 3
--------------------------------------------------
[WARNING] 航线穿越禁飞区【Airport】：距离中心 0.0 m（半径 2000 m）
```

两个端点距离 Airport 中心都约 2.2 km（在 2 km 半径之外），但航线正好从中心穿过——
这正是旧版本“只查端点”会漏掉的情况。

## 算法说明

**球面距离**用 Haversine 公式：

    a = sin²(Δφ/2) + cosφ₁·cosφ₂·sin²(Δλ/2)
    c = 2·atan2(√a, √(1−a))
    d = R·c

其中 R = 6371000 米（地球平均半径）。

**航线穿越**：以禁飞区中心为原点做局部等距投影（米），把航线变成一条线段，
再求禁区中心到该线段的**点到线段最短距离**，与半径比较：

    x = (lon − lon₀)·cos(lat₀)·R
    y = (lat − lat₀)·R
    t = clamp(−(A·(B−A)) / |B−A|², 0, 1)
    d_min = |A + t·(B−A)|

`d_min ≤ radius` 即判定穿越。禁飞区半径通常只有几百米到几公里，局部近似误差
远小于判定裕度，而且不会像“逐点采样”那样漏掉细长的穿越。

判定优先级：端点在内（`pickup_inside` / `delivery_inside`）优先于航线穿越
（`path_crosses`），同一个禁区只记一条违规。

## 参数配置

禁飞区在 `main.py` 顶部的 `NO_FLY_ZONES` 列表中定义，每项包含
`name`、`lat`、`lon`、`radius_m`；函数都接受可选的 `zones` 参数，便于测试或按批次加载。

## 本地测试

航线穿越判定、命令行退出码与 `--json` 输出。
