# 四类幕墙 ONNX 模型

模型来自提供的 `airsim_facade_impl_20261026.zip` 中
`01_ros_pkg/airsim_facade_inspection_yolo/models/best.onnx`。
随包保留 Ultralytics 导出的元数据，类别顺序经模型元数据核对为：

| 编号 | 类别 | 统计口径 |
|---|---|---|
| 0 | crack | 裂缝病害 |
| 1 | stain | 污渍病害 |
| 2 | peel | 剥落病害 |
| 3 | glass | 玻璃构件，不计入病害数量 |

输入为 RGB 浮点张量 `1×3×640×640`，归一化至 `[0,1]`；
输出为 `1×8×8400`，每候选框四个坐标和四类置信度。
模型导出版本为 Ultralytics 8.4.178，导出日期为 2026-10-18。
模型许可为 AGPL-3.0，完整许可见上级目录 `LICENSE`。

`facade_4class.json` 记录权重 SHA-256、类别顺序、输入输出形状和来源。
训练入口使用外部数据集，训练得到的新模型不会覆盖随包模型。

模型面向补充数据中的仿真建筑立面图像。验证结果显示玻璃构件效果较好，
裂缝、剥落召回偏低；输出用于辅助定位待复查区域，不能替代建筑安全鉴定。
