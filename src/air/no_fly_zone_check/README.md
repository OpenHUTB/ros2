# 禁飞区检测模块

本模块调用 AirSim 模拟器接口获取无人机状态，并通过 Haversine 公式判断无人机是否进入预设的禁飞区（机场、军事基地、学校）。

## 运行环境

- Python 3.10
- 需要启动 AirSim 1.8.1 模拟器
- 第三方库：`airsim`、`matplotlib`

## 运行步骤

1. 启动 AirSim 1.8.1 模拟器（确保 RPC 端口 41451 已开放）。
2. 运行检测程序：
   cd src/air/no_fly_zone_check
   python main.py

## 日志记录

当检测到无人机违规进入禁飞区时，程序会自动将违规时间、禁飞区名称、经纬度及距离信息记录到当前目录的 `violation_log.csv` 文件中。

## 距离预警

除了进入禁飞区报警外，模块还支持距离预警。当无人机距离禁飞区边缘小于 500 米时，终端会输出黄色预警提示，提醒飞手提前规避。
