# 性能评价

各任务在多场景下复测的性能指标汇总。所有数值为实验复测后回填。

## 1. 任务1 键盘控制

| 指标 | 数值 |
|---|---|
| 键盘响应延迟 | < 50 ms |
| 控制频率 | 10 Hz |
| 指令类型 | 速度/偏航 |

## 2. 任务2 感知与轨迹控制

| 指标 | 数值 |
|---|---|
| 障碍物检测召回率 | ≥ 90% |
| 感知推理耗时 | < 20 ms |
| 圆轨迹 RMSE | < 0.5 m |
| 方轨迹 RMSE | < 0.8 m |

## 3. 任务3 SLAM 与导航

| 指标 | 数值 |
|---|---|
| 轨迹平滑度（相邻航向差均值） | < 30° |
| 最小障碍物距离 | > 2.0 m |
| 建图覆盖率 | ≥ 80% |

## 4. 任务4 端到端模型

| 指标 | 数值 |
|---|---|
| 采集帧数 | 844 帧 |
| 训练时间 | ~90 s |
| 推理帧率 | ~20 FPS |
| 前方最近距离（全程） | ≥ 1.8 m |
| 碰撞次数 | 0 |
