# 无人机键盘遥控器故障排查

本文档补充 `drone_teleop.py` 使用过程中常见的连接和控制问题。

## 1. AirSim 连接被拒绝

如果运行脚本时出现：

```text
ECONNREFUSED
```

请依次检查：

1. OpenHUTB / AirSim 模拟器是否已经启动；
2. `--ip` 参数是否为模拟器所在主机的实际 IP；
3. AirSim RPC 端口 `41451` 是否可以访问；
4. 虚拟机网络是否与模拟器处于同一网段；
5. 防火墙是否允许客户端访问 `41451` 端口。

可以使用以下命令测试端口：

```bash
telnet 192.168.235.1 41451
```

连接成功时会显示：

```text
Connected to 192.168.235.1
```

如果显示 `Connection refused`，需要先启动模拟器或检查 IP 和端口配置。

## 2. 找不到无人机载具

运行后如果 `listVehicles` 返回空列表，请检查 AirSim 配置文件中是否已经配置无人机，并确认启动的是无人机仿真环境。

如果存在多个载具，可以显式指定名称：

```bash
python3 src/air/air_teleop/drone_teleop.py \
  --ip 192.168.235.1 \
  --vehicle Drone1
```

载具名称必须与 AirSim 配置中的名称完全一致。

## 3. 按键没有反应

请确认：

- 脚本在交互式终端中运行；
- 当前终端窗口已获得输入焦点；
- 起飞前已经按 `T` 解锁电机；
- 没有其他程序占用无人机 API 控制权；
- 终端快捷键没有拦截 `Ctrl+P`。

如果终端会拦截 `Ctrl+P`，可以使用其他终端运行脚本。

## 4. 无人机移动后无法及时停止

方向键控制采用瞬时速度指令。松开按键后脚本会自动清零速度。如果无人机仍持续移动，请立即按 `H` 悬停，并检查终端是否持续发送重复按键。

## 5. 安全退出

建议使用 `Esc` 退出，脚本会依次执行：

1. 悬停；
2. 降落；
3. 关闭电机；
4. 释放 API 控制权。

发生异常时可以按 `Ctrl+C`，并在模拟器中确认无人机已经安全降落。

## 6. 运行前检查清单

- [ ] 模拟器已经启动；
- [ ] IP 地址和端口正确；
- [ ] `listVehicles` 能识别无人机；
- [ ] 无人机周围没有障碍物；
- [ ] 已了解 `H` 悬停和 `Esc` 安全退出操作。
