                       #   AttributeError: module 'mediapipe' has no attribute 'solutions'
airsim             # AirSim Python 客户端（会自动带上 msgpack-rpc-python）
                   # ⚠ 旧版 requirements.txt 漏了这一条，导致控制节点
                   #   `import airsim` 直接 ModuleNotFoundError

# 仅"无 ROS 单机演示"（scripts/gesture_demo.py）需要：
pygame

# 中文绘制；若已用 apt 安装 python3-pil 可省略
Pillow
