# 基于 Hybrid A* 与 Reeds-Shepp 的垂直自动泊车

## 1. 问题描述

给定一辆自行车模型小车（后轮轴参考点，轴距 L=2.7m，最小转弯半径约 3.85m），
停在垂直车位前方的道路上。车位两侧各有一辆障碍车。要求小车自动规划路径并倒车入库。

这是一个典型的**带方向约束的局部规划问题**：
- 车辆不能原地转向，必须有速度才能转弯；
- 允许前进/倒车切换（揉库）；
- 不能碰到两侧障碍车。

## 2. 算法

### 2.1 Hybrid A*

Hybrid A* 把车辆运动学直接编码进搜索节点：

- **状态**：`(x, y, yaw)`，其中 yaw 离散到 10°；
- **动作**：`{前进, 倒车} × {左满舵, 直行, 右满舵}` = 6 个运动学原语；
- **扩展**：每个动作沿自行车模型积分 0.8m，过程中做碰撞检测；
- **代价**：行驶距离；
- **启发**：到目标的欧氏距离（可采纳）。

与普通 A* 不同，Hybrid A* 的每个节点本身就是一个合法的车辆位姿，
所以搜出来的路径**天然满足运动学约束**，不需要后处理平滑。

### 2.2 Reeds-Shepp 曲线

Reeds-Shepp 曲线描述了"能前进也能后退"的车辆最短路径，
由若干直线段和圆弧段拼接而成。本仓库实现了 6 个基础 family
（LSL/RSR/LSR/RSL/LRL/RLR），并对每条候选路径做数值积分终点校验，
丢弃终点不匹配的解。RS 曲线在本项目里作为启发式和终点直连尝试使用。

### 2.3 碰撞检测

车辆模型为旋转矩形（OBB），障碍物为轴对齐矩形（AABB）。
检测时把车辆四个角变换到障碍物坐标系，做 AABB 包含测试，
并反向把障碍物角点变换到车辆坐标系，双重判断避免漏检。

### 2.4 Pure Pursuit 跟踪

- 在参考路径上找离车最近的点；
- 沿路径向前 lookahead=1.0m 取前视点；
- 用 `δ = atan(2L·sin(α)/ld)` 计算前轮转角；
- **倒车时**：参考系换成车尾方向（yaw+π），并把转向反号；
- 检测到路径 gear 字段变化时先刹车停稳，再反向打方向，模拟真实换挡。

### 3.1 虚拟机演示
