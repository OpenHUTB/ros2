# 恶劣雨雾天气下相机-激光雷达融合可行性实验

本模块是「恶劣雨雾天气下多传感器感知性能对比」系列的第四部分。前三部分分别量化了
相机退化、图像增强的恢复上限、以及雷达与相机的横向退化对比，本模块回答一个更实际的
问题：**把雷达点云投影到相机图像上，这种融合在雨雾中还能不能用。**

## 实验思路

在 Town10HD 中生成 ego 车辆（`vehicle.tesla.model3`），在车顶**同时**挂载三台传感器，
并在同一参考位姿下依次切换 `ClearNoon` / `SoftRainNoon` / `HardRainNoon` / `HeavyFog` 四档天气：

| 传感器 | 位置 | 作用 |
| --- | --- | --- |
| `sensor.camera.rgb` | x=1.5, z=2.4 | 800×600、FOV 90°，待投影的图像 |
| `sensor.camera.depth` | x=1.5, z=2.4 | 同机位同内参，仅用于剔除天空像素 |
| `sensor.lidar.ray_cast` | x=0.0, z=2.6 | 32 线、50 m 量程、20 Hz、100 万点/秒，待投影的点云 |

两台相机姿态与雷达相同、只差固定平移，因此雷达坐标系到相机坐标系只需平移；
相机内参由 FOV 与分辨率反解（`fx = fy = (W/2)/tan(FOV/2) = 400`）。
投影公式为 `u = cx + fx·y/x`、`v = cy − fy·z/x`（z 轴向上，故 v 取负）。

## 指标

| 指标 | 含义 |
| --- | --- |
| 投影有效率 | 相机前方点中，落在图像范围内的比例 |
| 天空误投率 | 投到天空像素的点占比，正常应接近 0，用于校验标定 |
| 图像覆盖率 | 非天空像素中，被至少一个投影点覆盖的比例 |
| 近场 / 远端覆盖率 | 只用 ≤20 m / ≥30 m 的点计算的覆盖率 |
| 边缘命中率 | 投影点落在图像 Canny 边缘 3 像素邻域内的比例，衡量「语义上对不对得上」 |

## 运行

1. 启动 CARLA 服务端：双击解压目录下的 `CarlaUE4.exe`。
2. 安装依赖并运行：

   ```bash
   pip install -r requirements.txt
   python main.py
   ```

运行结束后 `results/` 目录得到：

- `fusion_metrics.csv`：四档天气的各项融合指标
- `weather_fusion_overlay.png`：四档天气的投影叠加图（按距离着色）
- `weather_fusion_metrics.png`：指标柱状图与边缘命中率随距离的变化曲线

指标与图片都保存后，脚本会在浓雾中让车辆自动驾驶 10 秒（`DEMO_SECONDS`），
CARLA 窗口跟随车顶相机，仅用于直观查看雨雾中的第一视角，不参与任何指标计算。

## 注意

- 雷达按渲染帧发布，单帧只含约 45° 扇形，本实验在固定 **0.3 s 窗口**内累积多帧拼成整圈点云；
  若直接拿单帧统计，覆盖率会被系统性低估。测量期间车辆必须保持静止，否则累积会拖影。
- 相机与雷达帧率不同，投影以累积窗口结束时刻最近的一帧图像为准，并非严格硬件同步。
- `atmosphere_attenuation_rate` 只能在生成传感器时写入，因此每档天气前都要重建一次雷达。
- 深度相机在本实验中只用于区分天空与真实表面：CARLA 深度相机的绝对读数与真实距离存在
  固定比例偏差，因此不用于绝对深度精度比对。
