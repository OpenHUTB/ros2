# mujoco_diff_drive_go_to_goal

MuJoCo 差速小车 go-to-goal 仿真：蓝色四轮小车（后两轮驱动、前两轮被动支撑）从原点 `(0, 0)` 出发，自主驶向绿色目标点 `(3.0, 2.0)` m。控制采用**分段比例控制**：航向误差大时原地差速转向对准目标，误差小时直行并叠加航向比例修正；两档阈值带滞回，避免在切换边界来回抖动。

## 运行环境（实际验证）

| 项 | 版本 |
|---|---|
| 操作系统 | Ubuntu（无头云主机，无独立显卡） |
| Python | 3.12.11 |
| 模拟器 | MuJoCo `>=3.2,<4.0`（本机实测 3.17.0） |
| 关键依赖 | numpy 1.26.4；Pillow 仅录帧导出 GIF 时需要；MuJoCo 不在 apt 仓库，需 pip 安装 |
| 渲染后端 | 可视化用 `MUJOCO_GL=glfw`；无头离屏录帧用 `egl`（mesa 软件渲染，无独立显卡也可出图） |

## 安装

```bash
# 先进入本包目录（仓库内 checkout 路径如下）：
cd src/ground/mujoco_diff_drive_go_to_goal
pip install -r requirements.txt
```

## 运行

在**包目录**下执行：

```bash
python3 main.py              # 打开 MuJoCo 窗口，关闭窗口即退出
python3 main.py --headless   # 无头模式：到达目标点或超时后打印结果退出（无窗口）
```

## 模型与参数

- 车体：蓝色长方体底盘，四轮；后两轮由 `velocity` 执行器驱动，前两轮被动支撑；
- 轮半径 `R=0.05 m`，左右轮间距 `L=0.22 m`；
- 目标点：绿色小球，`(3.0, 2.0) m`，只作可视化标记，不参与碰撞；
- 直行速度 `0.6 m/s`，原地转向角速度 `1.5 rad/s`，直行航向比例增益 `K=3.0`；
- 转入阈值 `0.5 rad`、转回阈值 `0.3 rad`（滞回）；到达判据 `0.12 m`；步数上限 `20000`（`dt=0.005`，兜底 100 s）。

## 差速运动学口径

`velocity` 执行器的 `ctrl` 单位是**轮子角速度 (rad/s)**，不是车体线速度。给定目标车体线速度 `v`、角速度 `omega`，差速逆解为：

```
ω_L = v/R - ω·L/(2R)
ω_R = v/R + ω·L/(2R)
```

## 验证结果（本机 mujoco 3.17.0 实测）

`python3 main.py --headless` 实测：

- 已到达；步数 `1435`，仿真时长 `7.17 s`；
- 判据触发时位置 `(3.008, 1.882) m`，距目标 `0.118 m`（小于 `0.12 m` 到达阈值；为判据触发瞬间位置，未继续滑行到静止）；
- 先原地转向对准目标方向，再直行逼近，直行段航向误差由比例增益持续修正，无边界极限环。

## 演示 GIF 复现

文档站 GIF 由 `test/record_demo_gif.py` 离屏渲染生成，不是另外录屏。无头环境用 EGL 软件渲染即可，在包目录执行：

```bash
python3 test/record_demo_gif.py
```

脚本复用 `main.py` 的目标点与控制律，输出到 `docs/img/ground/mujoco_diff_drive_go_to_goal_demo.gif`。闭环 `1435` 步、每 `8` 步录一帧抽稀为 `179` 帧，实测 960×720、每帧 40 ms，总时长约 `7.16 s`（实时 1:1），文件 761,153 B（0.73 MB）。

## 已知限制

- 只验证固定目标点 `(3.0, 2.0)` 与原点起点；其他起点/目标未做回归；
- 到达判据只看位置距离，不约束最终车头朝向；
- 速度与增益为初始取值，未做整定优化；
- 仅在 mujoco 3.17.0（`>=3.2,<4.0` 区间内）上验证，区间内其他版本与更早版本未做回归；
- 录帧依赖 EGL/OpenGL 离屏上下文；个别极简容器若未带 mesa 软件渲染库，需先装好 EGL 驱动。
