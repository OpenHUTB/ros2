# ride_comfort_transmissibility：乘坐舒适性传递率

路面是一段段不同频率的起伏。车过某段搓板路时抖得厉害、换个车速又平稳了，
原因是悬架对不同频率的输入放大倍数不一样 —— 这就是**传递率**。
这个模块把它算清楚：共振在哪个频率、放大多少倍、按 ISO 2631-1 属于哪个舒适度等级。

不依赖 CARLA、不需要显示器，纯 Python 标准库，Python 2.7 / 3.x 都能跑。

## 模型

单自由度基础激励（只看垂直方向）：

```
r    = f / f_n                                          频率比
T(r) = sqrt((1 + (2ζr)²) / ((1 − r²)² + (2ζr)²))        位移传递率

峰值位置  r_p = sqrt(1 − 2ζ²)              （ζ ≥ 1/√2 时没有经典共振峰）
峰值大小  T_p = sqrt((1 + 4ζ²(1−2ζ²)) / (4ζ²(1−ζ²)))
高频衰减  T(r) → 0，r = 10 时约 0.05
加权加速度 a_w = T(r) · a_in
```

ISO 2631-1 的舒适度等级（`a_w` 单位 m/s²，RMS）：

| a_w | 等级 |
|---|---|
| < 0.315 | 舒适 |
| 0.315 ~ 0.63 | 略有不适 |
| 0.63 ~ 1.0 | 不适 |
| 1.0 ~ 1.6 | 很不适 |
| 1.6 ~ 2.5 | 极不适 |
| > 2.5 | 无法忍受 |

`damping` 被限制在 `(0, 1/√2)`：超过 0.7071 之后 `sqrt(1−2ζ²)` 没有实数意义，
闭式峰位失效，程序直接报 `RideError`，而不是给一个错的数。

## 默认数字（`config/ride_comfort_transmissibility.yaml`）

| 项 | 值 |
|---|---|
| 悬架固有频率 / 阻尼比 | 1.2 Hz / 0.25 |
| 路面输入 / 激励频率 | 0.5 m/s² / 6.0 Hz |
| 理论峰位 / 峰值 | **0.935414 / 2.280351** |
| 扫描峰位 / 峰值 | 0.948625 / 2.283149（与闭式差 0.12%） |
| r = 1 处传递率 | 2.236068 |
| r = 10 处传递率 | 0.051440 |
| 6 Hz 处加权加速度 | 0.055794 m/s² → 等级「舒适」 |

扫描表（10 个频率比）：

| r | f Hz | T | a_w m/s² |
|---|---|---|---|
| 0.25 | 0.30 | 1.0655 | 0.5328 |
| 0.50 | 0.60 | 1.3038 | 0.6519 |
| 0.75 | 0.90 | 1.8535 | 0.9267 |
| 1.00 | 1.20 | 2.2361 | 1.1180 |
| 1.25 | 1.50 | 1.4024 | 0.7012 |
| 1.50 | 1.80 | 0.8575 | 0.4287 |
| 2.00 | 2.40 | 0.4472 | 0.2236 |
| 3.00 | 3.60 | 0.2215 | 0.1107 |
| 5.00 | 6.00 | 0.1116 | 0.0558 |
| 10.00 | 12.00 | 0.0514 | 0.0257 |

注意 r = 1（激励频率等于固有频率）时 T 是 2.236，但**真正的峰值 2.283 出现在
r ≈ 0.949**，略低于共振比 —— 阻尼越大，峰位越往左偏。这是很多人会算错的地方。

## 四条断言

| 断言 | 判据 | 默认结果 |
|---|---|---|
| 共振位置 | 扫描峰位与 `sqrt(1−2ζ²)` 的偏差 ≤ 0.02 | PASS（0.0132） |
| 峰值倍率 | 扫描峰值与闭式峰值的相对偏差 ≤ 5% | PASS（0.12%） |
| 高频衰减 | `T(r=10) ≤ 0.1` | PASS（0.0514） |
| 输入线性 | 输入加倍后 `a_w` 精确加倍 | PASS（0.0000） |

| 参数 | 默认 | 说明 |

## 跑起来

```bash
cd ~/catkin_ws19 && catkin_make
source /opt/ros/melodic/setup.bash
source ~/catkin_ws19/devel/setup.bash
roslaunch ride_comfort_transmissibility main.launch
```

默认 `结论：PASSED`。两个有意思的反例：

```bash
# ① 容差收到 0.001 → 扫描精度不够，只翻「共振位置」
roslaunch ride_comfort_transmissibility main.launch pos_tolerance:=0.001

# ② 阻尼降到 0.02（坏减振器）→ 峰值 25 倍，激励频率挪到 1.2 Hz 就「无法忍受」
roslaunch ride_comfort_transmissibility main.launch damping:=0.02 freq_hz:=1.2
```

反例②很说明问题：四条断言**全部通过**（物理上它自洽），但舒适等级从「舒适」
变成「无法忍受」。断言管的是「算得对不对」，等级管的是「人坐着难受不难受」。

## 常见问题

**1. 为什么峰值不在 r = 1？**
`T(1) = sqrt(1+(2ζ)²)/(2ζ)`，而真正的极值点在 `r = sqrt(1−2ζ²)`。ζ = 0.25 时
r_p = 0.935，峰值比 T(1) 高约 2%。阻尼越大偏得越多，这也是判据要写「峰位」
而不是直接拿 r=1 当峰的原因。

**2. `damping:=0.8` 为什么直接报错？**
超过 `1/√2 ≈ 0.7071` 以后曲线没有经典共振峰，`sqrt(1−2ζ²)` 是虚数。与其给一个
错的峰位，不如判参数非法 —— 现实里的悬架阻尼比也不会到 0.8。

**3. 高通/低通行为怎么读？**
`r → 0` 时 `T → 1`（车身跟着路面一起动，等于没有悬架）；`r → ∞` 时
`T → 0`（悬架把高频震动滤掉了）。所以舒适性设计的目标是把共振峰挪到人最不敏感
的低频、同时把峰压下去，也就是「加大阻尼」。
