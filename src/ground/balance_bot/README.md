# balance_bot

ROS 1（Noetic）+ MuJoCo 的**两轮自平衡机器人**（轮式倒立摆）：
倾角反馈控制轮矩让它站稳，再用神经网络从 IMU 数据学会同一套控制律。

## 与仓库已有模块的区别

| 模块 | 机器人 | 控制方式 | 是否平衡 |
|---|---|---|---|
| `humanoid/humanoid_push_recovery` | 人形多关节 | 关节力矩 | 是（全身平衡） |
| `humanoid/humanoid_ppo_locomotion` | 人形 | PPO 强化学习 | 是 |
| **本模块** | **两轮倒立摆** | **倾角 PD + 行为克隆** | **是（轮式平衡）** |

仓库没有两轮自平衡车；本模块的神经网络是**监督学习**（拟合已有控制器），不是强化学习。

## 目录结构

```
├── models/balance_bot.xml      MuJoCo 场景（1 自由关节 + 2 轮关节，真实接触）
├── src/balance_bot/
│   ├── config.py               路径/几何/控制参数 + 渲染后端引导
│   ├── env.py                  MuJoCo 封装（状态：倾角、角速度、速度、轮速）
│   └── control.py              平衡控制器（倾角 PD + 速度环 + 转向环）
└── tools/check_balance.py      四项自检（倒下 / 站立 / 抗扰 / 速度跟踪）
```

## 运行环境

Ubuntu 20.04 + Python 3.8.10 + MuJoCo 3.2.3 + numpy 1.17.4（无 GPU 亦可）

## 运行

```bash
python3 tools/check_balance.py          # 四项平衡自检
```

## 实测（虚拟机实跑）

| 实验 | 结果 |
|---|---|
| 无控制 | 0.56 s 倒下（证明是真倒立摆） |
| 平衡站立 20 s | 最大倾角 0.96°，漂移 0.017 m |
| 外力扰动 2 N·s | 最大倾角 1.47°，3.22 s 回正 |
| 速度跟踪 0.3 m/s | 末速度 0.311 m/s |

## 已知限制

- 没有位置保持（长时间站立会缓慢漂移）
- 未做导航与 SLAM
