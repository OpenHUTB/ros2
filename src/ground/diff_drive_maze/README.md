# diff_drive_maze

MuJoCo 差速小车走迷宫仿真：蓝色四轮差速小车（后两轮驱动、前两轮被动随动）从起点 `(-2.0, -2.0)` 出发，沿预设走廊航点
闭环转向、直行，绕过一道 L 型隔墙（横墙 + 竖墙），到达绿色终点 `(2.0, 2.0)` m；途中接触
墙壁判失败，进入终点附近判成功。

## 运行环境（实际验证）

| 项 | 版本 |
|---|---|
| 操作系统 | Ubuntu（无头云主机，无独立显卡） |
| Python | 3.12.11 |
| 模拟器 | MuJoCo `>=3.2,<4.1`（本机实测 3.17.0 与 4.0.0，结果一致） |
| 关键依赖 | numpy 1.26.4；Pillow 仅录帧导出 GIF 时需要；MuJoCo 不在 apt 仓库，需 pip 安装 |
| 渲染后端 | 可视化用 `MUJOCO_GL=glfw`；无头离屏录帧用 `egl`（mesa 软件渲染，无独立显卡也可出图） |

## 安装

```bash
# 先进入本包目录（仓库内 checkout 路径如下）：
cd src/ground/diff_drive_maze
pip install -r requirements.txt
```

## 运行

在**包目录**下直接运行脚本：

```bash
python3 main.py              # 打开 MuJoCo 窗口，关闭窗口即退出
python3 main.py --headless   # 无头模式：到达终点 / 撞墙 / 超时后打印结果退出（无窗口）
```

也可以在 source 过 ROS 2 工作空间后用 ros2 launch 拉起：

```bash
ros2 launch diff_drive_maze main.launch.py                # 开窗可视化
ros2 launch diff_drive_maze main.launch.py headless:=true # 无头模式
```

## 模型与参数

- 车体：蓝色长方体底盘，**后两轮**由 `velocity` 执行器驱动，**前两轮**为无执行器的被动随动轮（支撑与滚动，避免车体前倾、底盘擦地）；
- 轮半径 `R=0.05 m`，左右轮间距 `L=0.22 m`；
- 隔墙：横墙 `wall_h`（中心 `(-0.75, 0.0)`）、竖墙 `wall_v`（中心 `(0.5, 1.0)`），相接成 L 型，参与碰撞；
- 终点：绿色小球 `(2.0, 2.0) m`，只作可视化标记，不参与碰撞；
- 走廊航点 `(2.0, -2.0)`、`(2.0, 2.0)`；巡航直行速度 `0.5 m/s`，原地转向角速度 `1.5 rad/s`，直行航向比例增益 `K=3.0`；
- 转入阈值 `0.5 rad`、转回阈值 `0.3 rad`（滞回）；航点到达 `0.15 m`；终点到达判据 `0.12 m`；步数上限 `20000`（`dt=0.005`，兜底 100 s）。

## 差速运动学口径

`velocity` 执行器的 `ctrl` 单位是**轮子角速度 (rad/s)**，不是车体线速度。给定目标车体线速度 `v`、角速度 `omega`，差速逆解为：

```
ω_L = v/R - ω·L/(2R)
ω_R = v/R + ω·L/(2R)
```

## 验证结果（本机 mujoco 3.17.0 与 4.0.0 实测，结果一致）

`python3 main.py --headless` 实测：

- 到达终点；步数 `4491`，仿真时长 `22.46 s`；
- 终止位置 `(2.002, 1.884) m`，距终点 `0.116 m`（小于 `0.12 m` 到达阈值）；
- 闭环过程未接触墙壁；
- 车体中心到墙盒体表面（含墙端）的最小距离：横墙 `1.714 m`、竖墙 `1.446 m`（按无限平面算会被墙端外穿越误判，故以此口径为准）；
- 车体支撑：**底盘与地面接触 `0` 步（0.0%）**，最大俯仰角 `2.98°`，底盘最低 `z=0.099 m`（名义 `0.10 m`），四轮着地、无底盘擦地。

## 演示 GIF 复现

文档站 GIF 由 `test/record_demo_gif.py` 离屏渲染生成，不是另外录屏。无头环境用 EGL 软件渲染即可，在包目录执行：

```bash
python3 test/record_demo_gif.py
```

脚本复用 `main.py` 的起点、终点、隔墙、航点与控制律，输出到 `docs/img/ground/diff_drive_maze_demo.gif`。闭环 `4491` 步、每 `16` 步录一帧，实测 768×576、`280` 帧、每帧 `80 ms`、文件 `525,989` B（脚本直出实测 `823,688 B`，入库前用 ffmpeg 调色板量化压到 `525,989 B`）。

## 测试

```bash
python3 test/test_diff_drive_maze.py
python3 -O test/test_diff_drive_maze.py   # 断言不会被 -O 剔除
```

`unittest.TestCase` 共 `9` 项：角度归一化、四元数解 yaw、差速逆解、到达判据、航点切换、初始位姿、闭环到达且未撞墙、接触墙壁的撞墙判定，以及车体由四轮支撑（底盘-地面接触 0 步、俯仰角 < 5°）。

## 已知限制

- 只验证固定起点 `(-2.0, -2.0)`、终点 `(2.0, 2.0)` 与当前 L 型隔墙位置；其他布局未做回归；
- 走廊航点为预设固定序列，未做实时避障或全局路径规划；
- 到达判据只看位置距离，不约束最终车头朝向；
- 速度与增益为初始取值，未做整定优化；
- 在 mujoco **3.17.0 与 4.0.0**（本机实测，均属 `>=3.2,<4.1` 区间内）上验证通过，两者闭环结果与测试一致；区间内其他版本未做回归；
- 录帧依赖 EGL/OpenGL 离屏上下文；个别极简容器若未带 mesa 软件渲染库，需先装好 EGL 驱动。
