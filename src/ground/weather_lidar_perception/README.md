# 恶劣雨雾天气下相机与激光雷达感知性能对比实验

本目录是「恶劣雨雾天气下相机感知性能对比实验」（`src/ground/weather_perception_benchmark`）
系列的传感器扩展部分：前两场实验都以相机（`sensor.camera.rgb`）为感知对象，
本实验在同一辆车、同一参考位姿、同一四档天气下**同时挂载相机与激光雷达**
（`sensor.lidar.ray_cast`），一次采集得到两套数据，用「相对晴朗基准的退化率」
把两个传感器的退化程度放进同一口径做横向对比。

## 传感器与参数

| 传感器 | 参数 |
|---|---|
| `sensor.camera.rgb` | 800×600，FOV 90°（与实验 1 / 实验 2 完全一致，保证可比） |
| `sensor.lidar.ray_cast` | 32 线，量程 50 m，转速 20 Hz，`points_per_second=200000`，`upper_fov=10`、`lower_fov=-30` |

雷达回波强度受 `atmosphere_attenuation_rate` 控制（blueprint 默认 0.004）。
雨滴与雾滴会对 ~905 nm 激光产生散射与吸收，因此按天气档位递增设定该系数：
清晰 0.004 → 小雨 0.01 → 大雨 0.03 → 浓雾 0.06。
该属性只能在传感器生成时写入，故每档天气前都会用对应系数重建一次雷达。

注意：CARLA 引擎本身不会按天气改变激光回波（雨雾粒子只参与画面渲染、不遮挡激光射线），
上述退化完全来自显式设定的衰减系数。把 `main.py` 中 `LIDAR_ATTENUATION` 的四档取值
全部改为 0.004 重跑，即可得到「雷达对雨雾免疫」的对照结果。

此外，CARLA 的雷达按渲染帧发布（本机世界约 160 FPS，20 Hz 转速下单帧只有约 45° 扇形、约 1000 点），
单帧无法代表整圈。因此在车辆静止的前提下，脚本在固定 0.2 s 时间窗内累积连续多帧点云取并集，
拼成覆盖整圈、约 3 万点的完整扫描；四档天气使用完全相同的窗口，保证可比。

## 指标口径

- 相机：亮度（灰度均值）、对比度（灰度标准差）、边缘密度（Canny 边缘占比 %）
- 雷达：有效点数、平均回波强度、距离 95 分位（近似「能看多远」）、
  近/中/远三个距离区间（<15 m / 15–30 m / ≥30 m）的点数占比
- 跨传感器对比：`退化率 = (晴朗基准 − 退化值) / 晴朗基准 × 100%`，
  把量纲不同的图像指标与点云指标归一化到同一口径

## 使用方法

1. 启动 CARLA 服务端（解压目录下的 `CarlaUE4.exe`）
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python main.py`

## 输出（results/ 目录）

- `weather_lidar_bev.png`：四档天气的点云 BEV 俯视图（按高度着色）
- `weather_multisensor_degradation.png`：相机 / 雷达各指标退化率，以及跨传感器平均退化率对照
- `metrics.csv`：四档天气的相机与雷达指标原始数值

## 依赖

- CARLA 0.9.15（Python 客户端 `carla==0.9.15`）
- numpy、opencv-python、matplotlib
