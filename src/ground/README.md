# 仓储 AGV 多车交通管理

演示多台 AGV 在网格化仓储地图中同时执行运输任务。
核心解决：**多车冲突避让 + 动态路径重规划**。

## 运行

```powershell
cd src/ground/warehouse_agv
python main.py
```

## 场景概览

```
┌──────────────────────────────┐
│ ← 起点区              终点区 →│
├──────────────────────────────┤
│                              │
│  ═════════════════════════   │  ← 货架行（障碍）
│                              │
│  ═════════════════════════   │
│                              │
│  ═════════════════════════   │
│                              │
└──────────────────────────────┘
```

## 算法

1. **A\* 全局路径规划**：每台 AGV 初始独立规划路径
2. **反应式交通管理**：每步检测占用，遇到冲突优先等待
3. **动态重规划**：等待超过阈值时，临时标记他人位置为障碍，重新 A\* 寻路

## 与已有模块的区别

- 不同于 CARLA 场景：CARLA 是仿真实车 + 目标检测，本模块是**纯网格调度**
- 不同于差速小车：差速小车是单辆车的路径跟踪，本模块是**多车间协调**
- 不同于 R2D2：R2D2 是漫游 + 神经网络规划，本模块是**确定性 A\***
