# mujoco_wall_following

MuJoCo 差速小车沿墙巡线仿真：蓝色四轮差速底盘从起点 `(-1.45, -1.45)` 出发，在矩形
闭环走廊内沿预设航点逆时针绕一圈，回到起点附近。控制为**航点闭环 + 右侧射线贴墙 PD
微调 + 前向射线限速防撞**；途中接触墙壁判失败，绕回起点附近判成功。

## 运行环境（实际验证）

| 项 | 版本 |
|---|---|
| 操作系统 | Ubuntu（无头云主机，无独立显卡） |
| Python | 3.12.11 |
| 模拟器 | MuJoCo `>=3.2,<4.1`（本机实测 3.17.0 与 4.0.0，闭环结果与单测完全一致） |
| 关键依赖 | numpy 1.26.4；Pillow 仅录帧导出 GIF 时需要；MuJoCo 不在 apt 仓库，需 pip 安装 |
| 渲染后端 | 可视化用 `MUJOCO_GL=glfw`；无头离屏录帧用 `egl`（mesa 软件渲染，无独立显卡也可出图） |

## 安装

```bash
# 先进入本包目录（仓库内 checkout 路径如下）：
cd src/ground/mujoco_wall_following
pip install -r requirements.txt
```

## 运行

在**包目录**下直接运行脚本：

```bash
python3 main.py              # 打开 MuJoCo 窗口，关闭窗口即退出
python3 main.py --headless   # 无头模式：绕完一圈 / 撞墙 / 超时后打印结果退出（无窗口）
```

也可以在 source 过 ROS 2 工作空间后用 ros2 launch 拉起：

```bash
ros2 launch mujoco_wall_following main.launch.py                # 开窗可视化
ros2 launch mujoco_wall_following main.launch.py headless:=true # 无头模式
```

## 模型与参数

- 车体：蓝色长方体底盘，后两轮由 `velocity` 执行器驱动，前两轮为被动随动支撑轮；
- 轮半径 `R=0.05 m`，左右轮间距 `L=0.22 m`；
- 走廊：四面外墙 `wall_south/north/west/east`，内圈 `x,y∈[-1.9,1.9]`，墙厚 `0.1 m`、墙高 `0.5 m`（XML 中 `size` 是半边长），参与碰撞；
- 航点（逆时针一圈，末航点回到起点）：`(1.45,-1.45)`、`(1.45,1.45)`、`(-1.45,1.45)`、`(-1.45,-1.45)`；
- 巡航直行速度 `0.45 m/s`；转向指令角速度 `1.5 rad/s`（差速逆解下发的目标车体角速度，受轮胎侧滑影响，车体实测偏航速率低于指令值）；直行航向比例增益 `K=3.0`；
- 贴墙目标侧距 `0.28 m`（**射线原点到墙**，换算到车体中心约 `0.43 m`、车身外沿约 `0.33 m`），侧距比例增益 `KP_SIDE=2.8`；前向防撞限速阈值 `0.30 m`；
- 转入阈值 `0.5 rad`、转回阈值 `0.3 rad`（滞回）；中间航点到达半径 `0.18 m`；回起点到达判据 `0.10 m`；步数上限 `20000`（`dt=0.005`，兜底 100 s）。

## 差速运动学口径

`velocity` 执行器的 `ctrl` 单位是**轮子角速度 (rad/s)**，不是车体线速度。给定目标车体线速度 `v`、角速度 `omega`，差速逆解为：

```
ω_L = v/R - ω·L/(2R)
ω_R = v/R + ω·L/(2R)
```

## 验证结果（本机 mujoco 3.17.0 与 4.0.0 实测，结果一致）

`python3 main.py --headless` 实测：

- 绕回起点；步数 `8803`，仿真时长 `44.02 s`；
- 终止位置 `(-1.431, -1.355) m`，距起点 `0.097 m`（小于 `0.10 m` 到达阈值）；
- 有效贴墙段侧距：均值 `0.238 m`、std `0.055 m`、最小 `0.151 m`；
- 最小侧距 `0.151 m`（**侧向射线值 = 射线原点到墙**；射线原点在车体中心右侧 `0.15 m`，换算到车体中心约 `0.301 m`），最小前向距 `0.373 m`；
- 前向限速分支本闭环未触发（`0.373 m` > `SAFE_FRONT=0.30 m`），属未触发的兜底保护；
- 车体中心到四面内墙的最小距离：`x-` `0.305 m`、`x+` `0.301 m`、`y-` `0.435 m`、`y+` `0.312 m`，轨迹整体最小墙距 `0.301 m`；
- 车体支撑：四轮着地，**底盘与地面接触 `0` 步（0.0%）**，最大俯仰角 `2.27°`，底盘最低 `z=0.099 m`（名义 `0.10 m`），
  即车体由轮胎支撑、不发生底盘擦地，`velocity` 执行器轮速到车体位移的差速逆解在全流程成立；
- 闭环过程未接触墙壁。

## 演示 GIF

`docs/img/ground/mujoco_wall_following_demo.gif` 是 MuJoCo viewer 窗口的实际运行录屏（Peek 录制）：`1244×702`、`310` 帧、每帧 `100 ms`（约 `31 s`）、无限循环，文件 `511,620` 字节。

需要重新生成时可任选一条：

1. **录 viewer 窗口**：在包目录 `python3 main.py` 打开交互窗口，用 Peek 等工具录窗口区域；
2. **无头离屏渲染**（另出一份脚本产物，**不是**替换入库录屏）

```bash
MUJOCO_GL=egl python3 test/record_demo_gif.py            # 默认输出 ./wall_following_demo_script.gif
MUJOCO_GL=egl python3 test/record_demo_gif.py --out /tmp/x.gif
```

脚本复用 `main.py` 的起点、航点、走廊、贴墙参数与控制律，**默认输出到当前工作目录**，且会拒绝写入入库文件 `docs/img/ground/mujoco_wall_following_demo.gif`，避免误覆盖录屏。离屏参数为 `768×576`、每 `32` 步录一帧（`8803` 步 `275` 帧）、每帧 `160 ms`，本机实测产物 `280,662 B`（0.27 MB）；与入库录屏的尺寸和帧率不同属正常差异，只要闭环过程一致即可。

## 已知限制

- 只验证当前矩形走廊布局、起点 `(-1.45,-1.45)` 与预设航点序列；其他起点 / 墙布局未做回归；
- 航点为预设固定序列，贴墙与防撞基于局部射线反馈，未做实时全局路径规划；
- 到达判据只看距起点位置距离，不约束最终车头朝向；
- 速度、增益与贴墙偏移为初始取值，未做整定优化；底盘转向存在轮胎侧滑，车体实测偏航速率低于指令角速度；
- 在 mujoco **3.17.0 与 4.0.0**（本机实测，均属 `>=3.2,<4.1` 区间内）上验证通过，两者闭环结果（`8803` 步、终止位置、侧距统计）与 `10` 项单测完全一致；区间内其他版本未做回归；
- 录帧依赖 EGL/OpenGL 离屏上下文；个别极简容器若未带 mesa 软件渲染库，需先装好 EGL 驱动。
