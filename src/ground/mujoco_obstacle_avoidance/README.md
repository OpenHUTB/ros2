# mujoco_obstacle_avoidance

MuJoCo 差速小车避障仿真：蓝色四轮小车（后两轮驱动、前两轮被动支撑）从原点 `(0, 0)` 出发，
前向射线测距提前发现路径上的两个红色圆柱障碍，经「左转绕行 → 横向离开 → 回正」状态机绕开障碍，
再驶向绿色目标点 `(3.0, 0.0)` m。

## 运行环境（实际验证）

| 项 | 版本 |
|---|---|
| 操作系统 | Ubuntu（无头云主机，无独立显卡） |
| Python | 3.12.11 |
| 模拟器 | MuJoCo `>=3.2,<4.1`（本机实测 3.17.0，4.0.0 亦验证通过） |
| 关键依赖 | numpy 1.26.4；Pillow 仅录帧导出 GIF 时需要；MuJoCo 不在 apt 仓库，需 pip 安装 |
| 渲染后端 | 可视化用 `MUJOCO_GL=glfw`；无头离屏录帧用 `egl`（mesa 软件渲染，无独立显卡也可出图） |

## 安装

```bash
# 先进入本包目录（仓库内 checkout 路径如下）：
cd src/ground/mujoco_obstacle_avoidance
pip install -r requirements.txt
```

## 运行

在**包目录**下直接运行脚本：

```bash
python3 main.py              # 打开 MuJoCo 窗口，关闭窗口即退出
python3 main.py --headless   # 无头模式：到达目标点或超时后打印结果退出（无窗口）
```

也可以在 source 过 ROS 2 工作空间后用 ros2 launch 拉起：

```bash
ros2 launch mujoco_obstacle_avoidance main.launch.py                # 开窗可视化
ros2 launch mujoco_obstacle_avoidance main.launch.py headless:=true # 无头模式
```

## 模型与参数

- 车体：蓝色长方体底盘，四轮；后两轮由 `velocity` 执行器驱动，前两轮被动支撑；
- 轮半径 `R=0.05 m`，左右轮间距 `L=0.22 m`；
- 障碍：两个红色圆柱，`(1.2, 0.0)`、`(2.1, 0.0)`，半径 0.1 m；
- 目标点：绿色小球，`(3.0, 0.0) m`，只作可视化标记，不参与碰撞；
- 巡航直行速度 `0.6 m/s`，转向指令角速度 `1.5 rad/s`（差速逆解下发的目标车体角速度；受前两轮被动支撑与轮胎侧滑影响，车体实测偏航速率低于指令值，转向段亦有前移，并非严格原地），直行航向比例增益 `K=3.0`；
- 射线避障触发距离 `0.60 m`，绕行侧向偏移 `0.40 m`，绕行速度 `0.5 m/s`；
- 转入阈值 `0.5 rad`、转回阈值 `0.3 rad`（滞回）；到达判据 `0.12 m`；步数上限 `20000`（`dt=0.005`，兜底 100 s）。

## 差速运动学口径

`velocity` 执行器的 `ctrl` 单位是**轮子角速度 (rad/s)**，不是车体线速度。给定目标车体线速度 `v`、角速度 `omega`，差速逆解为：

```
ω_L = v/R - ω·L/(2R)
ω_R = v/R + ω·L/(2R)
```

## 验证结果（本机 mujoco 3.17.0 实测）

`python3 main.py --headless` 实测：

- 已到达；步数 `3715`，仿真时长 `18.57 s`；
- 终点 `(2.951, 0.107) m`，距目标 `0.118 m`（小于 `0.12 m` 到达阈值）；
- 前向射线仅命中障碍 1 `(1.2, 0.0)`，触发一次主动绕行，到障碍 1 最小中心距 `0.629 m`；障碍 2 `(2.1, 0.0)` 全程未进入前向射线范围，绕行障碍 1 后被抬到 `y≈0.40 m`，以最小中心距 `0.413 m` 侧偏通过（轨迹侧偏结果，非检测到障碍 2 后主动绕行），两障碍均未接触；
- 转向 `1.5 rad/s` 为指令角速度；实测 `turn_left` 段 6.48 s 转 1.277 rad（约 `0.197 rad/s`），x 前移 0.275 m，并非严格原地。

## 已知限制

- 只验证固定起点 `(0, 0)`、目标 `(3.0, 0.0)` 与当前障碍位置；其他布局未做回归；
- 绕行方向固定朝 `+y` 侧，未按障碍左右动态选择；
- 到达判据只看位置距离，不约束最终车头朝向；
- 速度与增益为初始取值，未做整定优化；
- 在 mujoco 3.17.0（本机实测）与 4.0.0（`>=3.2,<4.1` 区间内）上验证通过，区间内其他版本与更早版本未做回归；
- 录帧依赖 EGL/OpenGL 离屏上下文；个别极简容器若未带 mesa 软件渲染库，需先装好 EGL 驱动。
