# ros2_usv_station_keeping —— 欠驱动水面无人艇低速定点保持

小型 USV（无人艇）最常被要求做、又最容易翻车的一件事是**"停在那个点上别动"**。
难点不在控制律，而在两个物理事实：

1. **船没有侧向推进器**。想往右挪 1 米，只能先转头、再前进，或者干脆斜着顶流；
2. **水面一直在流**。在流速 0.25 m/s 的水里，"停在原地"意味着船必须以 0.25 m/s 逆流
   持续推进——任何"到点就关机"的逻辑都会立刻被冲走。

本模块把这两件事写成可以离线复现的一整套方案：几何制导（解出"船头该朝哪、该多快"）、
在线流估计（不假设知道流速）、推进器健康判定与降级策略，以及六个可复现场景和对应的
量化指标。核心算法只依赖 NumPy，**不需要 ROS 与任何仿真器就能跑完所有结论**。

## 快速开始（离线，不需要 ROS）

```bash
cd src/water/ros2_usv_station_keeping
pip install -r requirements.txt

python main.py                 # 跑 6 个场景，打印指标表并生成配图
python main.py --no-sweep      # 跳过流速扫描，更快
python -m pytest tests -q      # 86 项测试，约 1 s
bash ci/run_ci.sh              # 语法/依赖/测试/闭环 四阶段自检
```

在线运行：

```bash
ros2 launch ros2_usv_station_keeping station_keeping.launch.py target_x:=2.0 target_y:=-1.0
ros2 topic echo /station_keeping/status
```

## 核心思路

**制导**：给定期望世界速度 `v_des`（由位置误差算出）与流速 `c`，求解

```
u·dir(psi) + c = v_des
  =>  psi_des = atan2((v_des - c)_y, (v_des - c)_x)
      u_des   = |v_des - c|
```

无流时退化为"船头指向目标"；完美保持时 `v_des = 0`，得到 `psi = 流的反方向`、
`u = |c|`——正是顶流悬停。航向与目标方位的夹角就是 crab angle。

**流估计**：不能用"位置差分 − 船体速度"。船被顶住时位置不动、地速也为零，残差恒为 0，
估计器会一直认为没有流。改成从动力学反解：

```
c_x = u − (X − m_u·u̇)/d_u
c_y = v + (m_v·v̇ + m_u·u·r)/d_v
```

加速度由速度差分得到，噪声用低通压下去；代价是依赖船体参数标定。

**降级**：效率估计 + 两条兜底判据（持续打转、推力打满仍在漂）。一旦判定保不住，
输出零推力并上报——单侧失效的双推进器船在物理上无法同时满足"推力"与"力矩"，
继续满推只会把电耗在画圈上。

## 离线结果

6 个场景 × 180 s、20 Hz、含 GPS/罗经/计程仪噪声（固定随机种子，可复现）：

| 场景 | RMS 误差 | 峰值误差 | 收敛时间 | 能耗 | 平均 crab | 结论 |
|---|---|---|---|---|---|---|
| `calm` 静水 | **0.079 m** | 3.61 m | 12.2 s | 26 | 0° | 基础收敛正常 |
| `cross_current` 横流 0.25 | **0.229 m** | 3.67 m | 15.9 s | 320 | 12° | 顶流悬停成功 |
| `oblique_current` 斜流 | **0.234 m** | 3.86 m | 16.0 s | 306 | 7° | 非正交方向同样有效 |
| `gust` 阵风 | **0.457 m** | 3.81 m | — | 387 | 9° | 抖动来自流估计滞后 |
| `degraded_thruster` 单侧 55% | **0.211 m** | 3.64 m | 16.7 s | 335 | 15° | 自动放宽死区，仍能保持 |
| `failed_thruster` 单侧失效 | 漂移 | — | — | **42** | — | 判定 FAILED 并停机上报 |

两个关键对照：

- **关掉横漂补偿**，同一横流场景的 RMS 误差从 0.23 m 升到 0.6 m 以上（见
  `crab_compare.png`）——证明"航向偏置"不是可选项；
- **单侧失效**后能耗从 ~335 降到 42：不再无谓挣扎，把位置留给上层决策。

## 已知限制

- 全部结论来自**离线 2D 平面仿真**，未在真实船体上闭环验证；
- 流估计依赖船体质量/阻尼参数标定，参数偏差会直接变成"假流"；
- 流速低于 0.15 m/s 时估计残差与真实流同量级，模块按"无流"处理，此时横向误差靠
  控制环而非前馈纠正；
- 阵风场景的 RMS 明显高于恒定流，因为流估计（时间常数约 1 s）跟不上 3.5 s 相关时间
  的扰动；
- 传感器只有 GPS/罗经/计程仪，没有 DVL 与推进器电流反馈——真实船舶若有这两者，
  流估计与失效检测都会显著更准。
