# AUV 水质监测自主采样任务

演示多 AUV 在指定水域内执行网格化水质采样任务。
任务规划器结合 **TSP 贪心最近邻** 与 **优先级调度**，
自动将采样点分配给多 AUV 并生成覆盖巡游路径。

## 运行

```powershell
cd src/water/water_monitoring
python main.py
```

## 核心流程

```
┌─────────────┐    ┌─────────────────┐    ┌──────────────────┐    ┌────────────┐
│ 生成采样网格 │───▶│ 按优先级分配给AUV│───▶│ TSP 生成巡游路径 │───▶│ AUV 执行采样│
└─────────────┘    └─────────────────┘    └──────────────────┘    └────────────┘
```

## 采样数据模拟

| 区域 | pH | 溶解氧 | 浊度 | 优先级 |
|------|----|--------|------|--------|
| 中心疑似污染区 | 5.5~7.0 | 2~5 mg/L | 15~30 NTU | 0.9 |
| 其他区域 | 6.5~8.5 | 6~10 mg/L | 0.5~5 NTU | 0.2~0.6 |

## 依赖

- Python 3.10+
