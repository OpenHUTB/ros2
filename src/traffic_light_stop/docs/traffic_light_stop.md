# 红绿灯启停（Traffic Light Stop）设计文档

## 1. 项目概述

实现车辆在道路直线行驶时对路口红绿灯的自动响应：

- **绿灯**：以巡航速度 10 m/s 行驶；
- **红灯/黄灯**：自动减速，车头在停止线（x=50 m）前 1 m 处停稳；
- **变绿**：自动起步，通过路口后恢复巡航。

项目同时提供纯 Pygame 演示（无 ROS）与 ROS Noetic 节点入口，适合作为
ROS2 教学仓库的作业示例。

## 2. 系统架构

```
┌────────────┐   灯色    ┌──────────────┐  加速度  ┌──────────────┐
│ TrafficLight│ ───────▶ │ StopController │ ──────▶ │ VehicleModel  │
│ (红绿灯状态机)│          │ (停车控制器)   │          │ (一维车辆模型) │
└────────────┘          └──────────────┘          └──────┬───────┘
        ▲                                                │ 位姿/速度
        │  (ROS 版可从 /traffic_light 话题读取)           ▼
┌─────────────────────────────────────────────────────────────┐
│                traffic_light_sim.py (Pygame 可视化)          │
│  渲染：道路 / 停止线 / 红绿灯 / 车辆 / HUD，支持无头录制动图   │
└─────────────────────────────────────────────────────────────┘
```

- `headless_test.py`：无界面跑完整灯周期并断言关键指标；
- `main.py`（ROS 版）：把期望速度发布到 `/cmd_vel`，灯色可从话题订阅。

## 3. 模块说明

### 3.1 vehicle_model.py —— 一维车辆运动学

状态 `(x, v)`，输入加速度 `a`，欧拉积分：

```
v_new = v + a * dt        （速度不为负）
x_new = x + (v + v_new)/2 * dt
```

`head() = x + 车长(4.4 m)` 表示车头位置，用于停止线约束。

### 3.2 traffic_light.py —— 红绿灯状态机

按相位序列循环：`[(4,'green'), (1,'yellow'), (9,'red'), (12,'green')]`。
`cycle = t % total` 定位当前灯色，单步 `O(相位数)`。

### 3.3 stop_controller.py —— 停车控制律

核心：**平方根减速度曲线**。

红灯/黄灯时，车头剩余可行驶距离：

```
d = (stop_x - safety) - x_head
```

允许的最大安全速度（以减速度 a_max 恰好停在停止线前）：

```
v_max(d) = sqrt(2 * a_max * d)
```

控制律（一阶趋近 + 兜底）：

```
若 d <= 0 或 v^2/(2*a_max) >= d*0.95：  a = -a_max        # 全力刹车兜底
否则：                                 v_target = min(v_cruise, v_max(d))
                                       a = clamp((v_target - v)/tau, -a_max, a_acc)
```

兜底条件保证即使一阶追踪存在滞后，也不会越线。

### 3.4 traffic_light_sim.py —— Pygame 可视化

侧视滚动视野：车道虚线、10 m 里程碑、停止线、红绿灯（三色圆灯）、车辆矩形。
HUD 实时显示：灯色 / 速度 / 距停止线距离 / 状态 / 时间。
支持 `--record demo.gif --duration 25` 无头录制演示动图（Pillow 合成）。

### 3.5 main.py —— ROS 节点入口

- 发布 `/cmd_vel`（`geometry_msgs/Twist`，linear.x = 期望速度）；
- 订阅 `/traffic_light`（`std_msgs/String`：red/green/yellow），
  未收到话题时使用内部模拟灯色；
- 窗口交互与 Pygame 版一致（空格开始/暂停、R 重置、ESC 退出）。

## 4. 关键参数

| 参数 | 值 | 含义 |
|---|---|---|
| v_cruise | 10 m/s | 巡航速度（36 km/h） |
| stop_x | 50 m | 停止线位置 |
| safety | 1.0 m | 车头距停止线的安全余量 |
| a_max | 3.0 m/s² | 最大减速度 |
| a_acc | 2.0 m/s² | 最大加速度 |
| tau | 0.5 s | 速度一阶趋近时间常数 |
| DT | 0.05 s | 仿真步长（20 Hz） |

## 5. 测试结果

`python headless_test.py`（25 s，完整灯周期）：

| 指标 | 结果 | 要求 |
|---|---|---|
| 红灯期间车头距停止线最小距离 | 0.94 m | > 0（不越线） |
| 红灯停稳位置（车头） | 49.06 m | 停止线前 0.3~2.5 m |
| 绿灯后通过停止线时间 | 15.0 s | 红灯结束(14 s)之后 |
| 全程最大速度 | 10.00 m/s | ≤ 巡航 + 0.5 |

结果：**PASS**。演示动图见 `docs/traffic_light_demo.gif`。
