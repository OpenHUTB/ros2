# MuJoCo 红绿灯响应仿真

基于 MuJoCo 的差分小车红绿灯响应仿真，实现「红灯停、黄灯慢行、绿灯通行」逻辑。

## 环境

- Ubuntu 20.04
- Python 3.8+
- MuJoCo Python 库

```bash
sudo apt install python3-pip
pip3 install mujoco numpy
```

## 运行

```bash
python3 main.py
```

## 文件说明

| 文件        | 说明                                              |
|-------------|---------------------------------------------------|
| `scene.xml` | MuJoCo 场景：地面、红绿灯支架、方块小车（slide 关节） |
| `main.py`   | 主控制逻辑：信号灯时序 + 小车停止线响应 + 运行日志    |

## 控制逻辑

- 信号灯时序：红灯 5s → 黄灯 2s → 绿灯 5s，循环。
- 小车沿 x 轴平移，向红绿灯行驶。
- 到达停止线后：
  - 红灯：施加反向制动力刹停，速度归零后锁死，不后退。
  - 黄灯：小推力慢速通过。
  - 绿灯：正常推力通行。
