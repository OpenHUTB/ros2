# 项目 13：机械臂拧螺丝 —— 设计与验证

## 1. 任务

三自由度空间机械臂末端夹持竖直螺丝刀，对准桌面木板上的螺丝，
连续旋转 2.5 圈（900°）按螺距把螺丝拧入桌面螺孔，再抬起撤离。
完整演示"接近 → 对准下压 → 旋转拧入 → 抬起"。

## 2. 机械臂模型

| 部件 | 说明 |
|---|---|
| 肩方位 yaw | hinge 轴 (0 0 1)，范围 ±180° |
| 肩俯仰 pitch1 | hinge 轴 (0 -1 0)，范围 ±120° |
| 肘俯仰 pitch2 | hinge 轴 (0 -1 0)，范围 ±150° |
| 杆长 | L1 = L2 = 0.30 m，肩俯仰中心高 0.06 m |
| 螺丝刀 | 竖直杆（半径 0.009 m、长 0.10 m）+ 十字刀头，刀头位于末端 tip 下方 0.11 m |
| 螺丝 | 半径 0.019 m、半高 0.023 m 的圆柱 + 顶部十字槽 + 底部锥头 |
| 桌面 | 木板 box（0.26×0.22×0.02 m）+ 深色螺孔标记 |

## 3. IK 与构型选择（关键）

对目标点 (x, y, z)（z 以肩俯仰中心为基准）：

```
r    = hypot(x, y)
d    = hypot(r, z)
yaw  = atan2(y, x)                        # 肩方位
q2   = −acos((d² − L1² − L2²) / (2 L1 L2)) # 负解：肘抬到肩上方
q1   = atan2(z, r) − atan2(L2 sin q2, L1 + L2 cos q2)
```

**为什么必须取负解**：螺丝位于桌面上，目标点离肩只有约 0.21 m，而臂长
0.60 m，二连杆必须折叠约 139°。正解（q2 > 0）会把肘压到地面以下
（z ≈ −0.15 m），L1/L2 整段被地面挡住，画面里只剩一截杆"从桌面长出来"；
负解（q2 < 0）让肘抬到肩上方（约 z = 0.36 m），L2 从上往下伸到螺丝，
形成正常的"俯身拧螺丝"姿态。

实测三个目标点逆解→正解误差 0.00 mm。

## 4. 时间线

| 段 | 帧 | 时间 | 动作 |
|---|---|---|---|
| APPROACH | 0–70 | 0–0.28 s | 从 HOME (0.14, 0, 0.20) 移到螺丝上方 0.22 m 高处 |
| PRESS | 70–110 | 0.28–0.44 s | 下压对位，刀头贴住螺丝顶面 |
| SCREW | 110–350 | 0.44–1.40 s | 旋转拧入 900°，螺丝同步下沉 40 mm，刀头跟随下压 |
| LIFT | 350–420 | 1.40–1.68 s | 抬起撤离 |
| HOLD | 420–450 | 1.68–1.80 s | 停留展示拧好的螺丝 |

## 5. 螺丝下沉与旋转

螺丝绕 z 轴旋转 theta 的四元数 `quat_z(theta)`，同时中心高度按
转角线性下沉：

```
sz(theta) = SCREW_TOP_Z − 40 mm × (theta / 900°)
```

初始螺丝中心 0.020 m（顶面 0.043 m，露出板面 23 mm），
终了中心 −0.020 m（顶面 0.003 m，低于板面 0.020 m，完全拧入）。
螺丝刀刀头与螺丝同步旋转，tip 高度 = `sz + 螺丝半高 + 刀头偏移`，
保证刀头始终贴住螺丝顶。

## 6. 控制方案

臂采用**运动学插值驱动**：每帧 qpos 向 IK 目标角逼近（最大步长
0.07 rad/帧），随后 `mj_forward` 更新运动学并渲染，不积分动力学。
原因：臂杆质量轻（默认密度 1000），重力角加速度极大，手写 PD /
position 执行器均无法收敛（实测动态末端误差达 353 mm）。

## 7. 渲染与视觉

- 相机：lookat (0.11, 0.04, 0.14)、distance 0.98、azimuth 60°、elevation −30°
- 顶部状态条实时显示 `SCREW DRIVING turns x.xx / 2.5  depth xx / 40 mm`
- 黄色线：臂末端 tip 轨迹；青色线：刀头螺旋下降轨迹（旋转+下沉的合成）
- 螺丝顶十字槽随旋转转动，直观显示"正在拧"
