# 基于 MuJoCo 的机械臂抓取搬运（Pick & Place）

## 1. 问题描述

给定一个带末端工具的平面机械臂：两连杆臂（肩关节 shoulder + 肘关节 elbow，
水平面内绕 Z 轴旋转，L1 = L2 = 0.30 m），末端带**垂直升降关节（lift）** 与
**旋转夹爪（grip）**。地面上 A、B 两处各有一个托盘柱（柱顶高度 0.05 m），
蓝色小球（球心 z = 0.08 m）初始在 A 点柱顶。

要求机械臂自动完成：**从 A 点夹起小球，搬运到 B 点并放下**，全程可视化。

这是一个典型的**机械臂逆运动学（IK）+ 轨迹规划 + 抓取控制**问题：

- 水平面内已知末端目标 (x, y)，用解析 2 连杆 IK 求 (q1, q2)；
- 垂直方向用升降关节控制夹爪高度（抓取时降到球心高度，搬运时抬起）；
- 小球用**逻辑吸附**跟随夹爪（不做物理夹持，避免接触反弹），释放后落在 B 点；
- 末端走过的路径投影到像素，用黄色轨迹线画出。

## 2. 算法

### 2.1 二连杆解析逆运动学（ik2）

与平面二连杆机械臂相同：

```
x = L1·cos(q1) + L2·cos(q1+q2)
y = L1·sin(q1) + L2·sin(q1+q2)
```

逆解：`cos(q2) = (x²+y²-L1²-L2²)/(2·L1·L2)`，`q2 = acos(clamp(...))`（肘下姿势），
`q1 = atan2(y,x) - atan2(L2·sin(q2), L1+L2·cos(q2))`；超出工作空间返回 None。

### 2.2 PD 位置控制

```
τ_水平 = KP_H·(q目标 - q) - KD_H·q̇      （KP_H=100, KD_H=25）
τ_升降 = KP_L·(lift目标 - lift) - KD_L·l̇  （KP_L=200, KD_L=20）
```

`mj_step` 三细分步进（timestep = 0.002 s），水平移动 4 秒内从 A 到达 B 上方。

### 2.3 分段任务调度

9 段时间轴（秒），每段给出目标 (x, y, lift, grip, 是否允许吸附)：

| 段 | 时间 | 动作 |
|---|---|---|
| 1 | 0 → 0.5 | 保持高位在 A 上方就位 |
| 2 | 0.5 → 1.0 | 下降到球心高度（lift = -0.09） |
| 3 | 1.0 → 1.5 | 夹爪闭合，接近球时吸附 |
| 4 | 1.5 → 2.2 | 抬升（lift = 0.08） |
| 5 | 2.2 → 5.4 | 水平移动到 B 上方 |
| 6 | 5.4 → 7.0 | 下降到 B（留足时间） |
| 7 | 7.0 → 7.2 | 张开夹爪释放 |
| 8 | 7.2 → 7.8 | 保持低位让球落稳 |
| 9 | 7.8 → 8.4 | 收回高位 |

### 2.4 抓取与球的位置控制（逻辑吸附）

- 夹爪几何与球**无物理接触**（夹爪中心降到球心高度附近时即视为"抓住"）；
- 吸附后每帧把球 qpos 设到夹爪中心、球 qvel 清零，球完全跟随夹爪；
- 未吸附时球钉在 A，释放后钉在 B；球全程无碰撞反弹、无滑走；
- 最终球精确停在 B 点 `(0.45, -0.15, 0.0799)`。

### 2.5 渲染与轨迹投影（DLT 相机标定）

- 相机：自由相机斜视角 3D（lookat (0.3, 0.05, 0.08)、distance 0.8、
  azimuth 30°、elevation -55°、fovy 45°）；
- 渲染：`mujoco.Renderer` 离屏渲染（`MUJOCO_GL=osmesa` 软渲染，虚拟机可用）；
- 标定：渲染 10 组工作区内的机械臂姿态，提取末端红色小球的像素质心，
  用最小二乘反解 3×4 投影矩阵（重投影误差 < 1 px）；
- 轨迹：每帧把末端 3D 位置经投影矩阵映射到像素，用 PIL 画黄色轨迹线。

## 3. 模型参数（arm_gripper.xml）

| 部件 | 参数 |
|---|---|
| 底座 | 圆柱，半径 0.09 m，高 0.03 m（顶面 Z = 0.15） |
| 第一段杆 link1 | 胶囊体，半径 0.035 m，长 0.30 m，蓝色 |
| 第二段杆 link2 | 胶囊体，半径 0.028 m，长 0.27 m，橙黄色 |
| 升降连接杆 | 细圆柱（保持 body 质量） |
| 夹爪 | 底座盒 + 两片手指盒（旋转关节 grip，张开 -0.4 / 闭合 0） |
| 末端红球 tip | 球，半径 0.018 m（相机标定/轨迹用） |
| 小球 | 球，半径 0.03 m，蓝色，密度 177（约 0.02 kg），condim=4 |
| A/B 托盘柱 | 圆柱，半径 0.02 m，高 0.05 m（柱顶 z = 0.05，球心 z = 0.08） |
| 关节 | shoulder/elbow hinge + lift slide + grip hinge，各配 motor（±30） |
| 物理 | gravity 9.81 m/s²，timestep 0.002 s |

## 4. 运行

```bash
pip3 install --user mujoco pillow numpy
sudo apt install -y libosmesa6-dev       # 无显卡环境
MUJOCO_GL=osmesa python3 mujoco_arm_pick.py
```

输出 `demo_pick.gif`（640×480，24 fps，201 帧 / 8.4 秒）。

## 5. 效果说明

- 0.5 s 开始下降，约 1.2 s 夹爪中心到达球心高度，小球被吸附跟随夹爪；
- 2.2 s 抬升后水平移动，5.4 s 到达 B 上方，7.0 s 下降到 B 并张开夹爪释放；
- 小球落在 B 点托盘柱顶，最终位置 (0.45, -0.15, 0.08)，全程无反弹、无滑走；
- 黄色轨迹线全程跟随末端，直观展示「夹起 → 搬运 → 放下」的路径。
