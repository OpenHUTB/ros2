# 基于 MuJoCo 的双机械臂协同搬运

## 1. 问题描述

两台二连杆平面机械臂（肩关节 shoulder + 肘关节 elbow，均在水平面内绕 Z 轴旋转，
连杆长度 L1 = L2 = 0.25 m，另带垂直升降关节 lift 与旋转夹爪 grip）对称布置在台面上，
要求两臂**协同**把一块长木板从 A 区搬运到 B 区：

- 两臂同时下降，夹爪对准木板两端；
- 夹爪闭合后两臂一起抬升，木板随两夹爪移动（木板位姿 = 两夹爪中点 + 朝向角）；
- 两臂保持同步平移，把木板送到 B 区正上方；
- 同时下降放平，张开夹爪释放，木板停在 B 区。

关键点：两臂必须**同步**动作（同一套时间轴调度），夹取与释放的判定要可靠，
木板在搬运全程不倾斜、不掉落。

## 2. 算法

### 2.1 二连杆解析逆运动学（ik2）

与单臂项目一致：对平面二连杆机械臂，末端位置与关节角的关系为

```
x = L1·cos(q1) + L2·cos(q1+q2)
y = L1·sin(q1) + L2·sin(q1+q2)
```

逆解：

```
cos(q2) = (x² + y² - L1² - L2²) / (2·L1·L2)
q2 = acos(clamp(cos(q2), -1, 1))
q1 = atan2(y, x) - atan2(L2·sin(q2), L1 + L2·cos(q2))
```

两臂各自以**自己的底座**为原点解算（臂1 底座 (0.10, 0)，臂2 底座 (0.60, 0)），
臂1 负责木板左端、臂2 负责木板右端，各点均在工作空间内。

### 2.2 关节控制

- 水平关节：PD 位置控制 `τ = KP·(q_target - q) - KD·q̇`，KP=100、KD=25；
- 升降/夹爪：每帧直接位置过渡 `qpos += (goal - qpos) * 0.35`，并清零对应 qvel，
  保证下降、夹取、释放动作平滑且不抖动。

### 2.3 协同调度（时间轴）

| 时间 (s) | 动作 |
|---|---|
| 0.0 → 0.5 | 两臂从初始位同步下降，夹爪中心到木板中心高度（lift = -0.125） |
| 0.5 → 1.0 | 双夹爪闭合 |
| 1.0 → 1.6 | 吸附判定通过后两臂一起抬升（lift = 0.08） |
| 1.6 → 3.0 | 两臂保持高度协同平移，从 A 区两端到 B 区两端 |
| 3.0 → 3.5 | 同步下降放平 |
| 3.5 → 3.9 | 双夹爪张开释放，木板落位 B 区 |
| 3.9 → 4.6 | 两臂抬升收尾 |

**吸附判定**：两臂夹爪 z 均距木板中心高度 < 6 mm，且两夹爪都闭合（|qpos| < 0.05）时
才认为夹取成功，木板开始跟随两夹爪中点运动；释放后木板直接归位 B 区中心。

### 2.4 相机标定与轨迹绘制

- 相机：自由相机，lookat (0.35, 0.05, 0.08)、distance 1.05、azimuth 30°、elevation 25°；
- 标定：DLT 算法——渲染 10 组臂1 姿态，用红色末端球的像素中心与其世界坐标
  反解 3×4 投影矩阵（≥6 点，本机实测 7 点重投影误差 0.41 px）；
- 轨迹：每帧把两臂末端世界坐标投影到像素，用 PIL 叠加两条黄色轨迹线。

### 2.5 渲染

`mujoco.Renderer` 离屏渲染（`MUJOCO_GL=osmesa` 软渲染，虚拟机无显卡可用）；
光源关闭投影（castshadow=false），避免臂杆阴影盖住木板导致颜色失真。

## 3. 模型参数（内嵌 XML）

| 部件 | 参数 |
|---|---|
| 臂1 / 臂2 底座 | 圆柱，半径 0.06 m，位置 (0.10,0) / (0.60,0)，Z=0.15 |
| 第一段杆 link1 | 胶囊体，半径 0.03 m，长 0.25 m；臂1 蓝色 / 臂2 深紫 |
| 第二段杆 link2 | 胶囊体，半径 0.026 m，长 0.25 m，橙色 |
| 升降关节 lift | slide，Z 轴，range -0.20 ~ 0.15 |
| 夹爪 grip | hinge，range -0.55 ~ 0，两片手指 |
| 末端标记球 | 球，半径 0.018 m；臂1 红（标定用）/ 臂2 蓝 |
| 长木板 | box 0.40×0.08×0.05，绿色，free joint |
| B 区标记 | 黄色小球 (0.35, -0.15) |
| 物理 | gravity 9.81 m/s²，timestep 0.002 s |

## 4. 运行

```bash
pip3 install --user mujoco pillow numpy
sudo apt install -y libosmesa6-dev       # 无显卡环境
MUJOCO_GL=osmesa python3 mujoco_arm_dual_single.py
```

输出 `demo_dual.gif`（640×480，24 fps，110 帧 / 4.6 秒）。

## 5. 验证

```bash
MUJOCO_GL=osmesa python3 verify_dual.py ik    # IK 数值精度：逆解→正运动学互查
MUJOCO_GL=glfw   python3 verify_dual.py gui   # 实时渲染：查看器播放完整 4.6s 流程
```

本机实测：

- 相机标定 7 点，平均重投影误差 **0.41 px**；
- IK 精度：8 个夹持点 × 2 臂 逆解→正运动学互查，最大误差 **0.0000 mm**；
- 木板最终位置 **(0.350, -0.150, 0.046)**，与 B 区中心一致。

## 6. 效果说明

- 两臂动作严格同步：同时下降、同时闭合、同时抬升、同时平移、同时放下；
- 搬运全程木板跟随两夹爪中点，无倾斜、无掉落；
- 两条黄色轨迹线分别记录两臂末端路径，A→B 的搬运轨迹清晰可见。
