# 安全与限位增强说明（keyboard_mujoco.py）

> 在原始键盘控制脚本基础上，补齐项目文档「未验证项」第二条：
> **MuJoCo 侧关节目标角为开环递增，未做关节限位检查与碰撞检测，极端输入下的行为未验证。**

原脚本 `keyboard_mujoco.py.bak` 已备份保留，增强版直接覆盖 `keyboard_mujoco.py`。

---

## 一、新增能力一览

| 能力 | 解决的问题 | 实现原理 |
|------|-----------|----------|
| **关节硬限位检查** | 防止关节被推到物理极限之外 | 从模型 `jnt_range` 读取每个关节 `[min, max]`，按键请求越界时**拒绝执行**并提示 |
| **软限位预警** | 提示即将触达边界 | 目标进入距边界 10% 区间时打印警告 |
| **速度限幅与平滑** | 目标突变导致瞬间猛加速 | 写入 `ctrl` 的位置命令以 `MAX_JOINT_SPEED` 为上限做斜坡逼近，实际关节速度被钳制 |
| **碰撞检测（自碰撞保护）** | 极端位形下的连杆相互穿插 | 每步步进后读取 `data.contact`，检测非相邻连杆接触，触发即**回退到碰撞前安全位形**并保护 |
| **急停 E-STOP** | 突发状况即时锁停 | 空格键冻结所有关节命令，再按解除 |
| **步长调节** | 精细/快速操控 | `[` 减步长、`]` 增步长（0.02~0.5 rad） |
| **实时状态面板** | 观察当前姿态与限位状态 | 每 0.5s 刷新一行，标注每个关节是否进入软限位区 |

## 二、新增/变更按键

| 按键 | 功能 |
|------|------|
| `1-7` / `Shift+1-7` | 关节正 / 反向转动（沿用，新增限位与平滑处理） |
| `r` | 复位到初始关键帧（沿用） |
| `[` / `]` | 减小 / 增大单步增量 |
| `空格` | 急停（再按解除） |
| `q` | 退出（沿用） |

## 三、关键参数（文件顶部，可按需改）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MAX_JOINT_SPEED` | `1.0` rad/s | 速度限幅上限，调小更平稳 |
| `JOINT_STEP_DEFAULT` | `0.1` rad | 单次按键目标增量 |
| `SOFT_LIMIT_RATIO` | `0.10` | 距边界多少比例算"接近限位" |
| `STATUS_INTERVAL` | `0.5` s | 状态面板刷新间隔 |

## 四、三个安全特性的工作原理解释

1. **速度限幅（斜坡逼近）**：原脚本按下键后 `target_q` 直接跳变、`ctrl` 立即写满目标，关节会被瞬间驱动。增强版让命令 `ctrl_q` 每帧只朝 `target_q` 前进最多 `MAX_JOINT_SPEED × 实际经过时间`，即使用户把目标一次调大，实际运动也按限速匀速过渡。

2. **碰撞检测为何可靠**：MuJoCo 默认**不**计算"父子 body（相邻连杆）"之间的接触，因此 `data.contact` 里出现的接触必然是非相邻连杆的真实自碰撞，不会因关节连接处误报。检测到后回退到碰撞发生前的命令并进入保护态，反向运动或复位即可脱困。

3. **限位为何读取模型而非写死**：直接从 `model.jnt_range[jnt_ids]` 读取，适配任何版本/配置的 Panda 模型，避免硬编码错误。

## 五、运行与验证

运行方式不变（与 MuJoCo 独立演示一致）：

```bash
cd ~/catkin_ws/src/panda_keyboard_control/mujoco_sim
python3 keyboard_mujoco.py
```

**验证清单**（建议按此逐步自测）：

1. **限位检查**：对某一关节持续按正向键，直到提示 `[限位拒绝]`，确认关节停在硬限位边界、不再越界。
2. **软限位预警**：接近边界时观察 `[警告]` 与状态面板中该关节的 `R` 标记。
3. **速度平滑**：快速连按按键，观察关节是平滑过渡而非瞬间猛跳（对比 `.bak` 旧版更明显）。
4. **碰撞保护**：刻意把两个不相邻关节转到相互靠近的位形，触发 `[碰撞保护]`，确认回退到安全位置。
5. **急停**：运动时按空格，确认所有关节立即冻结；再按空格恢复。
6. **步长调节**：`[`/`]` 改变步长后，观察单步转角变化。

> ⚠️ 本增强版在本环境（无 `mujoco_menagerie` 模型库、未安装 MuJoCo）下**未实机跑通**，以上为设计逻辑与自测建议。实机验证时如遇碰撞误报，可检查 `ARM_BODIES` 是否把夹爪 `hand` 误纳入（当前已按名字过滤）。
