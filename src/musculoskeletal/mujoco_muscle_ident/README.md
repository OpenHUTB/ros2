# MuJoCo 肌肉参数辨识

给定一段"黑箱"关节轨迹，反推肌肉参数——建模时最常遇到的问题：
**手里只有数据，参数得靠拟合**。

五组实验回答：能不能估准、噪声多大就估不动、哪些参数彼此耦合、
初值离多远还收得住、以及**该用什么样的激励去测**。

## 正模型（MuJoCo 关节）

    L      = L0 - r*theta
    F      = Fmax * (a*fl*fv + fp)
    qfrc   = (F_flex - F_ext)*r - b*qd

关节限位 ±1.4 rad 由 MuJoCo 约束求解器处理，重力与惯量也由 MuJoCo 计算。
待辨识参数：`fmax`、`l_opt`、`tau_act`、`r`、`b`。

辨识器是自实现的 **Levenberg–Marquardt**，并在**归一化参数空间** `p/SCALE` 中搜索
（否则各参数量级差 4 个数量级，数值条件极差）。

## 五组实验

### I1 无噪声辨识

平均误差 **0.49%**。

| 参数 | 真值 | 估计 | 误差 |
|---|---|---|---|
| `fmax` | 320.0000 | 319.0926 | 0.28 % |
| `l_opt` | 0.2750 | 0.2746 | 0.15 % |
| `tau_act` | 0.0100 | 0.0098 | 1.99 % |
| `r` | 0.0300 | 0.0300 | 0.00 % |
| `b` | 0.0500 | 0.0500 | 0.04 % |

### I2 噪声敏感性（3 seeds 取中位数）

| 噪声 | 中位误差 | 最大误差 |
|---|---|---|
| 0 % | 0.49 % | 1.99 % |
| 1 % | 0.69 % | 2.09 % |
| 2 % | 0.90 % | 2.20 % |
| 5 % | 1.50 % | 2.66 % |

### I3 参数相关性

协方差由 $(J^TJ)^{-1}\sigma^2$ 得到：

| 参数对 | 相关系数 |
|---|---|
| `fmax` ↔ `r` | -0.96 |
| `tau_act` ↔ `b` | +0.83 |
| `l_opt` ↔ `tau_act` | +0.38 |

### I4 收敛域

| 初值范围（× 真值） | 成功率 | 中位误差 |
|---|---|---|
| 0.9–1.1× | 100 % | 2.0 % |
| 0.8–1.2× | 75 % | 2.0 % |
| 0.6–1.5× | 25 % | 46.3 % |
| 0.5–2.0× | 0 % | 59.8 % |

### I5 激励设计

用 $D$-最优指标 $\det(J^TJ)^{1/p}$ 评估三种激励：

| 激励 | D-最优 | 辨识误差 |
|---|---|---|
| square+sine | 5.09e+03 | 0.49 % |
| chirp | 2.03e+03 | 0.43 % |
| sine | 2.12e+02 | 1.42 % |

**D 指标与辨识误差排序完全一致**——说明可以先用 D 指标筛选激励方案，不必真的做实验。

## 已知限制

1. 单关节、双肌肉，未涉及多关节耦合与冗余肌肉；
2. 只辨识 5 个参数，未含肌腱刚度、羽状角；
3. 正模型为理想 Hill 肌肉 + 刚性肌腱；
4. 未做模型失配（model mismatch）分析；
5. 未接入 ROS 话题。
