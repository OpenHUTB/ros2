# MuJoCo 肌肉驱动夹爪：真实接触抓取

两指夹爪由 **Hill 肌肉**驱动合拢，与方块产生**真实接触摩擦**，抬升时方块完全靠摩擦力跟手。
四组实验回答：肌肉激活多大才夹得住、摩擦系数如何影响、松开后多久会掉。

与"运动学跟随"的演示不同，这里**不对方块施加任何位置或焊接约束**，抓不住就是抓不住。

## 运行环境

| 依赖 | 版本 |
|---|---|
| Python | 3.8+（实测 3.14.3） |
| MuJoCo | 3.0+（实测 3.16.0） |
| numpy | 1.20+ |
| Pillow / matplotlib | 仅 `gif` 与出图需要 |

不依赖 ROS 运行；`launch/` 与 `package.xml` 只是与其他模块统一的包装。

## 运行

```bash
python3 main.py check                 # 模型自检
python3 main.py run --scene g2        # 单个实验
python3 main.py bench --out out       # 四组实验，导出 out/metrics.json
python3 main.py gif --out gif         # 两段动图（抓住 / 打滑）
python3 tools/plot_metrics.py out/metrics.json out
python3 -m unittest discover -s tests # 9 项测试
```

## 四组实验

### G1 肌肉激活 → 夹持力

| 激活 | 夹持力 |
|---|---|
| 0.05 | 1.17 N |
| 0.10 | 2.29 N |
| 0.20 | 4.32 N |
| 0.40 | 7.65 N |
| 0.80 | 12.22 N |

近似线性，斜率约 15 N/单位激活。

### G2 抬升阈值：夹得多紧才抬得起来

抬升目标 100 mm，方块 30 g：

| 激活 | 抬升高度 | 结果 |
|---|---|---|
| 0.05 / 0.10 / 0.20 | ~0 mm | 打滑 |
| **0.40** | **97.8 mm** | 夹住 |
| 0.80 | 98.2 mm | 夹住 |

**阈值在 0.2 与 0.4 之间**，对应夹持力约 5 N。

### G3 摩擦系数的影响

| 摩擦 μ | 激活 0.4 时抬升 |
|---|---|
| 0.3 | 6.4 mm（抬 6 mm 就滑脱） |
| 0.8 | 97.8 mm |
| 1.5 | 97.8 mm |

摩擦不足时，**力够了也夹不住**——限制来自接触面而非肌肉。

### G4 对照组：松开肌肉会掉

夹住抬到 95 mm，然后把激活降到 0：

| 指标 | 数值 |
|---|---|
| 抬升高度 | 95.4 mm |
| **松开后掉落时间** | **0.16 s** |

### G5 抓持力闭环

PI 调节激活，跟踪目标夹持力（估计式：接触法向力 ≈ 肌肉力 − 弹簧回位力）：

| 目标 | 稳态 | 上升时间 | 末态激活 |
|---|---|---|---|
| 2 N | 2.00 N | 0.27 s | 0.51 |
| 4 N | 4.00 N | 0.22 s | 0.64 |
| 8 N | 8.00 N | 0.24 s | 0.93 |

### G6 滑移反射

40 g 方块、初始激活 0.33（刚好在打滑边缘）：

| 配置 | 抬升高度 | 加力次数 |
|---|---|---|
| 无反射 | **0 mm（抓不住）** | 0 |
| 有反射 | **86.2 mm** | 6 |

判据：手掌已抬起但方块没跟上（相对位移 > 2 mm）即判为滑移，立即提高激活。

### G7 负载扫描

| 方块质量 | 最小可抓激活 |
|---|---|
| 10 g | 0.38 |
| 30 g | 0.38 |
| 60 g | 0.40 |

### G8 手臂-夹爪联合抓取

在夹爪上方加两连杆手臂（肩/肘 PD 跟踪逆解目标、腕关节伺服保持手掌竖直），
手指参数与独立实验完全一致：

| 指标 | 数值 |
|---|---|
| 方块起始高度 | −0.345 m |
| 方块结束高度 | −0.257 m |
| **抬升** | **87.6 mm** |

手臂位置由逆解给出，抓取仍然只靠手指与方块之间的摩擦——没有任何把方块设到手上的语句。

## 已知限制

1. **单指单肌肉**：每根手指只有一条屈肌 + 一个回位弹簧，没有拮抗肌对与肌梭反馈。
2. **平面两指**：没有指尖形状（近似为长方体），未建模滚动接触。
3. **方块为刚体，30 g**，不对应具体物体。
4. **仿真步长 0.5 ms**：接触刚度较高，需要小步长才能稳定。
5. 未接入 ROS 话题，未做 sim2real。
