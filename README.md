\# ROS Turtlesim 仿真实践作业



本项目基于 ROS 机器人操作系统中的 `turtlesim` 核心仿真器开发，实现了对小海龟的运动控制、轨迹生成与话题交互，适用于机器人软件系统基础课程实验与作业展示。

\## 功能特性



\* \*\*基础运动控制\*\*：通过发布速度指令控制海龟平移与旋转。

\* \*\*特定轨迹生成\*\*：实现了指定图形轨迹绘制（如圆形、矩形或多边形闭环运动）。

\* \*\*状态实时反馈\*\*：订阅海龟位姿话题（`/turtle1/pose`），在终端实时打印坐标及朝向角。

\* \*\*参数与服务调用\*\*：支持设置轨迹颜色/宽度（`/turtle1/set\_pen`）及复位/生成新海龟服务。
