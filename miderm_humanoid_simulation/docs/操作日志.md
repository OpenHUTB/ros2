运行日志
2026‑10‑15 操作记录
1. 在The‑Construct平台选择Empty Simulation纯净ROS2环境。
2. 执行pip install mujoco，安装MuJoCo仿真库。
3. 最初方案尝试使用viewer实时窗口渲染，受云端共享内存限制，弹出窗口报错无法运行。
4. 修改方案，改为离屏渲染，代码后台生成画面帧，直接合成导出MP4视频，不需要可视化界面。
5. 踩坑记录1：最初代码渲染分辨率800×600，超出云端缓冲区上限，修改为640×480。
6. 踩坑记录2：导出MP4缺少ffmpeg编码器，安装imageio[ffmpeg]解决保存失败问题。
7. 代码运行成功，输出robot_sim.mp4仿真视频，下载保存至本地项目docs/assets文件夹。
