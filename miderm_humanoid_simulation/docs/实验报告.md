人形机器人MuJoCo动态仿真实验报告
 一、实验目的
基于MuJoCo动力学仿真引擎搭建简易人形机器人模型，完成动态仿真。

二、实验环境
运行平台：The Construct 云端Ubuntu22.04 + ROS2 Humble
仿真引擎：MuJoCo
Python依赖库：mujoco、numpy、imageio[ffmpeg]

三、模型设计
使用MJCF描述人形机器人结构，整体由地面、躯干、头部、双臂、双腿组成。
四肢设置铰链关节以及力矩电机执行器，躯干为自由关节，可以在重力作用下自由运动。
由于云端平台无法弹出图形可视化窗口，采用离屏渲染方案，仿真结束后直接导出mp4格式仿真视频。
 
四、实验步骤
1. 在云端平台选择无预装Gazebo的纯净Ubuntu环境。
2. 使用pip安装仿真所需全部依赖包。
3. 编写MJCF人形机器人模型与Python仿真代码，使用正弦函数控制四肢来回摆动。
4. 执行代码，离屏渲染生成5秒仿真视频。
5. 将生成的视频下载保存至本地项目的docs/assets目录。

五、仿真结果
人形机器人双臂与双腿按照正弦规律往复摆动，MuJoCo引擎完成动力学与重力计算，成功导出5秒动态仿真视频。

 六、实验总结
本次实验完成了人形机器人MJCF动力学模型搭建，解决了云端环境无法可视化窗口渲染的问题，掌握了MuJoCo建模、仿真以及离屏导出视频的操作流程。
